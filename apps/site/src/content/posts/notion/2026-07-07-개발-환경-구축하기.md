    - [[Java]] > [[Gradle]] Groovy > Java 25 > [[Spring]] Boot 4.0.X

### ◆ Spring Boot 4 프로젝트 실행하기

- `build.gradle` : 프로젝트의 빌드 & 의존성 & 실행 내용 정의하는 설계도

```cpp
plugins { 
	id 'java'
	id 'org.springframework.boot' version '4.0.7' // 스프링 부트
	id 'io.spring.dependency-management' version '1.1.7' // 의존성 관리
}

group = 'com.springboot'
version = '0.0.1-SNAPSHOT'

java {
	toolchain {
		languageVersion = JavaLanguageVersion.of(25) // JDK 버전
	}
}

repositories { // 의존성 받을 저장소
	mavenCentral()
}

dependencies { // 의존성 입력
	implementation 'org.springframework.boot:spring-boot-starter-web' // 추가
	implementation 'org.springframework.boot:spring-boot-starter'
	testImplementation 'org.springframework.boot:spring-boot-starter-test'
	testRuntimeOnly 'org.junit.platform:junit-platform-launcher'
}

tasks.named('test') {
	useJUnitPlatform()
}
```

- 의존성 추가하면 새로고침 하기
- 실행 방법
    - VS Code Terminal 에 `gradlew.bat bootRun` 입력
    - [http://localhost:8080/](http://localhost:8080/) 접속

## ✦ 스프링과 스프링 부트

### ◆ 스프링

- 엔터프레이즈 애플리케이션 : 대규모의 복잡한 데이터를 관리하는 애플리케이션
    - 서버 성능 & 안정성 & 보안 중요
- 스프링 프레임워크 → 엔터프라이즈 애플리케이션을 위한 개발 환경 제공

### ◆ 스프링 부트

- 스프링 프레임워크를 쉽고 빠르게 이용할 수 있도록 만들어주는 도구
- 설정 쉬움, 의존성 세트 스타터 사용해 의존성 간편하게 관리

#### 특징

- WAS (톰캣, 제티, 언더토우 등) 내장되어 있음 → 따로 설치 안해도 독립적 실행 가능
- 스프링 부트 스타터 제공 → 빌드 구성 단순화
- XML 설정 X Java 로 모두 작성 가능
- JAR 사용해 Java 옵션만으로 배포 가능
- 스프링 액츄에이터 (spring actuator) 제공 → 애플리케이션의 모니터링 · 관리 도구

### ◆ 스프링 vs 스프링 부트

1. 구성 차이
    - 스프링 : 애플리케이션 개발 환경 수동 구성 & 정의
    - 스프링 부트 : 스프링 코어 & 스프링 MVC 기능 자동 로드
2. 내장 WAS
    - 스프링 : 없음
    - 스프링 부트 : 톰캣, 제티, 언더토우 내장

## ✦ 스프링 콘셉트 공부하기

### ◆ 제어의 역전 & 의존성 주입

#### IoC (Inversion of Control)

- 객체를 직접 생성 & 제어 X
- 스프링 컨테이너가 객체 관리 & 제공

#### DI (Dependency Injection)

- IoC 를 구현하기 위한 방법
- 객체를 직접 생성하는 것이 아니라 주입 받음

### ◆ 빈과 스프링 컨테이너

#### 스프링 컨테이너

- 빈을 생성 & 관리 → 빈의 생명주기 관리
- `@Autowired` 어노테이션으로 빈 주입 받을 수 있도록 DI 지원

#### 빈 (Bean)

- 스프링 컨테이너가 생성 & 관리하는 객체
- 여러 방법으로 등록 가능
    - `@Component` 어노테이션

### ◆ 관점 지향 프로그래밍 (AOP)

- AOP (Aspect Oriented Programming)
- 프로그래밍에 대한 관심을 핵심 / 부가 관점으로 나눠 관심 기준 모듈화
    - 핵심 관점 : 프로그램 핵심 기능
    - 부가 관점 : 모든 핵심 기능에서 공통적으로 필요한 기능 
    ex) 로깅, DB 연결

### ◆ 이식 가능한 서비스 추상화 (PSA)

- PSA (Portable Service Abstraction)
- 스프링에서 제공하는 다양한 기술들을 추상화해 개발자가 쉽게 사용하는 인터페이스
- 어떤 기술을 사용하던 일관된 방식으로 처리
- ex) 어노테이션, JPA, MyBatis, JDBC, WAS

### ◆ 자동 구성

- 애플리케이션이 최소한의 설정만으로도 실행되도록 자동 구성
- 자동 구성되는 클래스 접미사 `AutoConfiguration` / 속성값 정의 클래스 접미사 `Properties`

### ◆ 스프링 부트 4와 자바 버전

#### 자바 변경 사항

- 텍스트 블록
    - 여러 줄의 텍스트 표현
    
    ```java
    String query = """
    	SELECT * FROM "items"
    	WHERE "status" = "ON_SALE"
    	ORDER BY "price";
    	""";
    ```
    
- `formatted()` 메소드
    - 값을 파싱
    
    ```java
    String textBlock = """
    	{
    		"id": %d,
    		"name": %s,
    	}
    	""".formatted(2, "juice");
    ```
    
- 레코드
    - 데이터 전달 목적 객체 빠르고 간편하게 만들기
    - 상속 불가, parameter 정의 필드는 private final 로 정의
    - getter 자동 생성
    
    ```java
    record Item(String name, int price) {
    	// parameter 자동 private final 로 정의
    }
    Item juice = new Item("juice", 3000);
    
    // 레코드 패턴
    if (obj instanceof Item(String name, int price)) {
    
    }
    ```
    
- 패턴 매칭
    - `instanceof` 키워드 더 쉽게 이용
    
    ```java
    switch (o) {
    	case Integer i -> {
    		// i 사용
    	}
    	case String s -> {
    		// s 사용
    	}
    	default -> {
    		// 기타 타입 처리
    	}
    }
    ```
    
- 가상 스레드
    - 적은 리소스로 대량의 동시 작업 효율적 처리
    
    ```java
    try (ExecutorService executor = Executors.newVirtualThreadPerTaskExecutor()) {
    	executor.submit(() -> {
    		// 작업 처리
    	});
    }
    ```

## ✦ 스프링 부트 4 코드 이해하기

### ◆ BlogprojectApplication.java

```java
package com.springboot.blogproject;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication // 스프링 부트 기본 설정
public class BlogprojectApplication {

	public static void main(String[] args) {
		SpringApplication.run(BlogprojectApplication.class, args); // 실행 
		// 메인 클래스, 커맨드 라인 인수 전달
	}
}
```

→ Java 의 `main()` 메소드 역할

#### `@SpringBootApplication`

```java
@Target(ElementType.TYPE)
@Retention(RetentionPolicy.RUNTIME)
@Documented
@Inherited
@SpringBootConfiguration  // 스프링 부트 관련 설정
@EnableAutoConfiguration  // 자동으로 등록된 빈을 읽고 등록
@ComponentScan(excludeFilters = { // 사용자가 등록한 빈을 읽고 등록
		@Filter(type = FilterType.CUSTOM,  
						classes = TypeExcludeFilter.class),
		@Filter(type = FilterType.CUSTOM, 
						classes = AutoConfigurationExcludeFilter.class) }) 
public @interface SpringBootApplication {
	...
}
```

| 이름 | 설명 |
| --- | --- |
| `@Configuration` | 설정 파일 등록 |
| `@Repository` | ORM 매핑 |
| `@Controller`, `@RestController` | 라우터 |
| `@Service` | 비즈니스 로직 |

### ◆ TestController

#### `@RestController`

```java
@Target(ElementType.TYPE)
@Retention(RetentionPolicy.RUNTIME)
@Documented
@Controller
@ResponseBody
public @interface RestController {

	@AliasFor(annotation = Controller.class)
	String value() default "";

}
```

#### `@Controller`

```java
@Target(ElementType.TYPE)
@Retention(RetentionPolicy.RUNTIME)
@Documented
@Component // 빈으로 등록 위해 필요
public @interface Controller {

	@AliasFor(annotation = Component.class)
	String value() default "";

}
```

→ `@Controller` , `@RestController`, `@Configuration`, `@Repository`, `@Service` 모두 `@Component` 어노테이션 가지고 있음

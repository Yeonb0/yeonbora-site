## ✦ 서버와 클라이언트

### ◆ 클라이언트 (Client)

- 서버로 요청하는 모든 프로그램
- ex) 웹 브라우저

### ◆ 서버 (Server)

- 클라이언트의 요청을 받아 처리하는 주체
- 데이터 요청 / 처리 요청

## ✦ 데이터베이스 (Database)

- 여러 데이터를 한 곳에 모아두고 관리하는 데이터 저장소
- 클라이언트에서 SQL 로 데이터베이스 관리 시스템에 데이터 요청
→ 데이터베이스 관리 시스템은 데이터베이스에서 데이터 꺼내 응답

### ◆ RDB (Relational Database) : 관계형 데이터베이스

- 데이터를 행 (row) & 열 (column) 로 이뤄진 테이블로 관리
- 기본키 (primary key) 이용해 각 행 식별
- 각 테이블 간 관계 지을 수 있음
- ex) Oracle, MySQL, SQL server, PostgreSQL

### ◆ SQL (Structured Query Language)

- 데이터 검색을 하는 언어
- ANSI 표준 SQL
- 각 RDB 별 방언 존재

### ◆ NoSQL

- Not Only SQL
- RDB 의 문제 해결
- ex) DynamoDB, Couchbase, MongoDB

## ✦ IP 와 Port

- IP : 인터넷에서 컴퓨터 or 기기 식별 & 통신 위한 주소. 서버 찾기 위한 번호
- Port : 서버에서 운용되고 있는 서비스 구분 번호

## ✦ 라이브러리와 프레임워크

### ◆ 라이브러리 (Library)

- 클래스 & 함수 등을 모아놓은 코드 모음
- 다른 사람들이 미리 개발해놓은 원하는 기능 사용하기
- 의존성에 추가해 사용 가능

### ◆ 프레임워크 (Framework)

- 소프트웨어 개발을 수월하게 하기 위한 소프트웨어 개발 환경
→ 전체적인 구조 잡기
- 장점 : 개발 효율 높음
- 단점 : 정해진 틀에서 개발해야 함

## ✦ 백엔드 개발자의 업무

1. 과제 할당
2. 과제 분석
3. 개발
4. 테스트
5. QA (Quality Assurance)
6. 배포 
7. 유지보수
    - 빌드 & 배포 자동화 → CI / CD

## ✦ 백엔드 프로그래밍 언어

- Python, C++, Java, C#, JS

## ✦ 자바 애너테이션 (Java annotation)

- 자바로 작성한 코드에 추가하는 표식
- `@` 기호 사용
- 메타 데이터로 사용

| 이름 | 설명 |
| --- | --- |
| `@Override` | Method 가 오버라이드 되었음 |
| `@Deprecated` | 더 이상 사용되지 않음 |
| `@SuppressWarnings` | 컴파일 경고를 무시함 |

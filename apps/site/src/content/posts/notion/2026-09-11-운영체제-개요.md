## ✦ 운영체제 개요

- 프로그맹이 실행되면?
    - 명령어 계속계속 실행 (fetch → decode → execute)
- 시스템 사용 쉽게 하려고 프로그램 실행할 때 여러 일이 일어남! 
→ [[운영체제|OS]] 가 이런 것들을 한다.
- 운영체제 (Operating System, OS)
    - 프로그램 쉽게 실행 + 동시에 여러 개 실행
    - 프로그램 간 [[메모리]] 공유
    - 장치랑 상호작용
    - 그외 흥미로운,,
- 어떻게 이런 것들을 함??
    - 가상화 (Virtualization)
        - 물리적 자원으로 가상 형태 자원 생성
        - OS 를 가상 머신 (virtual machine) 이라고도 함.
    - 기능 제공은? 응용 프로그램들이 사용 가능한 시스템 콜 (System call) 제공 (표준 라이브러리를 제공한다고도 함)
    - 자원 관리자 (resource manager)
        - 여러 시스템 자원 (CPU, 메모리, 디스크) 같은 자원들을 관리

### ◆ CPU 가상화

> OS 는 자원을 어떻게 가상화 하는가?
> 
> - 왜 가상화 하는진 뻔함 → 시스템을 사용하기 편리하게 만듬..
- 운영체제는 하드웨어 도움으로 시스템에 가상 CPU 가 여러개 존재하는 거같은 환상 (illusion) 만듬
- CPU 가상화 (virtualizing the CPU) : 한 CPU or 적은 CPU 를 무한개의 CPU 가 존재하는 것처럼 변환해 동시에 많은 수 프로그램 실행하게 함
    - 어떤 [[API]] 가 이런게 가능하게 하는가?
- 동시에 다수의 프로그램을 어떻게 실행하는가? 방법
    
    → 자원 관리자 역할
    

### ◆ 메모리 가상화

- 컴퓨터에서 물리 메모리 (physical memory) 는 그냥 byte 의 [[배열]]
- 근데 실제로 같은 프로그램을 여러 번 실행시키면 각자 자신의 메모리가 있는 거 같아보임
    - 메모리 가상화 (virtualizing memory) 를 하기 때문!
- 각 프로세스는 자신 만의 가상 주소 공간 (virtual address space) 를 가짐

### ◆ 병행성

- 운영체제 안에서도 병행 문제 일어남.. 여러 프로세스를 동시 실행
- 멀티 쓰레드 프로그램에서도 문제 발생
    - 여러 명령어들이 원자적으로 (atomically) 실행 안되고 걍 지들 알아서 실행됨

### ◆ 영속성

- DRAM 은 휘발성 → 그래서 저장 장치는 필수!
- 디스크 관리하는 운영체제 [[소프트웨어]] → 파일 시스템 (file system)
    - 디스크 어디에 저장?
    - 데이터 상태 추적

### ◆ 설계 목표

- 운영체제
    - 물리 자원 (CPU, 메모리, 디스크) 가상화
    - 병행성 관련 문제 처리
    - 파일 영속적으로 저장
- 우리의 목표!
    - 시스템 사용에 필요한 개념을 정의하자!
    - 오버헤드를 최소화하는 해결책을 찾아보자!
    - 서로서로 보호 (고립) 하자!
    - 신뢰성 (reliability) 을 제공하자!
    - 기타로 에너지 효율, 보안, 이동성 등등,,

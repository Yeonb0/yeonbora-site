## ✦ 프로세스 API

- Unix 에서 프로세스 어케 생성?

### ◆ `fork()` 시스템 콜

- 기존 프로세스를 복사해서 생성
    - 부모 프로세스 : 생성된 자식 프로세스 PID 반환
    - 자식 프로세스 : 0 반환
- 자식은 자신의 주소 공간, 레지스터, PC 값을 가짐
- 단일 CPU 시스템에서, 순서는 고정되어 있지 않음. 부모부터도 자식부터도 가능..
    
    → 멀티 쓰레드 프로그램에서 문제 발생 
    

### ◆ `wait()` 시스템 콜

- 부모 프로세스가 자식 프로세스 종료 대기하기.
- 자식이 종료되면 return
- 항상 자식이 먼저 출력 수행!

### ◆ `exec()` 시스템 콜

- 자기 자신이 아닌 다른 프로그램 실행
    - 실행 파일 이름 + 인자 입력하면 현재 실행 중인 프로세스의 code 와 data 부분 덮어 씀.
    heap, stack 은 초기화
- 새로운 프로세스 생성 X 현재 프로그램을 다른 프로그램으로 대체!
    - 그럼 현재 실행 중인 프로그램은? 절대로 return XX.. 그대로 사라져벌임..

## ✦ 페이징: 더 작은 테이블

- 페이지 테이블의 크기를 어떻게 할 것인가?
    - 선형 페이지 테이블
        - 각 페이지 크기가 4KB, 각 항목 32  bit
        → 가상 페이지 갯수 $\frac{2^{32}}{2^{12}}$ = 약 100만 개!
        - 각 항목 4 byte × 100만 개 → 한 페이지 테이블 4MB
    - 근데 각 프로세스가 페이지 테이블을 가짐..
        - 만약 100 개의 프로세스가 실행 중이면 페이지 테이블만 400MB 필요!
        ⇒ 메모리 부담..
- 어떻게 페이지 테이블의 크기를 줄일 수 있을까?

### ◆ 간단한 해법 : 더 큰 페이지

- 페이지 크기를 증가 시키자!
- ex) 32 bit, 16KB 페이지 → VPN 18 bit / Offset 14 bit
    - 각 PTE 의 크기가 4 byte 면

#### 택스트 작성하기

1\) hn 태그 : heading 1\~6. 숫자가 작을 수록 중요도가 높다. 검색 엔진에서 키워드로 인식

\#검색 엔진은 검색 시 h1부터 단계적으로 검색

 

```html
<h1>Heading level 1</h1>
<h2>Heading level 2</h2>
<h3>Heading level 3</h3>
<h4>Heading level 4</h4>
<h5>Heading level 5</h5>
<h6>Heading level 6</h6>
```

```html demo
<h1>Heading level 1</h1>
<h2>Heading level 2</h2>
<h3>Heading level 3</h3>
<h4>Heading level 4</h4>
<h5>Heading level 5</h5>
<h6>Heading level 6</h6>
```

 

2\) p 태그 : 본문의 문단 작성 시 사용

3\) br 태그 : 문단 줄바꿈 시 사용 (단독 사용)

4\) blockquote 태그 : 출처에서 인용한 문단 단위의 텍스트 작성시 사용

<span style="background-color: #666666; color: #ffffff;">\<blockquote <span style="background-color: #666666; color: #ffc1c8;">cite=<span style="color: #99cefa;">"출처 URL"> \<p> 반드시 한 개 이상의 p 태그를 포함해야 한다. \</p> \</blockquote></span></span></span>

 

```html
<blockquote cite="https://ko.wikipedia.org/wiki/HTML">
    <p>하이퍼 텍스트 마크업 언어(Hyper Text Markup Language, HTML, 문화어: 초본문표식달기언어, 하이퍼본문표식달기언어)는 웹 페이지를 위한 지배적인 마크업 언어다. 
    <br>또한, HTML은 제목, 단락, 목록 등과 같은 본문을 위한 구조적 의미를 나타내는 것뿐만 아니라 링크, 인용과 그 밖의 항목으로 구조적 문서를 만들 수 있는 방법을 제공한다. </p>
</blockquote>
```

5\) q 태그 : 문단 안 텍스트 단위 짧은 인용문. 사용하면 큰 따옴표(" ")로 묶임

<span style="background-color: #666666; color: #ffffff;">\<p> \<q </span><span style="background-color: #666666; color: #ffc1c8;">cite=<span style="color: #99cefa;">"출처 URL"> 이 안의 내용은 " " 로 묶인다. \</q> \</p></span></span>

```html
<p>차세대웹기술지원센터의 데이터에 따르면 <q cite="https://www.koreahtml5.kr/front/stats/browser/browserUseStats.do">2021년 대한민국에서 가장 높은 점유율을 가지고 있는 웹 브라우저는 구글의 크롬입니다.</q></p>
```

6\) ins 태그 : 새로 추가된 텍스트 표시. <u>밑줄이 표시된다</u>

7\) del 태그 : 삭제된 텍스트 표시. ~~취소선이 표시된다~~

8\) sub 태그 : 아래 첨자 텍스트

9\) sup 태그 : 위 첨자 텍스트

```html
<p>정가 : <del>36,000원</del><ins>20,000원</ins></p>
<p>공기의 원소 기호 : H<sub>2</sub>O</p>
<p>4<sup>2</sup> = 16</p>
```

```html demo
<p>정가 : <del>36,000원</del><ins>20,000원</ins></p>
<p>공기의 원소 기호 : H<sub>2</sub>O</p>
    <p>4<sup>2</sup> = 16</p>
```

#### 그룹 짓기 : 공간 분할 태그

1\) div 태그 : 블록 요소 & 인라인 요소를 그룹으로 묶을 때 사용 

```html
<div class="movie">
    <p>영화 소개</p>
    <p>영화를 소개하는 페이지입니다.</p>
</div>
<div class="tv">
    <p>TV 프로그램 소개</p>
    <p>TV 프로그램을 소개하는 페이지입니다.</p>
</div>
```

```html demo
<div class="movie">
    <p>영화 소개</p>
    <p>영화를 소개하는 페이지입니다.</p>
  </div>
  <div class="tv">
    <p>TV 프로그램 소개</p>
    <p>TV 프로그램을 소개하는 페이지입니다.</p>
  </div>
```

 

2\) span 태그 : 인라인 요소를 그룹으로 묶을 때 사용. 하나의 태그 안 일부 텍스트만 변경하고 싶을 때 사용!

```html
<h1>영화 소개</h1>
  <p>이번 영화의 <span>하이라이트</span> 장면은 바로 여기입니다.</p>
```

'하이라이트' 라는 텍스트만 지정.

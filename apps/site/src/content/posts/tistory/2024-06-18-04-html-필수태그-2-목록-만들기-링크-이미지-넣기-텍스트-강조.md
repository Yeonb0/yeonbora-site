#### 목록 만들기

1\) ul 태그 : 순서 없는 목록 생성.

  - li 태그 : 목록 내용 구성 → 글 머리 기호 붙음 

```html
<h1>판매 중인 과일</h1>
  <ul>
    <li>바나나</li>
    <li>사과</li>
    <li>수박</li>
  </ul>
```

```html demo
<h1>판매 중인 과일</h1>
  <ul>
    <li>바나나</li>
    <li>사과</li>
    <li>수박</li>
  </ul>
```

 

2\) ol 태그 : 순서 있는 목록 생성.

  - li 태그 : 목록 내용 구성 → 번호 붙음 

```html
<h1>오늘 할일</h1>
  <ol>
    <li>아침 먹기</li>
    <li>점심 먹기</li>
    <li>저녁 먹기</li>
  </ol>
```

```html demo
<h1>오늘 할일</h1>
  <ol>
    <li>아침 먹기</li>
    <li>점심 먹기</li>
    <li>저녁 먹기</li>
  </ol>
```

 

3\) dl 태그 : 정의형 목록 생성.

  - dt 태그 : 용어 작성

  - dd 태그 : 용어 설명 작성 

```html
  <dl>
    <dt>HTML</dt>
    <dd>HTML은 Hyper Text Markup Language의 약자로 웹 문서의 구조를 설계하기 위한 목적으로 개발된 언어입니다.</dd>
    <dt>CSS</dt>
    <dd>CSS는 Cascading Style Sheets의 약자로 웹 문서를 꾸미기 위한 목적으로 개발된 언어입니다.</dd>
  </dl>
```

```html demo
  <dl>
    <dt>HTML</dt>
    <dd>HTML은 Hyper Text Markup Language의 약자로 웹 문서의 구조를 설계하기 위한 목적으로 개발된 언어입니다.</dd>
    <dt>CSS</dt>
    <dd>CSS는 Cascading Style Sheets의 약자로 웹 문서를 꾸미기 위한 목적으로 개발된 언어입니다.</dd>
  </dl>
```

#### 링크 & 이미지 넣기

1\) a 태그 : HTML에서 내부 or 외부 링크 생성

  - href 속성 : 대상 경로, 필수. URL or 내부 문서 id 속성값 (불명확할 시 #)

  - target 속성 : 링크 연결 방식. 선택. 기본값은 기존 페이지 덮어 쓰기.

<span style="color: #006dd7;">    "</span><span style="background-color: #ffffff; color: #99cefa;"><span style="color: #006dd7;">\_blank" : 새창으로 열기</span> </span>

  - title 속성 : 링크 설명 텍스트 작성. 선택.

```html
<a href="https://www.gilbut.co.kr" target="_blank" title="도서출판 길벗">길벗 홈페이지</a>
```

```html demo
<a href="https://www.gilbut.co.kr" target="_blank" title="도서출판 길벗">길벗 홈페이지</a>
```

 

2\) img 태그 : 이미지 객체 삽입

  - src 속성 : 삽입 이미지 경로. 기준은 웹브라우저 실행 HTML파일의 위치. 필수. 링크도 가능하다!

<table>
<tbody>
<tr>
<td>./</td>
<td>현재 폴더</td>
</tr>
<tr>
<td>../</td>
<td>상위 폴더</td>
</tr>
</tbody>
</table>

ex) if 상위 상위 폴더에 있는 beach.jpg 사용한다면 → <span style="background-color: #666666;"><span style="color: #ffc1c8;">src</span>=<span style="color: #99cefa;">"../../images/beach.jpg"</span></span> 로 경로 표현

 

  - alt 속성 :  이미지 설명 텍스트 작성. 필수.

 

3\) a 태그 안에 img 태그가 위치할 수 있음. 이 경우 이미지를 누르면 링크로 이동.

```html
  <a href="https://www.google.com" target="_blank">
    <img src="https://cdn-icons-png.flaticon.com/512/2991/2991148.png" alt="구글 로고">
  </a>
```

```html demo
  <a href="https://www.google.com" target="_blank">
    <img src="https://cdn-icons-png.flaticon.com/512/2991/2991148.png" alt="구글 로고">
  </a>
```

#### 텍스트 강조

1\) strong 태그 : 텍스트 의미 강조. **텍스트 굵게 표시.&#xA0;**&#xC911;첩 사용가능(but 효과는 동일) / = b 태그

2\) em 태그 : 텍스트 의미 강조. *텍스트 기울게 표시.* 중첩 사용가능(but 효과는 동일) / = i 태그 

 

```html
<p>이 텍스트는 <em>매우</em> <strong>중요한</strong> 내용입니다. </p>
```

```html demo
<p>이 텍스트는 <em>매우</em> <strong>중요한</strong> 내용입니다. </p>
```

3\) label 태그 : form 태그 안에 사용하는 상호작용 요소에 이름 붙일 때 사용 <>\</>

  - 암묵적 방법 : label 태그 안에 상호작용 요소 포함

```html
<label>
	아이디
    <input type="text">
</label>
```

 

  - 명시적 방법 : label 태그 for 속성 = 상호작용 요소 id 속성 

```html
<label for="userpw">비밀번호</label>
<input type="password" id="userpw">
```

 

  - 동시 사용도 가능하다

```html
<label for="username">
	<input type="text" id="username">이름
</label>
```

 

4\) fieldset 태그 : 상호작용 요소 그룹 짓기. 그룹별로 박스 모양 테두리 생김. <>\</>

5\) legend 태그 : 그룹 지은 요소 이름 붙이기. <>\</>

```html
<form action="#">
  <fieldset>
  	<legend>그룹이름</legend>
    <p>
      <label for="userid">아이디</label>
      <input type="text" id="userid">
    </p>
    <p>
      <label for="passwd">비밀번호</label>
      <input type="password" id="passwd">
    </p>
  </fieldset>
</form>
```

7\) select 태그 : 콤보박스 생성 <>\</>

  - option 태그 : 콤보박스에 항목 추가 <>\</>

  - optgroup 태그 : 항목들을 그룹으로 묶을때 사용. 반드시 label 속성으로 그룹명 지정해야함 <>\</>

 

  - size 속성 (select) : 콤보박스에서 화면에 노출되는 항목 개수 지정. 속성 값으로 숫자. 기본 1개.

  - multiple 속성 (select) : 여러 항목 동시에 선택 가능. 하나 선택한 상태로 Ctrl 누르고 클릭

  - selected 속성 (option) : 기본 선택 항목 변경

```html
<select name="city" id="city" size="5" multiple>
  <optgroup label="서울시">
    <option value="강북구">강북구</option>
    <option value="강남구">강남구</option>
    <option value="서초구" selected>서초구</option>
  </optgroup>
  <optgroup label="경기도 성남시">
    <option value="중원구">중원구</option>
    <option value="분당구">분당구</option>
  </optgroup>
</select>
```

9\) 폼 관련 속성들

  - disabled 속성 : 상호작용 요소 비활성화. input, textarea, select, button 태그에 사용 가능

    → 서버 전송시 값 전송 X

  - readonly 속성 : 상호작용 요소 읽기 전용으로 변경. 입력 불가 / 선택, 복사 가능.  textarea, input 태그에 사용 가능

    → 서버 전송시 값 전송 O 

  - maxlength 속성 : 입력 가능 글자 수 제한. 숫자 입력. textarea, input 태그에 사용 가능

  - checked 속성 : 요소를 선택된 상태로 표시. input 태그의 checkbox, radio에 사용 가능

  - placeholder 속성 : 입력 요소에 대한 힌트 적는 용도

```html
<fieldset>
    <legend>좋아하는 과일</legend>
    <input type="checkbox" id="banana" name="banana" value="banana">
    <label for="banana">banana</label><br>
    <input type="checkbox" id="apple" name="apple" value="apple">
    <label for="apple">apple</label><br>
    <input type="checkbox" id="orange" name="orange" value="orange"  checked>
    <label for="orange">orange</label><br>
</fieldset>
<input type="tel" placeholder="전화번호를 입력해 주세요.">
```

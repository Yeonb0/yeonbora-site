#### 표 만들기

1\) table 태그 : 표 생성시 사용(HTML만 사용 시 선이 없다) <>\</>

  2) caption 태그 : 표 제목 지정. table 태그 안 가장 먼저 작성

  3) tr 태그 : table row. 표에서 행 생성

    4) th 태그 : 표에서 제목을 나타내는 열 생성

    5) td 태그 : 표에서 일반적 데이터를 나타내는 열 생성

 

```html
<table>
  <tr>
    <th>번호</th>
    <th>상품명</th>
    <th>수량</th>
    <th>가격</th>
  </tr>
  <tr>
    <td>1</td>
    <td>콜라</td>
    <td>1개</td>
    <td>1,500원</td>
  </tr>
  <tr>
    <td>2</td>
    <td>사이다</td>
    <td>2개</td>
    <td>1,000원</td>
  </tr>
  <tr>
    <td>3</td>
    <td>탄산수</td>
    <td>3개</td>
    <td>1,000원</td>
  </tr>
</table>
```

6\) rowspan : 행과 행 병합

7\) colspan : 열과 열 병합

→ 속성값으로 병합하고 싶은 셀의 개수 적기. 병합한 수 만큼 다음 행 or 열 비워야 함.

```html
<table>
    <tr>
      <th>번호</th>
      <th>상품명</th>
      <th>수량</th>
      <th>가격</th>
    </tr>
    <tr>
      <td>1</td>
      <td>콜라</td>
      <td>1개</td>
      <td>1,500원</td>
    </tr>
    <tr>
      <td>2</td>
      <td>사이다</td>
      <td>2개</td>
      <td rowspan="2">1,000원</td> <!-- 행 병합-->
    </tr>
    <tr>
      <td>3</td>
      <td>탄산수</td>
      <td>3개</td> 
      <!-- 4행 4열은 3행 4열과 병합했으므로 생성하지 않습니다. -->
    </tr>
    <tr>
      <td>총 금액</td>
      <td colspan="3">6,500원</td> <!-- 열 병합-->
      <!-- 5행 2열부터 열 3개를 병합했으므로 나머지 열은 생성하지 않습니다. -->
    </tr>
  </table>
```

8\) thead, tfoot, tbody 태그 : 각각 헤더 영역, 푸터 영역, 본문 영역 해당 행 그룹.

→ 순서 : thead, tfoot, tbody 순. thead와 tfoot은 한 번만 사용 가능.

11\) scope 속성 : 제목 나타내는 셀의 범위 지정. th 태그에서만 사용 가능

<table>
<tbody>
<tr>
<td>col</td>
<td>열, 세로 방향 </td>
</tr>
<tr>
<td>colgroup</td>
<td>그룹화 된 열</td>
</tr>
<tr>
<td>row </td>
<td>행, 가로방향</td>
</tr>
<tr>
<td>rowgroup</td>
<td>그룹화 된 행</td>
</tr>
</tbody>
</table>

```html
<table>
    <tr>
      <th scope="col">구분</th>
      <th scope="col">중간고사</th>
      <th scope="col">기말고사</th>
    </tr>
    <tr>
      <th scope="row">전공</th>
      <td>A+</td>
      <td>B+</td>
    </tr>
    <tr>
      <th scope="row">교양</th>
      <td>C-</td>
      <td>B</td>
    </tr>
  </table>
```

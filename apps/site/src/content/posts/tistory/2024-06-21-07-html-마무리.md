### 멀티미디어 설정

1\) audio 태그 : 오디오 파일 삽입 <>\</>

  - src 속성 : 오디오 파일 경로

  - controls 속성 : 오디오 컨트롤 패널 

 

2\) video 태그 : 비디오 파일 삽입 <>\</>

  - src 속성 : 비디오 파일 경로

  - controls 속성 : 비디오 컨트롤 패널

 

3\) source 태그 : audio, video 태그에서 파일 경로, 미디어 타입 명시

  - src 속성 : 파일 경로 표시

  - type 속성 : 미디어 타입 표시

---

### 시맨틱 태그

1\) header 태그 : 헤더 영역 구분시 사용. 웹 최상단. 로고, 검색, 메뉴 등등 <>\</>

2\) nav 태그 : 웹 페이지에서 내부의 다른 영역이나 외부를 연결하는 링크 영역 구분 <>\</>

3\) section 태그 : 웹 페이지에서 논리적으로 관련 있는 내용 영역 구분. 보통 hn 태그 중 하나 포함 <>\</>

4\) article 태그 : 웹 페이지에서 독립적인 영역 구분 시 사용(단독) <>\</>

5\) aside 태그 : 웹 페이지에서 주된 내용, 독립적 내용 아닐시 사용 <>\</>

6\) footer 태그 : 푸터 영역 구분시 사용. 웹 최하단. 저작권, 연락처, 사이트 맵 등등 <>\</>

7\) main 태그 : 웹 페이지 주요 내용 지정 시 사용

### 글로벌 속성

1\) class 속성 : 요소에 클래스명 지정시 사용. 여러 요소 중복 가능

2\) id 속성 : 요소에 아이디명 지정시 사용. 중복 불가

3\) title 속성 : 요소에 추가 정보 넣을 때 사용. 마우스 올리면 툴팁으로 표시

```html
<p><span title="World Wide Web Consortium">W3C</span>는 국제 웹 표준 개발 기구입니다.</p>
```

```html demo
<p><span title="World Wide Web Consortium">W3C</span>는 국제 웹 표준 개발 기구입니다.</p>
```

4\) style 속성 : CSS 코드 인라인으로 작성시 사용

5\) lang 속성 : 텍스트의 언어 코드 지정시 사용 

6\) data-\* 속성 : 사용자 커스텀 속성 만듬.

#### CSS 문법 형식

1\) 형식 : 선택자{속성:값;}

```css
h1{
  font-size:24px;
  color:red;
}
```

 

2\) 주석 : /\* 주석 내용 \*/

```css
/* 주석 내용 입력 */
```

---

#### CSS 적용하기

1\) 내부 스타일 시트 사용하기 : style 태그

```css
<style>
  /* CSS 코드 */
</style>
```

 

2\) 외부 스타일 시트 사용하기 : 별도 CSS 파일과 연결 → 가장 많이 사용

```html
<link rel="stylesheet" href="css 파일 경로">
```

 

3\) 인라인 스타일 사용하기 : 태그에 직접 CSS 코드 작성

```html
<body>
  <h1 style="color:red; font-size:24px;">인라인 스타일</h1>
</body>
```

```html demo
<body>
  <h1 style="color:red; font-size:24px;">인라인 스타일</h1>

```

### 기본 선택자

1\) 전체 선택자 : HTML에서 사용할 수 있는 모든 요소 선택. "\*" 기호로 표시

2\) 태그 선택자 : HTML 태그명으로 선택자 지정. p, hn, 등등

3\) 아이디 선택자 : HTML 태그에서 id 속성 값 이용해 지정. "#" 기호로 표시

4\) 클래스 선택자 : HTML 태그에서 class 속성 값 이용해 지정. "."기호로 표시

5\) 기본 속성 선택자 : HTML 태그의 속성과 값 이용해 지정

<span style="background-color: #333333; color: #ffffff;">\[<span style="background-color: #666666; color: #ffc1c8;">속성=<span style="background-color: #666666; color: #99cefa;">값]{<span style="color: #9feec3;">/\* CSS 코드 \*/}</span></span></span></span>

  - 속성 선택자는 다른 선택자와 함께 사용할 수 있다.

### 조합 선택자

1\) 그룹 선택자 : 여러 선택자 하나로 그룹 짓기. "," 기호 사용

```css
p, #title, .red {
  color:red;
}
```

 

2\) 자식 선택자 : 부모 텍스트 하위에 있는 자식 요소만 스타일 적용. > 기호로 구분

```css
.box > p{
  color:red;
}
/* box 클래스 안에 있는 p 태그 작성 요소만 선택 */
```

 

3\) 하위 선택자 : 선택자 범위 특정 부모 요소의 하위 요소 한정. 공백으로 구분

```css
div p{
  color:red;
}
/* div 태그 하위의 p만 선택 */
```

 

4\) 인접 형제 선택자 : 형제 관계 요소 선택자 지정(형제만 지정) + 기호로 구분

```css
h1+h2{
  color:red;
}
/* h1 과 형제인 h2만 지정 */
```

 

5\) 일반 형제 선택자 : 이전 선택자 뒤에 오는 형제 관계 요소를 모두 선택자 지정

```html
 <title>일반 형제 선택자(general_sibling)</title>
  <style>
    h1 ~ h2{
      color:red
    }
  </style>
</head>
<body>
  <h1>lorem1</h1>
  <h2>lorem2</h2>
  <h2>lorem3</h2>
</body>
<!-- lorem2,3 모두 적용 -->
```

### 다양한 선택자 조합

```css
div.box{} 
/* class 속성값이 box인 div 태그 */

section#main{}
/* id 속성값이 main인 section 태그 */

#main.box{}
/* id 속성값이 main이고 class 속성값이 box인 요소 선택 */

div:hover button{}
/* div 태그에 마우스를 올린 상태일 때, 해당 div 태그 하위의 button 태그 선택 */

div:hover > button
/* div 태그에 마우스를 올린 상태일 때, 해당 div 태그의 자식인 button 태그 선택 */
```

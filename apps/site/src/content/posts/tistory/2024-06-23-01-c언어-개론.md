### 1. C언어란

1\) 프로그래밍 언어 : 사람과 컴파일러가 이해할 수 있는 언어

2\) 컴파일러 : 프로그래밍 언어를 기계어로 번역하는 역할.

 

### 2. C언어의 장점

1\) 절차지향적 : 정해진 순서의 실행 흐름 중시

2\) 이식성이 좋음 : CPU 종류에 상관없이 실행 가능

3\) 좋은 성능 : 사용 메모리 적음. 속도 최적화

 

### 3. C언어 프로그램의 이해

1\) 프로그램의 작성

2\) 작성한 프로그램 컴파일

3\) 컴파일 된 결과물 링크

 

```cpp
#include <stdio.h>

int main(){
  printf("Hello world!");
  return 0;
}
```

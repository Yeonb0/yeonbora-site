### 1. C언어의 기본 단위 '함수'

```cpp
int main(void){
  return 0;
}
```

 

<span style="background-color: #666666;"><span style="color: #ffc9af;">출력형태</span> <span style="color: #99cefa;">함수이름</span>(입력형태){</span>

<span style="background-color: #666666;">  <span style="color: #ffc1c8;">반환형</span> 반환값;</span>

<span style="background-color: #666666; color: #ffffff;">}</span>

 

  - 함수 내의 존재하는 문장 끝에는 ';'를 붙여주어야 한다

  - 표준 함수 : 기본적으로 제공되는 함수

  - 표준 라이브러리 : 표준 함수들의 모임

    → 표준 라이브러리를 불러오기 위해선 헤더파일을 선언해야 한다

<span style="background-color: #666666; color: #9feec3;">#include <헤더파일명.h></span>

  - return 0;   →  값 반환 / 함수 종료 (0은 정상적인 종료라는 뜻)

### 2. 주석

1\) 블록 단위 주석

```cpp
/* 주석 처리 방법1 */
/* 
	여러 줄 주석 방법
    시작과 끝을 표시
*/
```

  - 블록 단위 주석은 중첩 될 수 없다.

 

2\) 행 단위 주석

```cpp
// 주석 처리 하기
```

  - 행 단위 주석은 블록 단위 주석 내부에 포함될 수 있다.

### 3. printf 함수의 이해

 - 문자열 이외의 데이터를 서식 문자를 통해 출력할 수 있다.

```cpp
#include <stdio.h>

int main(){
  printf("Hello Everybody\n");
  printf("%d\n",1234);
  printf("%d %d\n",10,20);

  return 0;
}
```

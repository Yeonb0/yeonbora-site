### 2. 변수

  - 값을 저장할 수 있는 메모리 공간, 혹은 그 이름

```cpp
int num;
// 자료형이 int 인 변수 num 선언
```

  - 변수를 선언하고 초기화하지 않은 뒤 출력하면 쓰레기 값이 나온다

```cpp
int num = 10;
// 선언과 동시에 초기화 가능
```

```cpp
int num1=10, num2=30;
// 한번에 여러 변수를 선언 및 초기화 할 수 있다
```

 

  - 변수 이름 규칙들

1\) 변수의 이름은 알파벳, 숫자, 언더바(\_)로 구성된다

2\) C언어는 대소문자를 구분한다

3\) 변수의 이름은 숫자로 시작할 수 없고, 키워드로 변수의 이름으로 사용할 수 없다

4\) 이름 사이에 공백이 삽입될 수 없다

5\) 변수의 이름은 의미 있는 이름이어야 한다

3\) 상속 : 부모 요소에 적용된 스타일을 자식 요소가 물려받음 

```css
<style>
 	div{
      color:red;
    }
  </style>  
<body>
  <div>
    <p>inherit</p>
  </div>
</body>
```

 

```html demo
<style>
    id="div1" div{
      color:red;
    }
  </style>  
<body>
  <div id="div1">
    <p style="color:red">inherit</p>
  </div>
</body>
```

5\) 색상 

  - 키워드 표기법 : red, blue, white, black 등등 키워드 사용

  - RGB 색상 표기법

rgb(red, green, blue) : 빨강, 초록, 파랑 0\~255

rgba(red, green, blue, alpha) : 빨강, 초록, 파랑 0\~255 / 투명도 0\~1 (소숫점 앞 0 생략 가능)

  - HEX 색상 표기법 : Red, Green, Blue 값 16진수 변환, #+00\~ff로 나타내기. 가장 많이 사용!

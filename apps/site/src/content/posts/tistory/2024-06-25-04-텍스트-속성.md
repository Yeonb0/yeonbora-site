#### 1) font-family 속성

#### 2) font-size 속성

  - 텍스트 글씨 크기 변경. 속성값으로 단위를 포함한 크기.

<span style="color: #ffc1c8; background-color: #666666;">font-size: <span style="color: #99cefa;">크기;</span></span>

```css
p{
  font-size:14px;
}
```

 

#### 3) font-weight 속성

  - 텍스트 굵기 지정 

  - 숫자 표기법 : 숫자 100단위로 굵기 표기. 얇음 100\~900 굵음

  - 키워드 표기법 : 키워드로 표시. lighter(부모 요소보다 얇게), normal(400), bold(700), bolder(부모 요소보다 두껍게)

<span style="color: #ffc1c8; background-color: #666666;">font-weight: <span style="color: #99cefa;">크기;</span></span>

#### 5) font-variant 속성 

  - 영문 텍스트를 크기가 작은 대문자로 변경시 사용

<span style="background-color: #666666;"><span style="color: #ffc1c8;">font-variant</span>: <span style="color: #99cefa;">속성;</span></span>

<table>
<tbody>
<tr>
<td>normal</td>
<td>텍스트 변환 X</td>
</tr>
<tr>
<td>small-caps</td>
<td>텍스트 변환 O</td>
</tr>
</tbody>
</table>

 

```css
<style>
      .variant {
        font-variant: small-caps;
      }
</style>
  <body>
    <p>Lorem ipsum dolor sit.</p>
    <p class="variant">Lorem ipsum dolor sit.</p>
  </body>
```

```html demo
<style>
      .variant {
        font-variant: small-caps;
      }
    </style>
  </head>
  <body>
    <p>Lorem ipsum dolor sit.</p>
    <p class="variant">Lorem ipsum dolor sit.</p>
  </body>
```

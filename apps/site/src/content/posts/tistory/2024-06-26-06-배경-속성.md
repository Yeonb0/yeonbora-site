### 배경 : 요소의 배경을 의미한다

1\) background-color : 요소의 배경에 색상

```css
div{
  width: 160px;
  height: 120px;
  background-color:red;
}
```

  - 반드시 배경의 크기를 지정해야함

 

2\) background-image : 요소의 배경에 이미지

```css
div{
  width: 160px;
  height: 120px;
  background-image: url('이미지 링크');
}
```

  - 반드시 배경의 크기를 지정해야함

  - 요소의 배경이 삽입 이미지 보다 작을 때 : 원본 이미지가 잘린다

  - 요소의 배경이 삽입 이미지 보다 클 때 : 배경 너비에 맞추기 위해 반복되어 채워진다

 

3\) background-repeat : 반복하려는 속성 변경할 때 사용

<table>
<tbody>
<tr>
<td>no-repeat</td>
<td>이미지 반복 X</td>
</tr>
<tr>
<td>repeat-x</td>
<td>가로 방향으로 반복</td>
</tr>
<tr>
<td>repeat-y</td>
<td>세로 방향으로 반복</td>
</tr>
<tr>
<td>repeat</td>
<td>가로, 세로 방향으로 반복</td>
</tr>
<tr>
<td>round</td>
<td>이미지를 반복하되, 이미지가 요소에 딱 맞도록 크기 자동 조정</td>
</tr>
<tr>
<td>space</td>
<td>이미지가 잘리지 않도록 반복</td>
</tr>
</tbody>
</table>

```css
div{
      width:320px; /* 원본 이미지보다 2배 크게 설정 */
      height:120px;
      background-image:url('images/coffee.jpg');
      background-repeat:no-repeat;
      border:1px solid black; /* 요소의 넓이가 잘 보이게 테두리 설정 */
    }
```

 

4\) background-size : 이미지 크기 지정해서 처리

<table>
<tbody>
<tr>
<td>auto</td>
<td>이미지 크기 유지</td>
</tr>
<tr>
<td>cover</td>
<td>이미지 가로 세로 비율 유지하며 확대, 축소해 꽉 채움</td>
</tr>
<tr>
<td>contain</td>
<td>이미지 가로 세로 비율 유지하며 배경 요소 안에 들어가도록 확대, 축소</td>
</tr>
<tr>
<td>&#x3C;너비 높이></td>
<td>이미지 크기 직접 지정</td>
</tr>
</tbody>
</table>

  - contain 은 한 부분이 가득 차면, 나머지는 반복해서 채운다.

```css
div{
      width:80px; /* 원본 이미지보다 1/2 작게 설정 */
      height:60px; /* 원본 이미지보다 1/2 작게 설정 */
      background-image:url('images/coffee.jpg');
      background-size:80px 60px; /* 너비와 높이를 80px, 60px로 지정 */
    }
```

 

5\) background-position : 삽입하려는 이미지의 위치 결정

```css
background-position: <x 위치> <y 위치>;
```

  - 1개 입력 시 : 지정한 값 x축 값, y축 값은 center

<table>
<tbody>
<tr>
<td>x</td>
<td>left, center, right</td>
<td>가로 방향 위치 지정</td>
</tr>
<tr>
<td>y</td>
<td>top, center, bottom</td>
<td>세로 방향 위치 지정</td>
</tr>
<tr>
<td>공통 </td>
<td>px, rem, em, %</td>
<td>위치 직접 지정</td>
</tr>
</tbody>
</table>

 

  - size를 cover , position을 center로 하면 이미지가 정중앙에 있는 것 처럼 보인다.

 

6\) background-attachment : 이미지를 스크롤할때 이미지 작동 방식

<table>
<tbody>
<tr>
<td>local</td>

</tr>

</tr>

</tr>
</tbody>

7\) background 속성 한번에 지정

```css
background: <color> <image> <repeat> <position> / <size> <attachment>
```

  - 한번에 쓰는 것보단 따로 쓰는 것을 권장한다.

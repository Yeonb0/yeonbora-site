### 1. while 반복문

  - 특정 조건 주고, 그 조건 만족하는 동안 계속해서 반복하는 구조 

```cpp
#include <stdio.h>

int main(){
  int num=0;
  while(num<5){
    printf("Hello World! %d \n",num);  // 5번 반복
    num++;
  }

  return 0;
}
```

  - 반복의 조건을 무너뜨리기 위한 최소한의 연산 필요

  - 반복의 대상이 하나의 문장이라면 중괄호 생략 가능

```cpp
while(num<5)
    printf("Hello World! %d \n",num++);
```

  - while (1) 일시 무한 루프 형성. break; 로 빠져나올 수 있도록 만들어야 함

  - 중첩 가능

---

### 2. do \~ while 반복분

  - 반복 영역 최소 한번 시행

  - while 끝에 세미콜론; 필수

```cpp
#include <stdio.h>

int main(){
  int total=0, num=0;

  do{
    printf("정수 입력(0 to quit): ");
    scanf("%d", &num);
    total+=num;
  } while(num!=0);
  printf("합계: %d\n", total);

  return 0;
}
```

---

### 3. for 반복문 

  - 가장 많이 사용

```cpp
// for( 초기식 ; 조건식 ; 증감식)

for(int num=0; num<3; num++){
  printf("Hi! \n);
}
```

  - 초기식 : 반복을 위한 변수의 선언 및 초기화

  - 조건식 : 반복의 조건 검사, 비워지면 무한 루프 형성

  - 증감식 : 반복의 조건을 '거짓'으로 만드는 증가 or 감소 연산  

  - 반복의 횟수가 정해진 경우라면 가장 적절

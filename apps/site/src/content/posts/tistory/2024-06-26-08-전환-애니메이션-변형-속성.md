### 1. 전환 속성 : 전환 효과가 일어날 때 

1\) transition-property : 전환 효과 적용 대상 속성 지정

<table>
<tbody>
<tr>
<td>none </td>
<td>지정 X</td>
</tr>
<tr>
<td>all</td>
<td>모든 속성</td>
</tr>
</tbody>
</table>

 

```css
transition-property: background-color, color, width;
```

 

2\) transition-duration : 전환 효과 지속 시간. s(초), ms

  - transition-property & transition-duration은 항상 같이 써야 한다. 하나라도 빠지면 전환 효과 X

```css
transition-property: background-color, color, width;
transition-delay: 1s, 500ms, 2s;  /* 500ms = 0.5초 */
```

 

3\) transition-delay : 전환 효과 지연. 속성값으로 시간

 

4\) transition-timing-function : 전환 효과의 진행 속도

<table>
<tbody>
<tr>
<td>linear</td>
<td>처음 속도와 마지막 속도 일정</td>
</tr>
<tr>
<td>ease</td>
<td>처음에는 빨라지다가 중간부터 느려짐</td>
</tr>
<tr>
<td>ease-in</td>
<td>처음에는 느리다가 완료까지 점점 빨라짐</td>
</tr>
<tr>
<td>ease-out</td>
<td>처음에는 빠르지만 완료까지 점점 느려짐</td>
</tr>
<tr>
<td>ease-in-out</td>
<td>느렸다가 빨랐다가 다시 느려짐</td>
</tr>
<tr>
<td>cubic-bezier(p1, p2, p3, p4)</td>
<td>사용자가 정의한 속도로 진행</td>
</tr>
</tbody>
</table>

```css
<style>
    .container{
      padding:10px;
      color:white;
      border:1px solid black;
    }
    .bar{
      width:100px;
      background-color:red;
      transition-property:width;
      transition-duration:1s;
      margin-bottom:10px;
    }
    .container:hover .bar{
      width:200px;
    }
    .bar:nth-child(1){
      transition-timing-function:linear;
    }
    .bar:nth-child(2){
      transition-timing-function:ease;
    }
    .bar:nth-child(3){
      transition-timing-function:ease-in
    }
    .bar:nth-child(4){
      transition-timing-function:ease-out;
    }
    .bar:nth-child(5){
      transition-timing-function:ease-in-out;
    }
  </style>
<body>
  <div class="container">
    <div class="bar">linear</div>
    <div class="bar">ease</div>
    <div class="bar">ease-in</div>
    <div class="bar">ease-out</div>
    <div class="bar">ease-in-out</div>    
  </div>  
</body>
```

### 2. 애니메이션 속성

1\) 키프레임 정의하기 

  - 시작, 종료 최소 2개의 스타일 정의 해야함. 

```css
  <style>
div{
      width:100px;
      height:100px;
      border-color:red;
      animation-name:bgchange;
      animation-duration:10s;
      animation-fill-mode:forwards;
    }
    @keyframes bgchange{
      0%{background-color:red;}
      25%{background-color:orange;}
      50%{background-color:yellow;}
      100%{background-color:green;}
    }
  </style>

<body>
  <div></div>
</body>
```

```html demo
  <style>
#div2{
      width:100px;
      height:100px;
      border-color:red;
      animation-name:bgchange;
      animation-duration:20s;
    }
    @keyframes bgchange{
      0%{background-color:red;}
      25%{background-color:orange;}
      50%{background-color:yellow;}
      100%{background-color:green;}
    }
  </style>

<body>
  <div id="div2"></div>
</body>
```

 

2\) animation-name : 특정 요소에서 적용할 키 프레임 명 지정

 

3\) animation-duration : 애니메이션 지속 시간 설정. s/ms

 

4\) animation-delay : 애니메이션 실행 지연. s/ms

 

5\) animation-fill-mode : 애니메이션 실행 전과 후 스타일 지정

  - forwards 가장 많이 사용

 

6\) animation-iteration-count : 애니메이션 실행 횟수

  - 숫자, infinite(무한 반복) 가능

 

7\) animation-play-state : 애니메이션의 재생 상태 지정 

<table>
<tbody>
<tr>
<td>paused</td>
<td>일시 정지</td>
</tr>
<tr>
<td>running</td>
<td>실행</td>
</tr>
</tbody>
</table>

  - 자바스크립트와 함께 사용

 

8\) animation-direction : 애니메이션 진행 방향 지정

<table>
<tbody>
<tr>
<td>normal</td>
<td>키프레임에 정의된 시간 순서대로 진행 (from → to)</td>
</tr>
<tr>
<td>reverse</td>
<td>키프레임에 정의된 시간 역으로 진행 (to <span>→<span> from)</span></span></td>
</tr>
<tr>
<td>alternate</td>
<td>홀수 번째 normal, 짝수 번째 reverse</td>
</tr>
<tr>
<td>alternate-reverse</td>
<td>홀수 번째 reverse, 짝수 번째 normal</td>
</tr>
</tbody>
</table>

 

9\) animation-timing-function : 애니메이션 속도 지정

  - transition-timing-function과 동일

 

10\) animation 속성 한번에 지정

```css
animation: <name> <duration> <timing-function> <delay> <iteration-count> <direction> <fill-mode> <play-state>;
```

   - 한 번에 적용하고 싶은 애니메이션 속성만 적어도 ok

### 3. 변형 효과

1\) transform 속성 

<table>
<tbody>
<tr>
<td>translate(x, y)</td>
<td>요소를 현재 위치에서 x, y만큼 이동</td>
</tr>
<tr>
<td>translateX(n)</td>
<td>요소를 현재 위치에서 n만큼 x축으로 이동</td>
</tr>
<tr>
<td>translateY(n)</td>
<td>요소를 현재 위치에서 n만큼 y축으로 이동</td>
</tr>
<tr>
<td>scale(x, y)</td>
<td>요소를 x, y만큼 확대 또는 축소 (1보다 작으면 축소, 크면 확대)</td>
</tr>
<tr>
<td>scaleX(n)</td>
<td>요소를 n만큼 x축으로 확대 또는 축소</td>
</tr>
<tr>
<td>scaleY(n)</td>
<td>요소를 n만큼 y축으로 확대 또는 축소</td>
</tr>
<tr>
<td>skew(xdeg, ydeg)</td>
<td>요소를 x축과 y축으로 xdeg, ydeg만큼 기울임</td>
</tr>
<tr>
<td>skewX(deg)</td>
<td>요소를 deg만큼 x축 방향으로 기울임</td>
</tr>
<tr>
<td>skewY(deg)</td>
<td>요소를 deg만큼 y축 방향으로 기울임</td>
</tr>
<tr>
<td>rotate(deg)</td>
<td>요소를 deg만큼 회전함</td>
</tr>
</tbody>
</table>

 

```css
<style>
    div{
      width:100px;
      height:100px;
      background-color:red;  
      margin:20px;
    }
    div:hover{ 
      transform:skew(30deg, 30deg);
    }
  </style>

<body>
  <div></div>
</body>
```

```html demo

    #div3{

    #div3:hover{

    }
  </style>
</head>

</body>
```

```css

    .container{
      border:1px solid black;
      display:inline-block;
      margin:20px;
    }
    .box{
      width:100px;
      height:100px;
      background-color:red;  
    }
    .box:hover{ /* 마우스를 올리면 회전 */
      transform:rotate(30deg);  /* 오른쪽으로 회전 */
    }
  </style>

<body>
  <div class="container">
    <div class="box"></div>
  </div>
```

2\) transform-origin : 변형 기준점 설정

```css
transform-origin: <x축 위치> <y축 위치>;
```

<table>
<tbody>
<tr>
<td rowspan="3">x축</td>
<td>left</td>
<td>왼쪽을 기준점으로</td>
</tr>
<tr>
<td>center</td>
<td>중앙을 기준점으로</td>
</tr>
<tr>
<td>right</td>
<td>오른쪽을 기준점으로</td>
</tr>
<tr>
<td rowspan="3">y축</td>
<td>top</td>
<td>위쪽을 기준점으로</td>
</tr>
<tr>
<td>center</td>
<td>중앙을 기준점으로</td>
</tr>
<tr>
<td>bottom</td>
<td>아래쪽을 기준점으로</td>
</tr>
</tbody>
</table>

```css
<style>
    .container{
      border:1px solid black;
      display:inline-block;
      margin:20px;
    }
    .box{
      width:100px;
      height:100px;
      background-color:red;  
    }
    .box:hover{ 
      transform:rotate(30deg);  /* 오른쪽으로 회전 */
      transform-origin:top left; /* 왼쪽 위 모서리를 기준점으로 지정 */
    }
  </style>

<body>
  <div class="container">
    <div class="box"></div>
  </div>
</body>
```

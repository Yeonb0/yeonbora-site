### 1. if 문

```cpp
if(조건){
	조건 일치 시 실행할 것
} else {
	조건 일치 안할 시 실행할 것
}
```

```cpp
if(조건1){
	조건 1 만족 시 실행
} else if(조건2){
	조건 2 만족 시 실행
} else if(조건3){
    조건 3 만족 시 실행
} else {
	모든 조건 만족 안할 시 실행
}
```

### 2. 조건 연산자 : 삼항 연산자

```cpp
int result = (num1>num2) ? (num1) : (num2);

// num1 > num2 일떄
result = num1;

// num1 <= num2 일때
result = num2;
```

 

(조건) ? data1 : data2;

조건이 참 → data1

조건이 거짓 → data2

### 3. 반복 생략과 탈출

1\) break : 가장 가까이 감싸고 있는 [[반복문]] 빠져나옴

```cpp
while(1){
    sum+=num;
    if(sum>5000) 
      break;  // break문 실행! 반복문 탈출
    num++;
  }
```

 

2\) continue : 실행중 위치와 상관없이 반복문 조건검사 위치로 이동 (continue 이후는 생략)

```cpp
for(num=1;num<20;num++){
    if(num%2==0 || num%3==0)
      continue;  // 아래 printf 생략
    printf("%d ",num);
  }
```

### 4. switch 문과 goto 문

1\) [[switch]]

```cpp
 int num;
  printf("1이상 5이하의 정수 입력: ");
  scanf("%d",&num);

  switch(num){
    case 1:
      printf("1은 ONE\n");
      break;
    case 2:
      printf("2는 TWO\n");
      break;
    case 3:
      printf("3은 THREE\n");
      break;
    case 4:
      printf("4는 FOUR\n");
      break;
    case 5:
      printf("5는 FIVE\n");
      break;
    default:
      printf("I don't know! \n");
  }
```

 

  - switch (n) : n 값에 따라서 실행 영역 결정

  - break를 안 넣으면 이후 case 모두 시행.

  - default : 어떤 경우에도 속하지 않을 때

 

2\) [[goto]]

  - 가급적 사용 X 

```cpp
if(num==1)
    goto ONE;
  else if(num==2)
    goto TWO;
  else
    goto OTHER;

  ONE:
    printf("1을 입력하셨습니다! \n");
    goto END;
  TWO:
    printf("2를 입력하셨습니다! \n");
    goto END;
  OTHER:
    printf("3 혹은 다른 값을 입력하셨습니다! \n");
    goto END;
  END: 
    return 0;
```

### 2. 자료형

#### 1) 기본 자료형 : 문자, 숫자, 논리, undefined, null, Symbol

  - 문자열 : 큰 따옴표 or 작은 따옴표로 둘러싸인 값

```javascript
let string1 = "Hello world!";
let string2 = 'Hello world!';
```

    → 시작과 끝 따옴표는 동일해야함

  - 문자열 연결 연산자

```javascript
let string = '문자열은 큰따옴표(")나' + "작은따옴표(')로 감싸야 합니다";
```

 

  - 이스케이프 문자

<table>
<tbody>
<tr>
<td>\'</td>
<td>작은 따옴표</td>
</tr>
<tr>
<td>\"</td>
<td>큰 따옴표</td>
</tr>
<tr>
<td>\n</td>
<td>줄 바꿈</td>
</tr>
<tr>
<td>\t</td>
<td>수평 탭</td>
</tr>
<tr>
<td>\\</td>
<td>역슬래시</td>
</tr>
</tbody>
</table>

 

  - 템플릿 문자열 : \`으로 문자열 정의

    → Enter 입력시 줄 바꿈 적용

    → ${ } 문법으로 문자열에 변수, 식을 넣을 수 있음

```javascript
let dan = 3;
let gugu = 8;
let string = `${dan} X ${gugu} = ${dan * gugu}`;
```

 

  - 숫자형 : 정수, 실수 구분 X 

    → 실수 사용시 오차 조심!

 

  - 논리형 : true / false 두 값만 존재

  - undefined : 변수를 선언하고 데이터를 할당하지 않았을 때 자동 할당

  - null : 변수, [[상수]] 선언 후 비울 때 할당

#### 2) 참조 자료형 : 객체

  - [[배열]] : 복수의 데이터 정의

```javascript
let studentScore = [80, 90, 70, 60];  // 국어, 영어, 수학, 과학 점수
```

    → 요소 : 배열로 정의한 데이터

    → 인덱스 : 배열 요소에 접근시 사용, 0부터 시작

    → 배열은 모든 자료형 저장 가능. 비어있는 배열도 정의 가능

 

  - [[객체]] 리터럴 

```javascript
let studentScore = {
  koreanScore:80,
  englishScore:90,
  mathScore:70,
  scienceScore:60
};
'

console.log(studentScore.koreanScore);       // 80
console.log(studentScore.['englishScore']);  // 90
```

<table>
<tbody>
<tr>
<td>&#x26;&#x26;</td>
<td>x&#x26;&#x26;y</td>
<td>x가 참이면 y 반환, 거짓이면 x 반환</td>
</tr>
<tr>
<td>||</td>

<td>x가 참이면 x 반환, 거짓이면 y 반환</td>
</tr>
<tr>

```javascript

false || false;  		  // false
false || "cat";			  // "cat"
"" || "cat";			  // "cat"
"dog" || "cat"; 		  // "dog"
```

#### 6) 형 변환

  - 암시적 [[형 변환]]

```javascript
const result = 10 + "10";
console.log(result); // 1010

// 내부적으로 숫자형 데이터를 문자열로 형 변환
```

 

  - 명시적 형 변환

```javascript
let num = 10;
let strNum = "10";
String(num);  // 숫자형 -> 문자형
```

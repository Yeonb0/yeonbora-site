### 1. 미디어 쿼리

  - 사이트에 접속하는 미디어 티입과 특징, 해상도에 따라 다른 스타일 속성 적용

  - 뷰포트 : 웹 페이지가 접속한 기기에서 보이는 실제 영역 크기

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

 

  - content 속성값

<table>
<tbody>
<tr>
<td>width</td>
<td>뷰포트 너비 설정. 보통 device-width 사용</td>
</tr>
<tr>
<td>height</td>
<td>뷰포트 높이 설정. 잘 사용 X</td>
</tr>
<tr>
<td>initial-scale</td>
<td>뷰포트 초기 배율 설정. 기본 1, 그보다 작으면 축소, 크면 확대</td>
</tr>
<tr>
<td>minimum-scale</td>
<td>뷰포트의 최소 축소 비율 설정. 기본 0.25</td>
</tr>
<tr>
<td>maximum-scale</td>
<td>뷰포트의 최대 확대 비율 설정. 기본 5.0</td>
</tr>
<tr>
<td>user-scalable</td>
<td>뷰포트의 확대 or 축소 가능 여부 설정</td>
</tr>
</tbody>
</table>

### 2. 기본 문법

```css
@media <not/only> <mediatype> and (<media feature>) <and/or/not> (<media feature>){
  /* CSS 코드 */
}
```

 

  - not : 뒤에 오는 모든 조건 부정

  - only : 미디어 쿼리를 지원하는 기기만 적용

  - mediatype : 미디어 쿼리가 적용될 타입 명시. 생략 가능. 기본값 all. 생략 X 시 다음에 반드시 and 와야 함

<table>
<tbody>
<tr>
<td>all</td>
<td>모든 기기</td>
</tr>
<tr>
<td>print</td>
<td>인쇄 장치</td>
</tr>
<tr>
<td>screen</td>
<td>컴퓨터 화면 장치, 스마트 기기</td>
</tr>
<tr>
<td>speech</td>
<td>스크린 리더기</td>
</tr>
</tbody>
</table>

 

  - mediafeature : 미디어 쿼리가 적용될 미디어 조건

<table>
<tbody>
<tr>
<td>min-width</td>
<td>화면 너비</td>
<td>미디어 쿼리가 적용될 최소 너비</td>
</tr>
<tr>
<td>max-width</td>
<td>화면 너비</td>
<td>미디어 쿼리가 적용될 최대 너비</td>
</tr>
<tr>
<td>orientation</td>
<td>portrait</td>
<td>세로 모드, 세로 높이 > 가로 너비</td>
</tr>
<tr>
<td>orientation</td>
<td>landscape</td>
<td>가로 모드, 가로 너비 > 세로 높이</td>
</tr>
</tbody>
</table>

 

```css
@media only screen and (min-width:360px) and (max-width:720px){
  /* CSS 코드 */
}
```

  → 미디어 쿼리 적용 가능 기기, 화면 장치, 뷰포트 너비 최소 360px, 최대 720px 일때 CSS 코드 실행

### 1. 조건문

#### 1) if, else, else if

```javascript
if(조건식){
  // 조건식이 참이면 실행
} else {
  // 조건식이 거짓이면 실행
}
```

```javascript
if(조건식1){
  // 조건식1이 참일 때 실행
} else if(조건식2){
  // 조건식2가 참일 때 실행
} else {
  // 조건식이 모두 거짓이면 실행
}
```

 

  - if문은 중첩 가능하다

 

#### 2) switch 

```javascript
let food = "melon";
switch(food){
  case "melon":
  case "apple":
  case "banana":
  	console.log("fruit");
    break;
  case "carrot":
    console.log("vegetable");
    break;
  default:
  	console.log("It's not fruits and vegetables.");
    break;
}
```

  - case문은 조건 일치 시 break 만날때까지 모두 실행

  - case/default 중 하나 이상은 반드시 있어야 함

 

  - 조건이 범위일 때는 if문 / 값이 하나일 때는  switch문

### 2. 반복문

#### 1) while

```javascript
while(조건식){
  // 조건식이 참일 때 반복적 실행
}
```

 

#### 2) do \~ while 

```javascript
do{
  // 블록문
} while(조건식);
```

  - 무조건 한번은 실행

 

#### 3) for 

```javascript
for(초깃값; 조건식; 증감식){
  // 블록문
}
```

  - 중첩 사용 가능

 

  - 배열 사용 시

```javascript
let arr = ["banana","apple","orange"];
for(let i = 0; i < arr.length; i++){
  console.log(arr[i]);
}
```

 

  - for in

```javascript
for(가변수 in <배열/객체 리터럴>){
  // 블록문
}
```

 

```javascript
let obj = {name:"철수", age:"20"};
for(let key in obj){
  console.log(key + ": " + obj[key]);
}

// name: 철수
// age: 20
```

 

#### 4) break & continue

  - break : 반복문 즉시 종료 시 사용

  - continue : 해당 반복 시행만 건너뛸 때 사용

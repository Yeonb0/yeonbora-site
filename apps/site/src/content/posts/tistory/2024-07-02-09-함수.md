### 1. 함수 정의 하기

```cpp
int main(void){


}

// 반환형 함수명 (입력형){
```

 

  - 값의 반환은 return 으로. 반환형이 void 일시 생략 가능

  - return : 함수 빠져나가기 / 값 반환

  - 함수는 main 함수 이전에 작성되어야 한다

```cpp
int Increment(int);

int main(){
  // main 함수
}

int Increment(int n){
  n++
  return n;
}
```

  - 미리 선언한 후, 나중에 정의 할 수 있다.

### 2. 함수의 변수들

#### 1) 지역 변수

  - 중괄호 내에 선언되는 변수. 

  - 선언된 지역 내에서만 유효. 지역 벗어날 시 자동으로 소멸

  - 선언된 지역 다를 시 이름 같아도 ok

  - 반복문 / 조건문에도 선언 가능

  - 매개 변수 → 지역 변수 (역 X)

 

#### 2) 전역 변수 

  - 중괄호 밖에 선언되는 변수.

  - 기본 0으로 초기화

  - 어디서든 접근 가능

  - 동일한 이름의 지역 변수는 같은 이름의 전역 변수를 가린다

  - 최대한 적게 쓰는 것을 추천!

 

#### 3) static 변수 

  - 선언된 함수 내에서만 접근 가능 (지역 변수 특성)

  - 1회 초기화 후 종료 시까지 메모리 공간에 존재 (전역 변수 특성)

  - 기본 0으로 초기화

 

#### 4) register 변수

  - 연산 속도가 빠른 변수로 선언

```cpp
#include <stdio.h>
int num1;    // 전역변수, 자동 0 초기화

void Func(void){
  static int num2;  // static 변수, 자동 0 초기화
  int num3;  // 지역변수, 쓰레기값, 함수 나갈시 소멸
}

int main(){
		register num4=0;  // register 변수, 빠르게 접근 가능
}
```

### 3. 재귀함수

  - 함수 내에서 자기 자신은 다시 호출하는 함수

  - 탈출 조건이 존재해야 한다

```cpp
#include <stdio.h>

void Recursive(int num){
  if(num<=0)     // 재귀의 탈출 조건
    return;      // 재귀의 탈출!
  printf("Recursive call! %d\n", num);
  Recursive(num-1); 
}

int main(){
  Recursive(5);  // 5번 호출!
  return 0;
}
```

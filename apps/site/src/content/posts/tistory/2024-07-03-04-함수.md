### 1. 함수 : 어떤 목적을 가지고 작성한 코드를 모아 둔 블록문

#### 1) 함수 선언문

```javascript
function gugudan(){
  for(let i=1;i<=9;i++){
    console.log(`3 * ${i} = ${3*i}`);
  }
}  // 함수 작성

gugudan();  // 함수 실행
```

 

#### 2) 함수 표현식

```javascript
const 변수명 = function(){};    // 익명 함수
const 변수명 = function 식별자(){}    // 네이밍 함수
```

```javascript
const gugudan = function gugudan(){
  for(let i=1;i<=9;i++){
    console.log(`3 * ${i} = ${3*i}`);
  }
};     // 함수 정의

gugudan();    // 함수 호출
```

  - function 키워드 다음 식별자로 호출 불가. const 뒤 변수명으로 호출해야 함!

 

#### 3) 화살표 함수

```javascript
const gugudan = () => {
  for(let i=1;i<=9;i++){
    console.log(`3 * ${i} = ${3*i}`);
  }
};    // 함수 정의

gugudan();    // 함수 호출
```

  - 가장 많이 사용하는 방법

### 2. 함수 기능 확장

#### 1) 매개변수, 인수

  - 매개변수 : 함수를 정의할 때 외부에서 전달하는 데이터를 함수에저 받을 수 있도록 정의하는 변수

  - 인수 : 함수 호출 시 소괄호 안의 전달하고 싶은 데이터

```javascript
const 함수명 = (매개변수1, 매개변수2) => {

};    // 함수 선언

함수명(인수1, 인수2);    // 함수 호출
```

 

  - 매개 변수는 개수 제한이 없다. but 최소한으로 정의하는 것이 좋음

  - 매개변수 O 인수 X  →  undefined 값 할당

  - 매개변수 X 인수 O  →  오류 X but 인수 값 이용 불가

 

  - 기본값 할당

```javascript
function sum(a=10, b=10){
  console.log(a, b);
}

sum();    //  10, 10 출력
```

 

#### 2) return 

  - 함수 외부로 데이터 반환, 반환값

```javascript
function sum(num1, num2){
  let result = num1 + num2;
  return result;
}

const result = sum(10,20);
console.log("out: " + result);  // out: 30
```

  

  - 데이터 반환 X시 함수 종료, undefined 반환

  - 화살표 함수에서 { } 생략시 다음 코드는  return 문으로 처리

```javascript
const sum = (num1, num2) => num1+num2;
const result = sum(10,20);    // 30
```

 

#### 3) 스코프

  - 지역 스코프 : 함수 안에서 정의한 블록문만 스코프의 유효 범위

  - 전역 스코프 : 스코프와 상관 없이 모두 참조 가능

  - 블록 스코프 : { } 블록문 기준으로 스코프의 유효 범위. let, const 키워드 변수만 적용

  - 우선 순위 : 지역 > 전역

```javascript
let a = 10;
{
  let b = 20;
  console.log(`코드 블록 내부 a: ${a}`);  // 10
  console.log(`코드 블록 내부 b: ${b}`);  // 20
}
console.log(`코드 블록 외부 a: ${a}`);  // 10
console.log(`코드 블록 외부 b: ${b}`);  // 참조 오류
```

 

#### 4) 호이스팅 

  - 코드를 선언과 할당으로 분리해 선언부를 스코프 최상위로 끌어올리는 것

  - 변수 : var 적용 O / let, const 적용 X

 

  - 함수 : 선언문 적용 O / var 표현식, 화살표 함수 적용 O (함수가 아니다 오류)

 

#### 5) 즉시 실행 함수

  - 정의하며 동시에 실행

```javascript
(function init(){
  console.log("initialized!");
})();
```

  - 한 번 실행 후 메모리에서 삭제. init 식별자 재사용 가능

 

```javascript
(function sum(a,b){
  console.log(a + b);
})(10,20);  // 30
```

  - 매개 변수 있어도 정의, 실행 가능

#### 1. 배열이란

  - 다수의 데이터를 저장 & 처리

  - 자료형 배열이름\[길이정보];

  - 길이정보는 가급적 상수로!

```cpp
int arr1[7];    // 길이 7인 int형 1차원 배열
double arr2[13];    // 길이 13인 double형 1차원 배열
```

 

  - 인덱스로 접근 가능. 0부터 시작 // 반복문으로 순차적 접근 가능

  - 선언과 동시에 초기화 가능

```cpp
int arr1[5] = {1,2,3,4,5};  // 순서대로 1,2,3,4,5 초기화

int arr2[] = {1,2,3,4,5,6,7};  // 자동으로 길이 7 삽입

int arr3[5] = {1,2};  // 1,2,0,0,0 으로 초기화
```

#### 2. 배열과 문자열

  - 문자열은 char 배열을 통해 저장 

  - 문자열 끝에 null(\0)문자 자동 삽입

  - scanf로 문자열 입력

```cpp
int main(){
  char str[50];
  scanf("%s", str);  // 문자열 입력 받아서 str에 저장
  printf("입력 받은 문자열: %s", str);  // 문자열 출력
  
  return 0;
}
```

  - 입력 받을때 & 연산자 삽입 X 

  - null 문자의 유무로 문자열 여부 판단

  - null 문자의 위치로 문자열 끝 판단

  - null 문자 아스키 코드 0 / 공백 문자 아스키 코드 32 → 서로 다르다!

```cpp
str[8] = '\0';
str[8] = 0;

// 두 문장은 동일하다
```

  - scanf 는 공백을 기준으로 데이터를 구분한다. 따라서 문장 입력에는 적절치 않음.

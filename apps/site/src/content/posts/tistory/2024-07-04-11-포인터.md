#### 1. 포인터와 연산자

  - [[Pointer|포인터]] : [[메모리]]의 주소 값 저장

```cpp
int main(){
  int num=7;
  int * pnum;  // 포인터 변수 선언
  pnum = &num; // num 주소 값을 포인터 변수 pnum 에 저장
}
```

 

  - 선언 : 변수명 앞에 \*붙이기

  - & : [[변수]]의 주소값 반환 (주소값 반환)

  - \* : 포인터가 가리키는 메모리 참조 (저장된 값 반환)

  - 포인터 값이 지정하는 변수 변경 가능

  - 포인터는 선언하면 초기화 해야한다! 

```cpp
int *ptr=NULL;
```

  - 널 포인터 : 아무 곳도 가리키지 않음

#### 2. 포인터와 배열

  - [[배열]]의 이름 = 포인터, but 그 값 **변경 불가**한 상수형 포인터

  - 포인터를 배열의 이름처럼 사용 가능

```cpp
int arr[3] = {15,25,30};
int *ptr1 = &arr[0];
int *ptr2 = arr;

// ptr1, ptr2는 동일
```

 

  - 포인터 대상 증가/감소 연산 → 자료형의 [[바이트|byte]] 값 만큼 증감

```cpp
*(++ptr)=20;  // ptr에 저장된 값 자체를 변경
*(ptr+1)=20;  // ptr에 저장된 값 변경 X
```

  - arr\[i] == \*(arr+i)

```cpp
char str1[] = "My String";  // 변수 형태의 문자열 (값 변경 가능)

char *str2 = "My String";   // 상수 형태의 문자열 (값 변경 불가)
```

  - [[포인터 배열]] : 포인터 변수로 이루어진 배열 

```cpp
int *arr[20];  // 길이가 20인 int 포인터 배열 
int num1=10, num2=20, num3=30;

*arr[0] = &num1;

char *strArr[3]={"Simple", "String", "Array"};  // 문자열 배열
```

#### 3. 포인터와 함수

  - 함수의 인자로 배열 전달 방법

```cpp
// 1)
void ShowArray(int *arr, int len){  // 배열의 포인터, 길이 전달

}

// 2)
void ShowArray(int arr[], int len){  // 배열의 이름, 길이 전달


}
```

  - 함수 내에서는 인자로 전달된 배열 길이 계산 불가. 직접 전달해야 함!

 

1\) [[Pass-by-Value|Call-by-value]] : 값을 전달하는 형태

  - 함수 안에서 값 변경해도 복사된 매개변수 값만 변경

2\) [[Pass-by-Reference|Call-by-reference]] : 주소 값을 전달하는 형태 

  - 함수 안에서 값 변경시 main 함수 값도 변경

 

  - const

```cpp
// 1)
const int *ptr = &num;
```

  - \*ptr 을 이용해 num 값 변경 못하도록 막음

 

```cpp
// 2)
int *const ptr = &num;
```

  - \*ptr이 가리키는 변수 변경 불가

 

  - 두 const 선언은 동시에 사용 가능하다!

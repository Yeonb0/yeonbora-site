### 1. 객체와 객체 속성

#### 1) 객체 : 키(key)와 값(value)으로 구성된 속성의 집합

  - 리터럴 방식 : { } 으로 [[객체]] 생성

```javascript
const person = {};  // 빈 객체

const person = {
  name = {  // 객체
    firstName:"Gildong",
    lastName:"Hong"
  },
  age: 20,
  isAdult: true,
  printInfo:funtion(){  // 메서드
    console.log("printInfo");
  }
  address: [15, 200, 17] // 배열
};
```

  - 객체 안 객체, 메서드(함수), [[배열]] 가능 

 

#### 2) 객체 속성 접근법

a. 대괄호 연산자

```javascript
// 대괄호 접근 

const person = {
  name: "Hong Gildong",
  age: 20;
};

console.log(person["name"]);  // Hong Gildong
console.log(person["age"]);  // 20
```

  - 객체명\["키"]  → 이때 키는 따옴표로 감싼 문자열 형태로 작성.

```javascript
const person = {
  name = {  // 객체
    firstName:"Gildong",
    lastName:"Hong"
  },
  printInfo:funtion(){  // 메서드
    console.log("printInfo");
  }
  likes: ["apple", "samsung"];
};

// firstName 접근
console.log(person["name"]["firstName"]);  // Gildong

// 배열 접근
console.log(person["likes"][1]);  // samsung

// 함수 접근
console.log(person["printInfo"]());  // printInfo
```

 

b. 마침표 연산자

```javascript
const person = {
  name = {  // 객체
    firstName:"Gildong",
    lastName:"Hong"
  },
  printInfo:funtion(){  // 메서드
    console.log("printInfo");
  }
  likes: ["apple", "samsung"];
};

console.log(person.name.lastName);  // Hong
console.log(person.likes[0]);  // apple
console.log(person.printInfo());  // printInfo
```

  - 객체의 키에 공백이 있으면 대괄호만 사용 가능

 

####  3) 객체 속성 / 값 변경

  - 값 변경 : 키로 접근해 값 재할당

```javascript
const person = {
  name: "Hong Gildong"
};

person.name = "Kim";

console.log(person.name);  // Kim
```

 

  - 속성 추가 : 객체 속성에 없을 경우 키와 값 추가

```javascript
const person = {};
console.log(person); // {}

person.name = "Hong Gildong";  // 속성 name, 값 Hong Gildong 추가
console.log(person); // {name: "Hong Gildong"}
```

  - 함수, 배열, 객체일 때도 값 변경 / 추가 가능

 

  - 속성 삭제 : 속성 접근시 앖에 delete 키워드

```javascript
const person = {
  age: 20;
};

delete person.age;
console.log(person);  // {}
```

 

#### 4) 객체의 데이터 관리

  - 객체 자료형 : 참조(reference)

 

a. 기본 자료형 : 깊은 복사

  - [[변수]]에 데이터 할당시 데이터 그 자체가 할당 

  - 복사한 값을 재할당할 시 한쪽 데이터 변경해도 서로 영향 X

```javascript
let num = 10;
let copyNum = num;
num = 20;  // num 재할당

console.log(num); // 20
console.log(copyNum); // 10 -> 변경 X
```

 

b. 참조 자료형 : 얕은 복사

  - 변수 공간에 데이터 할당 X, 데이터 위치 [[메모리]] 주소 값만 할당

  - 데이터 재할당 불가 / but 값 변경, 속성 추가 가능

```javascript
const person = {
  age: 20;
};

person = {
  age: 30
}; // 오류 발생. 데이터 재할당 불가


person.age = 30; // 가능. 값 변경은 가능
```

```javascript
const person = {
  name: "Kim";
};

const copyPerson = person;  // 객체를 복사
person.name = "Hong";  // 객체 값 변경

console.log(copyPerson.name);  // Hong 
// 복사된 객체에서도 값 변경
```

   - 한쪽 데이터 변경시 다른 쪽 데이터도 변경

```cpp
int arr1[3][4]; // 세로가 3, 가로가 4인 int 형 2차원 배열

double arr2[3][3][3]; // 가로, 세로, 높이가 3인 double 형 3차원 배열
```

  - [[배열]]의 크기 : 가로 X 세로 X 자료형 

  - 다차원 배열이라도 [[메모리]] 상에선 1차원으로 존재

  - 자료형 크기 만큼 차이 존재

 

  - 선언과 동시에 초기화 하기

```cpp
int arr[3][3] = {
  {1,2,3},
  {2,3,4},
  {3,4,5}
};
```

 

  - 요소 모자라게 초기화할시 0으로 부족한 부분 0으로 초기화

  - 배열의 크기 둘 다 안 알려줌 → 오류 발생

  - 2차원 배열 선언시 배열의 세로 길이만 생략 가능

  - 3차원 배열 = 2차원 배열이 여러개 모인 형태

### 2. 이중 포인터

  - [[Pointer|포인터]]를 가리키는 포인터

```cpp
int num;
int *ptr &num;
int **dptr = &ptr;

*dptr // 포인터 변수 ptr
**dptr // 변수 num
```

 

  - int [[변수]] Swap 함수 : int 변수의 포인터(주소 값) 전달

  - int 포인터 변수 Swap 함수 : int 변수의 이중 포인터 (포인터의 주소 값) 전달

 

#### 1) 포인터 배열

```cpp
int num1=10, num2=20, num3=30;
int *ptr1=&num1, *ptr2=&num2, *ptr3=&num3;

int * ptrArr[]={ptr1, ptr2, ptr3};
int **dptr = ptrArr;
```

  - 배열의 요소가 포인터인 배열

#### 2) 배열 포인터

```cpp
int (*ptr)[4];
int arr[4][];
```

  - 가로 길이가 4인 int 형 2차원 배열

  - 2차원 배열을 가리킴!

  - arr\[i] = \*(arr+i)

### 3. 다차원 배열과 포인터

  - 2차원 배열 arr2d\[3]\[3] 의 첫째 요소 표현법 

```cpp
sizeof(arr2d)    // 36, 배열 전체 크기 반환
sizeof(arr2d[0]) // 12, 각 행의 크기 반환
```

  → 두 표현은 서로 다르다 

  - 2차원 배열 이름을 대상으로 증가/감소 연산 할 경우, '행' 단위로 증감

 

```cpp
int (*ptr)[4];  // 포인터 연산 시 4칸씩 건너뛰는 포인터

int arr[3][4];  // 위 포인터가 가리킬 수 있는 배열
```

 

  - 2차원 배열 함수인자 전달 

```cpp
void SimpleFunc(int parr[][7], int arr[][5]);
void SimpleFunc(int (*parr)[7], int (*arr)[5]);

// 동일한 표현
```

### 4. 기타 포인터

#### 1) 함수 포인터

  - 함수가 저장된 메모리 공간의 주소값 

```cpp
int SimpleFunc(int num1, int num2);

int (*fptr)(int, int);
// 반환형이 int, 매개변수가 int, int 인 함수 포인터

fptr = SimpleFunc;

fptr(3,4);  // SimpleFunc(3,4) 와 동일
```

  - 매개변수의 선언으로 함수 포인터 변수가 올 수 있다

```cpp
int WhoIsFirst(int age1, int age2, int(*cmp)(int n1, int n2));
```

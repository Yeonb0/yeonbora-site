### 1. 폼 조작하기

#### 1) form 태그 선택하기

  - forms 속성 사용하기

  - name 속성 사용하기 : 추천

```html
  <form name="frm1">
    <input type="text">
  </form>
  <form name="frm2">
    <input type="text">
  </form>
  <form name="frm3">
    <input type="text">
  </form>
```

```javascript
document.frm1;  // form 태그의 name 속성값이 frm1인 노드
document.frm3;  // form 태그의 name 속성값이 frm3인 노드
```

 

#### 2) 폼 요소 선택하기

  - elements 속성 사용 

  - name 속성 값 사용 

```javascript
document.frm1.elements[0]; // 0번 인덱스 노드
document.frm1.elements['uname'];  // form 요소 노드의 하위 노드 중에서 name 속성값이 uname인 노드

document.frm1.age;  // elements 속성 생략 후 name 속성값으로 바로 접근
```

 

#### 3) 폼 요소 입력값 다루기

```javascript

document.frm.pw.value;
```

  - 여러 줄 입력 요소 다루기 : 해당 요소 노드에서 value 속성 사용

  - 체크박스/라디오버튼 다루기 : [[반복문]]으로 체크박스/라디오 버튼 노드에 접근 뒤 checked 속성 확인, 있으면 value 속성 사용

```html
  <form>
    <label><input type="checkbox" value="apple">사과</label>
    <label><input type="checkbox" value="banana">바나나</label>
    <label><input type="checkbox" value="orange">오렌지</label>
    <label><input type="checkbox" value="melon">멜론</label>
  </form>
```

```javascript
const checkboxEls = document.querySelectorAll("[type='checkbox']");
for(let i = 0; i<checkboxEls.length; i++){
  if(checkboxEls[i].checked === true){
    console.log(checkboxEls[i].value);
  }
}
```

#### 2) 이벤트 등록하기

  -  인라인 방식으로 [[Event|이벤트]] 등록 : HTML 코드 내의 script 이용

```html
  <form>
    <input type="text" onfocus="focusEvent()" onblur="blurEvent()">
  </form>
  <script>
    function focusEvent(){
      console.log("focus on");
    }
    function blurEvent(){
      console.log("focus out");
    }
  </script>
```

 

  - 프로퍼티 리스너 방식 

```html
  <button>클릭</button>
  <script>
    const btnEl = document.querySelector("button");
    btnEl.onclick = function(){
      alert("click");
    }

    /*  화살표 함수 방식
    btnEl.onclick = () => {
      alert("arrow click");
    }
    */
    /* 
    btnEl.onclick = clickEvent;
    function clickEvent(){
      alert("click");
    }
    */
  </script>
```

 

  - 이벤트 등록 메서드 : 가장 권장하는 방식

```javascript
<노드>.addEventListener("<이벤트 타입>", <이벤트 함수>);
```

 

```html
  <button>클릭</button>
  <script>
    const btnEl = document.querySelector("button");
    const clickEvent = () => {
      alert("button Click");
    }
    btnEl.addEventListener("click", clickEvent);
  </script>
```

  - 함수가 addEventListener() 메서드보다 위에 작성되어야 함.

#### 2) 이벤트 취소하기 

  - preventDefault() 메서드 : 기본으로 연결된 이벤트 취소

```html
  <a href="https://www.naver.com">네이버 이동</a>
  <a href="https://www.daum.net">다음 이동</a>
  <script>
    const aEls = document.querySelectorAll("a");
    for(let i = 0; i < aEls.length; i++){
      aEls[i].addEventListener("click", function(e){
        // 기본 이벤트 취소
        e.preventDefault();
      });
    }
  </script>
```

#### 3) this 키워드

  - 이벤트 함수 내부에서 this 키워드 사용시 이벤트가 발생한 요소 노드 바로 가리킴.

```html
  <p>text-1</p>
  <p>text-2</p>
  <p>text-3</p>
  <script>
    const pEls = document.querySelectorAll("p")
    pEls.forEach((el)=>{
      el.addEventListener("click", function(){
        console.log(this);
        
        if(this.style.color === "red"){
          this.style.color = "black";
        }else{
          this.style.color = "red";
        }
        
      });
    })
  </script>
```

 

  - 이벤트 함수가 화살표 함수면 this 의 범위가 달라짐. [[이벤트 객체]]의 target 속성 사용 해야 함.

```html
 <script>
    const pEls = document.querySelectorAll("p")
    pEls.forEach((el) => {
      el.addEventListener("click", (e) => {
        // console.log(this); // window 객체를 가리킴
        console.log(e.target);
      });
    })
  </script>
```

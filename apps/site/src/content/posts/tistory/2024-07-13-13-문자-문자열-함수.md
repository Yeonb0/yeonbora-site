#### 2. 문자 단위 입출력 함수

  - 문자 출력 함수

```cpp
#include <stdio.h>

int putchar(int c);
int fputc(int c, FILE * stream);

// 호출 성공시 문자, 실패 시 EOF 반환
```

  - fputc 함수는 문자를 전송할 스트림 지정 가능. stdout, 파일 대상 데이터 전송 가능

 

  - 문자 입력 함수

```cpp
#include <stdio.h>

int getchar();
int fgetc(FILE * stream);
```

  - fgetc 함수는 문자를 입력 받을 스트림 지정 가능

 

  - EOF : End Of File. 파일의 끝을 표현하기 위해 정의한 상수. -1로 정의되어 있음

함수 호출 실패 했을 시 / Window에서 Ctrl + Z 입력되었을 시 반환

  → '-1'로 정의되어 있기에 자료형으로 int 사용

 

#### 3. 문자열 단위 입출력 함수

  - 문자열 출력 함수

```cpp
#include <stdio.h>

int puts(const char *s);
int fputs(const char *s, FILE *stream);
// 성공시 음수가 아닌 값, 실패 시 EOF 반한
```

  - puts 함수는 출력의 대상이 stdout 으로 결정

  - puts 함수는 출력 후 자동 개행, fputs 함수는 자동 개행 X

 

  - 문자열 입력 함수

```cpp
#include <stdio.h>

char * gets(char *s);
char * fgets(char *s, int n, FILE * stream);
// 파일에 끝에 도달하거나 함수호출 실패 시 NULL 포인터 반환
```

  - gets는 오류가 발생할 수 있음. 주로 fgets 함수 사용하는 것이 좋음

  - 문자열을 입력 받으면 문자열의 끝에 자동으로 널 문자 추가. 원하는 입력 길이 - 1 만큼만 저장

  - 개행 문자 \n도 문자열의 일부로 포함.

 

#### 4. 표준 입출력과 버퍼

  - 키보드 입력  →  입력 버퍼  → (Enter 입력) →   프로그램 입력

  - 프로그램 출력  →  출력 버퍼  →  모니터 출력

 

  - 출력 버퍼 비우기 : 데이터가 목적지로 이동

```cpp
#include <stdio.h>

int  fflush(FILE * stream);

// 함수 호출 성공 시 0, 실패 시 EOF 반환
```

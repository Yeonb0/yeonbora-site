#### 1. 문자열 길이 반환 : strlen

  - 문자열의 길이 반환. null 문자는 길이에 포함 X 

```cpp
#include <string.h>
#include <stdio.h>

int main(){
  char str[]="1234567";
  printf("%d \n", strlen(str));  // 7이 출력
  
  return 0;
}
```

 

#### 2. 문자열 복사 : strcpy, strncpy

```cpp
#include <string.h>
#include <stdio.h>

int main(){
  char str1[30]="Simple String";
  char str2[30];
  strcpy(str2, str1);  // str1의 문자열을 str2에 복사
  strncpy(str2, str1, sizeof(str2));  // str1의 문자열을 str2에 복사, str1이 길이가 길면 sizeof(str2)만큼만 복사
  
  strncpy(str2, str1, sizeof(str2)-1);
  str2[sizeof(str2)-1]=0;
  // 널 문자가 삽입될 공간 마련 해야 함
```

 

#### 3. 문자열 덧붙이기 : strcat, strncat

```cpp
#include <string.h>
#include <stdio.h>

int main(){
  char str1[30]="First~";
  char str2[30]="Second";
  strcat(str1,str2);  // str1의 문자열 뒤에 str2를 복사
  printf("%s", str1);  // First~Second
  
  strncat(str1, str2, 8); // str2의 문자열 중 최대 8개를 str1의 뒤에 덧불여라
```

  - null 문자는 숫자에 포함되지 않지만, 자동 삽입

 

#### 4. 문자열 비교 : strcmp, strncmp

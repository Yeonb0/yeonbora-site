#### 2. 메모리의 동적 할당

  - malloc : 메모리 공간 할당

  - free : 할당된 메모리 공간의 해체

```cpp
#include <stdlib.h>

void * ptr1 = malloc(4);  // 4바이트가 힙 영역에 할당
void * ptr2 = malloc(12);  // 12바이트가 힙 영역에 할당

free(ptr1);  // ptr1이 가리키는 4바이트 메모리 공간 해제
free(ptr2);  // ptr2가 가리키는 12바이트 메모리 공간 해제
```

 

    - malloc함수는 void 포인터형 → 형 변환해서 접근해야 한다

```cpp
int *ptr = (int *)malloc(sizeof(int));

int *ptr2 = (int *)malloc(sizeof(int)*7);
```

  - 메모리 공간 할당 실패 시 NULL 반환

  - malloc 후 free를 해주는 습관을 들이자!

 

  - calloc 함수 : 배열형으로 공간 할당, 자동 0으로 초기화

  - realloc 함수 : 힙에 할당된 메모리 공간 확장

```cpp
void * calloc(30, 4);
// 4바이트 크기의 블록 30개 할당

int * arr = (int *)malloc(sizeof(int)*3);  // 길이가 3인 int형 배열 할당
arr = (int *)realloc(arr, sizeof(int)*5);  // 길이가 5인 int형 배열로 확장
```

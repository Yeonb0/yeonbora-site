#### 1. 파일의 분할

  - 컴파일러는 파일 단위로 컴파일 진행

  - 외부에 선언 & 정의 컴파일러에게 전달 : extern

```cpp
extern int num;
// int형 변수 num이 외부에 선언되어 있다

extern void Increment(void);
// 함수가 외부에 정의되어 있다
```

  

  - static 전역 변수 : 외부 파일에서의 접근 허용 X. 

    → 변수의 접근범위를 파일 내부로 제한

  - static 함수 : 파일 내에서만 접근 가능하도록 함수 제한

---

#### 2. 헤더파일

```cpp
#include <stdio.h>  // 표준 헤더파일 포함 시
#include "header.h"  // 프로그래머 정의 헤더파일 포함 시
```

 

  - 절대 경로 사용 X

  - 상대 경로 사용 

```cpp
#include "Release\header0.h"  
// 소스 파일 하위 디렉터리 Release 디렉터리의 파일
#include "..\CProg\header1.h"
// 한 단계 상위 디렉터리의 하위 디렉터리 CProg 디렉터리의 파일
```

  - 기준 : 소스파일의 위치

  - 헤더파일 : 함수 선언

  - 소스파일 : 함수 정의

 

  - 구조체의 선언 및 정의 : 헤더파일에 삽입

  - but 소스파일 내에서만 사용되면 소스파일에 정의

 

  - 조건부 컴파일을 통해 중복 삽입 해결!

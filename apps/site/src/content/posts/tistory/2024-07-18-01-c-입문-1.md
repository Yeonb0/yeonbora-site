#### 2. 함수 오버로딩 

  - 함수의 이름이 같더라도 매개변수의 선언 형태 다르면 동일한 이름의 함수정의 허용

  - 매개변수의 자료형 또는 개수가 다를 때.

  - 반환형만 다르면 적용 X 

```cpp
void MyFunc(){
  std::cout << "MyFunc(void) called" << std::endl;
}

void MyFunc(char c){
  std::cout << "MyFunc(char c) called" << std::endl;
}

void MyFunc(int a, int b){
  std::cout << "MyFunc(int a, int b) called: " << std::endl;
}
```

#### 3. 매개변수의 디폴트 값

  - 함수호출시 인자를 전달하지 않을때의 기본값 설정 가능

  - 함수의 선언 부분에만 표현하면 됨.

```cpp
#include <iostream>
int Adder(int num1=1, int num2=2);

int main(){
  std::cout<<Adder()<<std::endl;
  std::cout<<Adder(5)<<std::endl;  // 첫 번째 매개변수로 전달
  std::cout<<Adder(3, 5)<<std::endl;
  return 0;
}

int Adder(int num1, int num2){  // 별도로 기본값 표시 X
  return num1 + num2;
}
```

 

  - 일부만 디폴트 값 지정 가능. 

  - 반드시 오른쪽 [[매개 변수]]의 디폴트 값부터 채워야 함!

```cpp
int Func(int num1, int num2, int num3=10);   // 가능
int Func(int num1=10, int num2, int num3);   // 불가능
```

  - 함수에 전달되는 인자가 왼쪽에서부터 오른쪽으로 채워지기 때문!

#### 5. 이름 공간

  - :: 범위지정 연산자 : 이름 공간을 지정할 때 사용

 

```cpp
#include <iostream>

namespace BestComImpl{
  void SimpleFunc(void);
}

namespace ProgComImpl{
  void SimpleFunc(void);
}

int main(){
  BestComImpl::SimpleFunc(); // BestCom이 정의한 함수
  ProgComImpl::SimpleFunc(); // ProgCom이 정의한 함수
  return 0;
}

void BestComImpl::SimpleFunc(){
  std::cout << "BestCom이 정의한 함수" << std::endl;
}

void ProgComImpl::SimpleFunc(){
  std::cout << "ProgCom이 정의한 함수" << std::endl;
}
```

 

  -동일한 이름 공간에 정의된 함수를 호출할 때에는 이름 공간 명시 필요 X

```cpp
void BestComImpl::SimpleFunc(){
  std::cout << "BestCom이 정의한 함수" << std::endl;
  PrettyFunc();  // 동일 이름 공간
  ProgComImpl::SimpleFunc();  // 다른 이름 공간
}
```

 

  - 이름 공간의 중첩 가능!

```cpp
namespace Parent{
  int num=2;
  namespace SubOne{
    int num=3;
  }
  namespace SubTwo{
    int num=4;
  }
}

std::cout<< Parent::num << std::end1l;  // 2 출력
std::cout<< Parent::SubOne::num << std::end1l;  // 3 출력

```

  - 이름공간의 별칭 선언

```cpp
namespace AAA{
  namespace BBB{
    namespace CCC{
      int num1;
      int num2;
    }
  }
}

int main(){
  AAA::BBB::CCC::num1 = 20;
  AAA::BBB::CCC::num2 = 30;

  namespace ABC=AAA::BBB::CCC;
  cout << ABC::num1 << endl; // Output: 20
  cout << ABC::num2 << endl; // Output: 30
}
```

 

  - 전역 변수 지정 가능

```cpp
int val=100; // 전역변수

int SimpleFunc(){
  int val=20; // 지역변수
  val += 3;   // 지역변수 val 3증가
  ::val += 7; // 전역변수 val 7증가
}
```

### ● 함수의 재귀적 호출

  - 재귀함수 : 함수 내에서 자기 자신을 다시 호출하는 함수

```cpp
void Recursive(void){
  printf("Recursive call! \n);
  Recursive();  // 자신을 재호출  
}
```

  - 실행 중간에 다시 호출되면, 복사본 만들어서 복사본 실행

  - 탈출 조건 필수!

 

  - 팩토리얼 함수

```cpp
int Factorial(int n){
  if (n==0)
    return 1;
  else
    return n*Factorial(n-1);
}
```

 

  - 피보나치 수열 함수

```cpp
int Fibonacci(int n){
  if(n == 1)
    return 0;
  else if(n==2)
    return 1;
  else
    return Fibonacci(n-1)+Fibonacci(n-2);
}
```

  - 재귀함수는 매우 많은 수의 함수호출을 동반한다.

 

  - 하노이의 탑 함수

```cpp
void HanoiTowerMove(int num, char from, char by, char to){
  if(num == 1){  // 이동할 원반의 수가 1개
    printf("원반1을 %c에서 %c로 이동 \n", from, to);
  }else{
    HanoiTowerMove(num-1, from, to, by);  // 맨 아래 제외 나머지 원반 A에서 B로 이동
    printf("원반%d를 %c에서 %c로 이동 \n", num, from, to);
    HanoiTowerMove(num-1, by, from, to);   // B에서 C로 이동
  }
}
```

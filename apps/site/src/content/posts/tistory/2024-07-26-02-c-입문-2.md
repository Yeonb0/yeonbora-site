#### 1. bool 자료형  

  - true 와 false를 저장하는 자료형

  - 1 [[바이트|byte]]

  - 기본 자료형 중 하나. 함수 매개변수, 반환값 모두 가능!

```cpp
bool IsPositive(int num){
  if(num<=0)
    return false;
  else
    return true;
}
```

#### 2. 참조자

  - 할당된 하나의 [[메모리]] 공간에 둘 이상의 이름 부여, 수 제한 X, 참조자 대상 참조자 가능

 

  - 자신이 참조하는 [[변수]]를 대신할 수 있는 또 하나의 이름

  - 참조자 통해 주소 값 반환 가능. 변수와 동일한 효과

  - 변수에 별명을 붙여주는 것! 

```cpp
 int num1=1020;
 int &num2=num1;  // num2는 num1에 대한 참조자
```

 

  - 변수에 대해서만 선언 가능. 선언과 동시에 참조해야만 한다

  - [[상수]]를 대상으로 참조자 불가, 미리 선언 후 참조 불가, 참조 대상 변경 불가.

  - NULL로 초기화 불가

  - [[배열]] 요소 참조자 선언 가능

```cpp
  int arr[3]={1,2,3};
  int &ref1=arr[0];
  int &ref2=arr[1];
  int &ref3=arr[2];
```

 

  - [[Pointer|포인터]] 변수 참조자 선언 가능

```cpp
  int num=12;
  int *ptr=&num;
  int **dptr=&ptr;

  int &ref=num;
  int *(&pref)=ptr;
  int **(&dpref)=dptr;
```

 

  - 참조자를 통해 [[Pass-by-Reference|Call-by-reference]] 구현 가능

```cpp
void SwapByRef2(int &ref1, int &ref2){
  int temp=ref1;
  ref1=ref2;
  ref2=temp;
}
```

 

  - const 선언 : 함수 내에서 참조자를 이용한 값의 변경 X

```cpp
void Func(const int &ref);

// 함수 내에서 참조자 ref를 이용한 값의 변경은 없다.
```

 

  - 함수 반환 값이 참조자일때, 변수 연결하면 다른 변수화, <u>참조자 연결하면 같은 변수화</u>

```cpp
int & RefRetFuncOne(int &ref){
  ref++;
  return ref;
}

int main(){
  int num1=1;
  int num2=RefRetFuncOne(num1);
  int &num3=RefRetFuncOne(num1);

  num1+=1;
  num2+=100;  // num1 과 num2 는 다른 변수
  num3+=10;   // num1 과 num3 은 같은 변수
  
  cout<<"num1: "<<num1<<endl;  // 13
  cout<<"num2: "<<num2<<endl;  // 102
```

 

  - 상수화된 변수

```cpp
const int num=20;
const int &ref=num;

const int &ref=50;
```

  - const 참조자는 상수도 참조 가능 

```cpp
int Adder(const int &num1, const int &num2){
  return num1+num2;
}

// 상수의 const 선언으로 가능!
```

#### 3. new & delete

  - new : malloc 함수 대신 사용, 할당할 대상의 정보 직접 명시

```cpp
int * ptr = new int;  
// int 형 변수의 할당

double * arr = new double[7];
// 길이가 7인 double 형 배열의 할당
```

 

  - delete : free 함수 대신 사용

```cpp
delete ptr;
// 앞서 할당한 int 형 변수 소멸

delete []arr;
// 앞서 할당한 double 형 변수 소멸
```

  

  - [[객체]]의 생성에서는 반드시 new & delete 사용!

 

  - C언어 표준함수 호출법 : 맨 앞 c, .h 빼기

```cpp
#include <cstdio>   //  #include <stdio.h>
#include <cstring>  //  #include <string.h>
```

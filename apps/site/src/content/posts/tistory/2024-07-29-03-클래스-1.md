### 1. 클래스와 객체

  - C언어의 키워드 struct 대신 class 사용

```cpp
class Car{
  char gamerID[CAR_CONST::ID_LEN];  // ID
  int fuelGauge;  // 연료량
  int curSpeed;   // 현재 속도
  
  void ShowCarState();  // 차량 정보 확인
  void Accel();  // 속도 증가
  void Break();  // 속도 감소
};
```

 

  - 접근제어 지시자

<table>
<tbody>
<tr>
<td>public</td>
<td>어디서든 접근 허용</td>
</tr>
<tr>
<td>protected</td>
<td>상속 관계 일때, 유도 클래스에서의 접근 허용</td>
</tr>
<tr>
<td>private</td>
<td>클래스 내에서만 접근 허용</td>
</tr>
</tbody>
</table>

 

```cpp
class Car{
  private:
    char gamerID[CAR_CONST::ID_LEN];  // 소유자 ID
    int fuelGauge;         // 연료량
    int curSpeed;          // 현재 속도
  public:
    void InitMembers(const char *ID, int fuel);
    void ShowCarState();
    void Accel();
    void Break();
};
```

 

  - public InitMembers 함수 통해 초기화

  - 함수 내에서는 private으로 선언된 [[변수]] 접근 가능

  - struct를 이용해 정의한 구조체는 기본값 public

  - class를 이용해 정의한 [[클래스]]의 기본값 private

 

  - 멤버 변수 : 클래스 구성 변수

  - 멤버 함수 : 클래스 구성 함수

  - [[객체]] : 구조체, 클래스

 

  - 인라인 함수는 헤더파일에 선언되어야 함.

### 2. 객체 지향 프로그래밍

  - 객체 : 하나 이상의 상태 정보(데이터) + 하나 이상의 행동(기능)

  - 객체 생성 방법

```cpp
ClassName ObjName;  // 일반적인 변수의 선언 방식
ClassName * ptrObj = new ClassName;  // 동적 할당 방식(힙 할당방식)
```

 

  - 객체 간의 대화 방법 : [[메세지]] 전달(Message Passing)

### 1. 정보 은닉

  - 좋은 클래스를 위한 조건

  - 멤버 변수는 private 선언

  - 변수 접근 함수(엑세스 함수)를 정의해 '정보 은닉'

  - 액세스 함수 : Getter, Setter. 멤버변수를 private으로 선언하며 클래스 외부에서의 멤버변수 접근을 목적으로 정의되는 함수

  - const 함수 : 함수 내부에서 멤버변수에 저장된 값을 변경하지 않겠다는 선언. 

  - const 함수 안에서는 const 가 아닌 함수를 호출할 수 없음

```cpp
int GetNum(){
  return num;
}

void ShowNum() const{
  cout<<GetNum<<endl;
}  // 오류 발생
```

 

  - const 참조자를 이용하면 const 함수만 호출 가능

```cpp
class LiveClas{
  private:
    int num;
  public void InitNum(const EasyClass &easy){
    num=easy.GetNum();  // 에러 발생
}
```

 

  - 캡슐화 : 연관된 클래스끼리 묶기

### 2. 생성자와 소멸자

#### 1) 생성자 

  - 클래스의 이름과 함수의 이름이 동일

  - 반환형 선언 X, 실제로 반환 X

```cpp
class SimpleClass{
  private:
    int num;
  public:
    SimpleClass(int n){  // 생성자
      num=n;
    }
    
    int GetNum() const{
      return num;
    }
 };
```

  - 객체 생성시 딱 한 번 호출

```cpp
SimpleClass sc(20);  // 전역, 지역 및 매개변수
SimpleClass * ptr = new SimpleClass(30);  // 동적 할당
```

 

  - 오버로딩 가능

```cpp
class SimpleClass{
  private:
    int num1;
    int num2;
  public:
    SimpleClass(){
      num1=0;
      num2=0;
    }
    SimpleClass(int n){
      num1=n;
      num2=0;
    }
    SimpleClass(int n1, int n2){
      num1=n1;
      num2=n2;
    }

    void ShowData() const{
      cout<<num1<<' '<<num2<<endl;
    }
};
```

 

  - 멤버 이니셜라이저 

```cpp
class Rectangle{
  private:
    Point upLeft;
    Point lowRight;
  public:
    Rectangle(const int &x1, const int &y1, const int &x2, const int &y2);
}

Rectangle::Rectangle(const int &x1, const int &y1, const int &x2, const int &y2)
:upLeft(x1, y1), lowRight(x2, y2){
   // empty
}
```

  - 멤버 변수로 선언된 객체의 생성자 호출에 활용. 생성자의 몸체 부분이 비는 경우 생김.

 

  - 객체의 생성 과정

> 1\. 메모리 공간의 할당\
> 2\. 이니셜라이저를 이용한 멤버변수(객체)의 초기화\
> 3\. 생성자의 몸체부분 실행

 

  - 이니셜라이저 이용시 선언과 동시에 초기화가 이뤄지는 형태로 바이너리 코드 생성

  - const 멤버 변수가 이니셜라이저를 통해 초기화 가능

 

  - 디폴트 생성자 : 객체가 되기 위해선 반드시 하나의 생성자가 필요. 자동으로 생성됨

```cpp
class AAA{
  public:
    AAA(){};  // 자동으로 생성되는 생성자
};
```

  - 생성자가 한번이라도 정의되었다면 void로 객체 생성 불가

```cpp
SoSimple simObj; // X
SoSimple * simPtr = new Sosimple // X
```

 

  - private 생성자 : 객체 생성 가능. 객체의 생성방법을 제한하고자 할 때 사용

 

#### 2) 소멸자

  - 클래스의 이름 앞에 \~ 붙은 형태

  - 반환형 선언 X, 실제로 반환 X 

  - 매개변수 void형, 오버로딩, 디폴트값 설정 불가

```cpp
class AAA{
  AAA(){ }
  ~AAA(){ }
};
```

  - 디폴트 소멸자가 자동으로 삽입

### 3. 클래스 배열, this 포인터

#### 1) 객체 배열

```cpp
SoSimple arr[10];
SoSimple * ptrNew = new SoSimple[10];
```

 

  - 입력 X 생성자 반드시 정의되어야 함

```cpp
SoSimple(){
  // ...
}
```

  - 배열 선언 이후, 초기화 과정 필요

 

  - 객체 포인터 배열 : 객체의 주소 값 저장이 가능한 포인터 변수로 이뤄진 배열

```cpp
Person * parr[3];
```

 

#### 2) this 포인터

  - 객체 자신의 주소 값 의미

  - 주소 값과 자료형이 정해져 있지 않은 포인터

  - 멤버 변수와 매개 변수의 이름을 동일하게 하고 this로 구분 가능

```cpp
class ThisClass{
   private:
     int num;
   public:
     void ThisFunc(int num){
       this->num=207;  // 멤버변수 num에 207 저장
       num=105;  // 매개변수 값을 105로 변경
     }
};
```

 

  - Self-Reference : 객체 자신을 참조할 수 있는 참조자

- [[데이터베이스]]에 명령을 내릴 때 사용하는 ㄴ언어
%% typo? : "ㄴ언어" → "언어" %%
- 주로 [[관계형 데이터베이스]]에 사용
- 1974, IBM 연구소 개발 SEQUEL 유래
- 국제 표준 [[데이터베이스|DB]] 언어, [[관계형 데이터베이스|RDB]] 지원 언어 채택

### 명령어
- 데이터 조회 : `SELECT`
- 데이터 수정 : `UPDATE`
- 데이터 추가 : `INSERT`
- 삭제 : `DELETE`

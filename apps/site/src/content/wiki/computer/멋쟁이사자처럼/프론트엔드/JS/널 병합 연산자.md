- `??` : 왼쪽에 있는 값이 [[null]]이나 [[undefined]]면 오른쪽의 기본 값을 반환 
```js
const name = student?.name ?? "이름 없음";
console.log(name); 
// student.name이 없으면 "이름 없음"을 출력
```

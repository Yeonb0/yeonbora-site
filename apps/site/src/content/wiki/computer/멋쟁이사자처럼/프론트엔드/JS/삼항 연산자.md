```js
condition ? exprIfTrue : exprIfFalse; 
```
- `condition` 이 [[Truthy]] 면 -> `exprIfTrue` 할당
- `condition` 이 [[Falsy]] 면 -> `exprIfFalse` 할당

```js
let age = 26;
let beverage = age >= 21 ? "Beer" : "Juice";
console.log(beverage); // "Beer"
```

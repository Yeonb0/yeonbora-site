- [[width]] -> `w-` 다음에 숫자 넣기
- [[height]] -> `h-` 다음에 숫자 넣기
- auto margin -> `mx-auto`

```html
<div className="max-w-3xl mx-auto"></div>
// 참고 : max-w-3xl = max-width: 48rem; /* 768px */
```

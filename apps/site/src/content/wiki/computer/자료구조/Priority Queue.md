## Minimum priority queue
### Operation
- `INSERT(S, x ,k)` : S 에 key 값이 k 인 x 넣기
- `EXTRACT_MIN(S)` : S 에서 key 가 가장 작은 값을 가진 요소 빼기
- `DECREASE_KEY(S, x, k)` : S 에서 x 의 key 값을 k 로 바꾸기

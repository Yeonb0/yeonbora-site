- 2개 [[이상(Anomaly)|이상]] 테이블 [[데이터]] 하나로 통합하는 질의 [[연산]]
- [[관계 대수]] 일반 집합 연산자의 [[SQL]] 구현

### 형식
```sql
SELECT 속성명1, 속성명2, …
FROM 테이블명
UNION | UNION ALL | INTERSECT | EXCEPT
SELECT 속성명1, 속성명2, …
FROM 테이블명
[ORDER BY 속성명 [ASC | DESC]];
```

### 조건
- 두 [[SELECT]] 문 기술 [[속성]] -> 개수 & 데이터 유형 동일

### 종류
| 연산자 | 집합 | 내용 |
| --- | --- | --- |
| `UNION` | 합집합 | 두 `SELECT` 조회 결과 통합 출력, 중복 행 1회만 출력 |
| `UNION ALL` | 합집합 | 두 `SELECT` 조회 결과 통합 출력, 중복 행 모두 출력 |
| `INTERSECT` | 교집합 | 두 `SELECT` 조회 결과 中 공통 행만 출력 |
| `EXCEPT` | 차집합 | 첫 `SELECT` 결과 - 두 번째 `SELECT` 결과 |

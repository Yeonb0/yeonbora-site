- 조건절 주어진 질의 먼저 수행 -> 그 검색 결과를 조건절 피연산자로 사용
- [[SELECT]] 문 중첩 구조

### 형태
- `= (SELECT …)` : 단일 값 비교
- `IN` · `NOT IN (SELECT …)` : 결과 집합 포함 여부
- `EXIST (SELECT …)` : 상관 조건 존재 여부
- ==ex)==
```sql
# '취미'가 "나이트댄스"인 사원의 '이름'과 '주소' 검색
SELECT 이름, 주소
FROM 사원
WHERE 이름 = (SELECT 이름 FROM 여가활동 WHERE 취미 = '나이트댄스');
# 취미활동 하지 않는 사원 검색
SELECT *
FROM 사원
WHERE 이름 NOT IN (SELECT 이름 FROM 여가활동);
# 취미활동을 하는 사원들의 '부서' 검색
SELECT 부서
FROM 사원
WHERE EXIST (SELECT 이름 FROM 여가활동 WHERE 여가활동.이름 = 사원.이름);
```

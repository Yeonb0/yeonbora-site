- [[프로시저]] 유사, [[SQL]] 사용해 일련의 작업 연속 처리
- 종료 시 처리 결과 ==단일값== 으로 반환
- [[데이터베이스|DB]] 에 저장, DML문 호출에 의해 실행
- 예약어 `RETURN` 통해 값 반환 -> 출력 파라미터 X
- 테이블 조작 X, `SELECT` 이용 조회만 O
- 프로시저 호출 X
- DML문에서 반환값 활용 용도로 사용

### 프로시저와 비교
| 구분 | [[프로시저]] | 사용자 정의 [[함수]] |
| --- | --- | --- |
| 반환값 | 없거나 1개 [[이상(Anomaly)\|이상]] O | 1개 |
| 파라미터 | 입 · 출력 O | 입력만 O |
| 사용 가능 명령문 | DML, DCL | `SELECT` |
| 호출 | 프로시저, 사용자 정의 함수 | 사용자 정의 함수 |
| 사용 방법 | 실행문 | DML에 포함 |

### 구조
- [[데이터]] -> 사용자 정의 함수 -> 반환
- `DECLARE` ==필수== : 사용자 정의 함수 명칭 · [[변수]] · 인수 · [[데이터 타입]] 정의
- `BEGIN` ==필수== : 사용자 정의 함수 시작
	- `CONTROL` : [[조건문]] or [[반복문]] 삽입 -> 순차 처리
	- `SQL` : `SELECT`문 삽입 -> 데이터 조회 작업 수행
	- `EXCEPTION` : `BEGIN` ~ `END` 안 구문 실행 시 예외 발생 -> 처리 방법 정의
	- `RETURN` ==필수== : 호출 프로그램에 반환할 값 or 변수 정의
- `END` ==필수== : 종료

### 생성
```sql
CREATE [OR REPLACE] FUNCTION 사용자 정의 함수명(파라미터)
[지역변수 선언]
BEGIN
	사용자 정의 함수 BODY;
	RETURN 반환값;
END;
```
- `OR REPLACE` : 선택적 예약어, 동일 사용자 정의 함수 [[이름]] 존재 시 기존 함수 대체
- 파라미터
	- IN : 호출 프로그램 -> 사용자 정의 함수 값 전달 시 지정
	- 매개변수명 : 호출 프로그램으로부터 전달받은 값 저장 변수 이름 지정
	- 자료형 : 변수 자료형 지정
- 사용자 정의 함수 BODY
	- 사용자 정의 함수 코드 기록
	- `BEGIN` 시작 `END` 끝
	- 사이에 적어도 하나의 SQL문 필요
- `RETURN` 반환값 : 반환할 값 or 반환할 값 저장 변수를 호출 프로그램으로 돌려줌
- ==ex)== 'i_성별코드' 입력받아 1이면 "남자", 2면 "여자" 반환
```sql
CREATE FUNCTION Get_S_성별(i_성별코드 IN INT)
RETURN VARCHAR2
IS
BEGIN
	IF i_성별코드 = 1 THEN
		RETURN '남자';
	ELSE
		RETURN '여자';
	END IF;
END;
```

### 실행
```sql
SELECT 사용자 정의 함수명 FROM 테이블명;
INSERT INTO 테이블명(속성명) VALUES (사용자 정의 함수명);
DELETE FROM 테이블명 WHERE 속성명 = 사용자 정의 함수명;
UPDATE 테이블명 SET 속성명 = 사용자 정의 함수명;

# Example
SELECT 이름, Get_S_성별(성별코드) FROM 사원;
```

### 제거
```sql
DROP FUNCTION 사용자 정의 함수명;

#Example
DROP FUNCTION Get_S_성별;
```

- [[데이터베이스|DB]] 에서 [[데이터]] `INSERT` · `UPDATE` · `DELETE` 등 [[Event|이벤트]] 발생 시마다 관련 작업 자동 수행
- DB 에 저장 -> 데이터 변경 · [[무결성]] 유지, 로그 메시지 출력
- DCL 사용 X, DCL 포함 [[프로시저]] or [[사용자 정의 함수|함수]] 호출도 X
- 트리거에 [[Error|오류]] -> 트리거가 처리하는 데이터에도 영향

### 구조
- 이벤트 -> 트리거 -> 데이터 변경
- 이벤트 : DB 시스템에서 데이터 삽입 · 갱신 · 삭제 등
- `DECLARE` ==필수== : 트리거 명칭 · [[변수]] · [[상수]] · [[데이터 타입]] 정의
- `EVENT` ==필수== : 트리거 실행 조건 명시
- `BEGIN` ==필수== : 트리거 시작
	- `CONTROL` : [[조건문]] or [[반복문]] 삽입 -> 순차 처리
	- `SQL` : DML문 삽입 -> 데이터 조회 · 추가 · 수정 · 삭제 작업 수행
	- `EXCEPTION` : `BEGIN` ~ `END` 안 구문 실행 시 예외 발생 -> 처리 방법 정의
- `END` ==필수== : 트리거 끝

### 생성
```sql
CREATE [OR REPLACE] TRIGGER 트리거명 동작시기 동작 ON 테이블명
[REFERENCING NEW | OLD AS 테이블명]
[FOR EACH ROW [WHEN 조건식]]
BEGIN
	트리거 BODY;
END; 
```
- `OR REPLACE` : 선택적 예약어, 동일 트리거 [[이름]] 존재 시 기존 트리거 대체
- 동작시기 : 트리거 실행될 때 지정
	- `AFTER` : 테이블 변경된 후 트리거 실행
	- `BEFORE` : 테이블 변경되기 전 트리거 실행
- 동작 : 트리거 실행될 작업 종류 지정
	- `INSERT` : 테이블에 새로운 [[튜플]] 삽입 시 실행
	- `DELETE` : 테이블 튜플 삭제 시 실행
	- `UPDATE` : 테이블 튜플 수정 시 실행
- `NEW` | `OLD` : 트리거 적용될 테이블 별칭 지정
	- `NEW` : 추가 or 수정에 참여할 튜플 집합(테이블)
	- `OLD` : 수정 or 삭제 전 대상이 되는 튜플 집합(테이블)
- `FOR EACH ROW` : 각 튜플마다 트리거 적용
- `WHEN` 조건식 : 선택적 예약어, 트리거 적용 튜플 조건 지정
- 트리거 BODY
	- 트리거 본문 코드 입력
	- `BEGIN` 시작 `END` 끝
	- 사이에 적어도 하나의 SQL문 필요
- ==ex)== <학생> 테이블 `INSERT` 시 학년 정보 누락되면 '학년' [[필드]]에 "신입생" 치환
```sql
CREATE TRIGGER 학년정보_tri BEFORE INSERT ON 학생
REFERENCING NEW AS new_table
FOR EACH ROW
WHEN (new_table.학년 IS NULL)
	BEGIN
		:new_table.학년 := '신입생';
	END;
```

### 제거
```sql
DROP TRIGGER 프로시저명;

# Example
DROP TRIGGER 학년정보_tri;
```

- 절차형 [[SQL]] 활용해 특정 기능 수행하는 [[트랜잭션]] 언어
- 호출 통해 실행, 미리 저장한 SQL 작업 수행
- [[데이터베이스|DB]] 저장 시 여러 프로그램에서 호출해 사용 O
- DB 저장되어 수행 -> ==Stored 프로시저==
- 시스템 일일 마감 작업, ==일괄([[배치 처리|Batch]])== 작업 등에 사용

### 구조
- [[데이터]] -> 프로시저 -> 결과
- `DECLARE` ==필수== : 프로시저 명칭 · [[변수]] · 인수 · [[데이터 타입]] 정의
- `BEGIN` ==필수== : 프로시저 시작
	- `CONTROL` : [[조건문]] or [[반복문]] 삽입 -> 순차 처리
	- `SQL` : DML, DCL 삽입 -> 데이터 조회 · 추가 · 수정 · 삭제 작업 수행
	- `EXCEPTION` : `BEGIN` ~ `END` 안 구문 실행 시 예외 발생 -> 처리 방법 정의
	- `TRANSACTION` : 수행된 데이터 작업 DB 적용 or 취소 결정 처리부
- `END` ==필수== : 프로시저 종료

### 생성
```sql
CREATE [OR REPLACE] PROCEDURE 프로시저명(파라미터)
[지역변수 선언]
BEGIN 
	프로시저 BODY;
END;
```
- `OR REPLACE` : 선택적 예약어, 동일 프로시저 [[이름]] 존재 시 기존 프로시저 대체
- 프로시저명 : 생성하려는 프로시저 이름 지정
- 파라미터
	- IN : 호출 프로그램 -> 프로시저 값 전달 시 지정
	- OUT : 프로시저 -> 호출 프로그램 값 반환 시 지정
	- INOUT : 전달 + 반환 시 지정
	- 매개변수명 : 호출 프로그램으로부터 전달받은 값 저장 변수 이름 지정
	- 자료형 : 변수 자료형 지정
- 프로시저 BODY
	- 프로시저 코드 기록
	- `BEGIN` 시작 `END` 끝
	- 사이에 적어도 하나의 SQL문 필요
- ==ex)== '사원번호' 입력받아 해당 사원 '지급방식' "S" 로 변경
```sql
CREATE OR REPLACE PROCEDURE emp_change_s(i_사원번호 IN INT)
IS
BEGIN
	UPDATE 급여 SET 지급방식 = 'S' WHERE 사원번호 = i_사원번호;
	EXCEPTION
		WHEN PROGRAM_ERROR THEN
			ROLLBACK;
	COMMIT;
END;
```

### 실행
```sql
EXECUTE 프로시저명;
EXEC 프로시저명;
CALL 프로시저명;

# Example
# '사원번호' 32를 인수로 해 프로시저 실행
EXECUTE emp_change_s(32);
```

### 제거
```sql
DROP PROCEDURE 프로시저명;

# Example
DROP PROCEDURE emp_change_s;
```

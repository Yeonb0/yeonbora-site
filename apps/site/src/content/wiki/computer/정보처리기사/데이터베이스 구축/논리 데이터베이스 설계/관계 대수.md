### 순수 관계 연산자
| 연산자 | 내용 | 표기 |
| --- | --- | --- |
| Select | 튜플 中 선택 부분 집합 -> new 릴레이션, 행(가로) 수평 연산자 | $\sigma_{<조건>}(R)$ (시그마) |
| Project | 속성 리스트 제시 속성 값만 추출, 열(세로) 수직 연산자, 중복 제거 | $\pi_{<속성 리스트>}(R)$ (파이) |
| Join | 공통 속성 중심 두 릴레이션 결합 -> new 릴레이션 | $R ⋈_{키속성 r = 키속성 s} S$ |
| Division | X ⊃ Y 인 R(X), S(Y) 에서 S 의 속성 제외한 R | $R_{[속성 r \div 속성 s]}S$ |

- Select : 비교 [[연산]] · 논리 연산자 사용 O
- Join 차수 = 두 릴레이션 차수 합
- Join = Cartesian Product (교차곱) 수행 -> Select 수행

### 일반 집합 연산자
- 수학적 집합 이론 사용 연산자

| 연산자 | 기호 | 내용 | 카디널리티 |
| --- | --- | --- | --- |
| 합집합 (Union) | ∪ | 튜플 합집합 구하기, 중복 제거 | \|R ∪ S\| ≤ \|R\| + \|S\| |
| 교집합 (Intersection) | ∩ | 튜플 교집합 구하기 | \|R ∩ S\| ≥ MIN { \|R\| , \|S\| } |
| 차집합 (Difference) | - | 튜플 차집합 구하기 | \|R - S\| ≤ \|R\| |
| 교차곱 (Cartesian Product) | $\times$ | 튜플 순서쌍 구하기 | \|R × S\| = \|R\| × \|S\| |

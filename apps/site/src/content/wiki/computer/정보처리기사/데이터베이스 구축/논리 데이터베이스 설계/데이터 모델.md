- 현실 세계 정보 -> 단순화 · 추상화한 개념적 모형
- [[데이터베이스 설계]] 의 표현 도구

### 구성 요소
- [[개체]] (Entity) : [[데이터베이스|DB]] 표현 대상, 개념 · 정보 단위
- [[속성]] (Attribute) : [[데이터]] 최소 논리적 단위, 데이터 항목 · [[필드]]
- 관계 ([[연관성|Relationship]]) : 개체 간 관계 or 속성 간 논리적 연결
	- 일 대 일 (1 : 1)
	- 일 대 다 (1 : N)
	- 다 대 다 (N : M)

### 종류
- 개념적 데이터 모델
	- 현실 세계 인식 -> 추상적 개념 표현
	- 속성으로 기술된 개체 타입 + 타입 간 관계 이용
	- ==ex)== [[E-R 모델]]
- 논리적 데이터 모델
	- [[데이터 타입]] + 타입 간 관계 이용
	- ==ex)== 관계 모델, 계층 모델, [[컴퓨터 네트워크|네트워크]] 모델

### 표시 요소
| 요소 | 내용 |
| --- | --- |

| [[연산]] (Operation) | DB 저장 데이터 처리 명세, DB 조작 기본 도구 |
| 제약 조건 (Constraint) | DB 저장 실제 데이터 논리적 제약 조건 |

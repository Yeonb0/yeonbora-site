### 구조
| 구성 | 내용 |
| --- | --- |
| 릴레이션 [[스키마]] | 구조 나타낸 것 |
| 릴레이션 [[인스턴스]] | 실제 값 |
| [[튜플]] (Tuple) | 릴레이션 구성 각각의 행 |
| [[속성]] (Attribute) | [[데이터베이스\|DB]] 구성 최소 논리적 단위, 개체 특성, 차수 |
| [[도메인]] (Domain) | 한 속성이 가질 수 있는 값의 범위 |

### 특징
- 1 릴레이션 안 튜플 모두 상이, Unique
- 튜플 사이 순서 X, 속성 사이 순서 X
- 시간에 따라 변함 -> 튜플 삽입 · 삭제
- 속성 명칭 유일, 값은 동일 O
- 튜플 유일 식별 -> 속성 부분 집합을 [[키(Key)]] 로 설정
- 속성 -> 논리적으로 더 이상 쪼갤 수 없는 원자값 저장

### 종류
| 종류 | 내용 |
| --- | --- |
| 개체 무결성 (Entity Integrity) | 기본 테이블 [[기본키]] 속성 -> NULL 값 · 중복 값 X |
| 도메인 무결성 (Domain Integrity) | 속성 값이 정의된 [[도메인]] 에 속한 값 |
| 참조 무결성 (Referential Integrity) | [[외래키]] 값 = NULL or 참조 릴레이션 기본키 값과 동일 |
| 사용자 정의 무결성 (User-Defined Integrity) | 속성 값이 사용자 정의 제약 조건 만족 |

- 개체 무결성 = 실체 무결성, 도메인 무결성 = 영역 무결성

### 강화 방법

- 데이터베이스 트리거

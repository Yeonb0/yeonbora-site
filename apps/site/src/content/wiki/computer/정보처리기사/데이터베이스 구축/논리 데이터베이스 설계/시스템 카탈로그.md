- 시스템 관련 다양한 객체 정보 포함 [[데이터베이스|DB]]
- 사용자 포함 [[데이터베이스 관리 시스템|DBMS]] 지원 all [[데이터]] 객체 정의 · 명세 정보 유지 관리
- = 데이터 사전 ([[자료 사전|Data Dictionary]])
- 저장 정보 = [[메타 데이터]]

### 메타 데이터 구성
- 데이터베이스 객체 정보 : 테이블, 인덱스, 뷰 등의 구조 · 통계 정보
- 사용자 정보 : 아이디, 패스워드, 접근 권한
- 테이블 [[무결성]] 제약 조건 정보 : [[기본키]], [[외래키]], NULL 값 허용 여부
- [[함수]], 프로시저, 트리거 정보

### 특징
- 시스템 테이블 -> 일반 사용자도 [[SQL]] 이용 검색 O
- INSERT, DELETE, UPDATE 갱신 X
- DB 시스템 따라 상이한 구조, DBMS 스스로 생성 · 유지
- 카탈로그 갱신 : 사용자 SQL 로 변화 -> 시스템 자동 갱신
- 분산 시스템 : all 정보 + 제어 정보 보유 필요

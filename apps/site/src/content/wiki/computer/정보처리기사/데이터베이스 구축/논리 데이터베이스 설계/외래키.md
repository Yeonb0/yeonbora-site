- 다른 [[릴레이션]] [[기본키]] 참조하는 [[속성]] or 속성 집합

### 조건
- 참조 릴레이션 기본키에 없는 값 입력 X
- NULL or 참조 릴레이션 기본키 값과 동일 -> [[무결성|참조 무결성]]

### 참조 동작 옵션
- [[CREATE TABLE]] 의 `FOREIGN KEY ~ REFERENCES ~` 로 지정 -> CASCADE 법칙 적용
- `ON DELETE` : 참조 릴레이션 [[튜플]] 삭제 시 조치
- `ON UPDATE` : 참조 릴레이션 참조 속성 값 변경 시 조치
	- `NO ACTION` : 기본 테이블 조취 X
	- `CASCADE` : 기본 테이블 관련 튜플 변화 · 삭제
	- `SET NULL` : 기본 테이블 관련 튜플 속성값 NULL 변경
	- `SET DEFAULT` : 기본 테이블 관련 튜플 속성값 DEFAULT 변경

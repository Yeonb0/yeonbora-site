- 종속성 이론 활용 -> 관계형 [[스키마]] 작게 쪼개기
- [[데이터베이스 설계]] 의 논리적 설계 단계 수행
- [[이상(Anomaly)]] 제거 목적

### 목적
- 일관성, 정확성, 단순성, 비중복성, 안정성, 무결성
- [[릴레이션]] 표현, 효과적 검색 [[알고리즘]]
- 검증, 누락 여부 확인, 검색 · 추출 효율성 추구

### 과정
| 단계 | 조건 |
| --- | --- |
| 1NF (제 1 정규형) | 릴레이션 all [[속성]] 값이 원자 값으로만 구성 |
| 2NF (제 2 정규형) | [[기본키]] X all 속성이 기본키에 대해 [[함수적 종속]] 만족 |
| 3NF (제 3 정규형) | 기본키 X all 속성이 기본키에 대해 이행적 종속 만족 X |
| BCNF (Boyce-Codd 정규형) | 릴레이션 R 결정자가 모두 [[후보키]] |
| 4NF (제 4 정규형) | [[다치 종속]] $A \twoheadrightarrow B$ 성립 시, all 속성이 A 에 함수적 종속 |
| 5NF (제 5 정규형, PJ / NF) | all [[조인 종속]] 이 R 의 후보키 통해서만 성립 |

- BCNF
	- 키 X all 속성 -> 키에 대해 완전 종속, 부분적으로 들어가 있지 않은 all 키 완전 종속
	- 어떤 속성도 키 X 속성에 대해선 완전 종속 불가

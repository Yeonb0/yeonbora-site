- [[데이터]]가 어떤 기준값에 의해 종속되는 것
- [[정규화]] 단계 판정 기준

### 종류
- 완전 함수적 종속 : 어떤 [[속성]] 이 [[기본키]] 에 대해 완전히 종속적
- 부분 함수적 종속 : 기본키 일부에 대해서만 종속적
- 이행적 종속 (Transitive Dependency) : A → B, B → C 일 때 A → C 만족하는 관계
- [[다치 종속]] (Multi Valued Dependency, 다가 종속)
	- A, B, C 3 속성 릴레이션에서 복합 속성 (A, C) 대응 B 값의 집합이 A 에 종속, C 값 무관 -> B 는 A 에 다치 종속
	- $A \twoheadrightarrow B$
- [[조인 종속]] (Join Dependency)
	- 릴레이션 속성 부분 집합 A, B, ···, C
	- 릴레이션 R = 자신의 프로젝션 (Projection) A, B, ···, C all 조인 결과 -> R 은 조인 종속 (A, B, ···, C) 만족

### 용어
- 결정자 (Determinant) : 속성 간 종속명 규정 시 기준 값
- 종속자 (Dependent) : 결정자의 값에 의해 정해지는 값

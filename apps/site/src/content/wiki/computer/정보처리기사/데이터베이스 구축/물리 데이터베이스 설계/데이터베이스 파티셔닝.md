- 대용량 테이블 or [[인덱스]] -> 작은 논리적 단위로 분할
- [[데이터]] 처리 -> 테이블 단위 / 데이터 저장 -> 파티션 별
- cf) [[파티션]] : 디스크 구분 영역

### 장 · 단점
| 장점 | 단점 |
| --- | --- |
| 접근 액세스 범위 ↓ -> 쿼리 성능 ↑ | 1 테이블 세분화 -> 세심한 관리 필요 |
| 데이터 분산 저장 -> 디스크 성능 ↑ | 테이블 간 조인 비용 ↑ |
| 파티션 별 [[백업]] · 복구 -> 속도 ↑ | 용량 小 테이블 파티셔닝 -> 성능 ↓ |
| 데이터 손상 최소화 |  |
| 데이터 가용성 ↑ |  |
| 파티션 단위 입 · 출력 분산 可 |  |

### 종류
| 종류 | 내용 |
| --- | --- |
| 범위 분할(Range Partitioning) | 지정한 열 값 기준 범위 지정 분할, ==ex)== 일별 · 월별 · 분기별 |
| 해시 분할(Hash Partitioning) | [[해시 함수]] 적용 결과 값 따라 분할, 데이터 고르게 분산 시 용이 |
| 조합 분할([[Composite]] Partitioning) | 범위 분할 후 [[해시 함수]] 적용해 재분할, 파티션 너무 클 때 유용 |
| 목록 분할(List Partitioning) | 지정한 열 값 대한 목록 기준 분할 |
| [[Round Robin\|라운드 로빈]] 분할(Round Robin Partitioning) | 레코드 균일 분배, 각 레코드 순차적 분배 & [[기본키]] 필요 X |

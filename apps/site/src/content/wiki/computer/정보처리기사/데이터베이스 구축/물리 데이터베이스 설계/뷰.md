- ==1개 이상== 기본 테이블로부터 유도된, [[이름]]을 가지는 가상 테이블
- 사용자에게만 제한적 자료 노출 목적
- 저장 장치 내 물리적 존재 X, 사용자에겐 있는 것처럼 간주

### 용도
- [[데이터]] 보정 작업 · 처리 과정 시험 등 임시 작업
- 조인문 사용 최소화 -> 사용상 편의성 ↑

### 특징
- from 기본 테이블 -> 같은 구조 · 조작
- 가상 테이블 -> 물리적 구현 X
- 데이터 논리적 독립성 제공 可, 관리 Good, 명령문 간단
- 데이터 접근 제어 -> 보안 제공
- [[기본키]] 포함 속성 집합으로 구성해야 삽입 · 삭제 · 갱신 [[연산]] 可
- 정의된 뷰 -> 다른 뷰의 정의에 기초 可
- 뷰 정의 -> `CREATE` 문 / 뷰 제거 -> `DROP` 문

### 장 · 단점
| 장점 | 단점 |
| --- | --- |
| 논리적 데이터 독립성 제공 | 독립적 인덱스 X |
| 동일 데이터 -> 동시 여러 사용자 지원 | 뷰로 정의 변경 X |
| 사용자 데이터 관리 간단 | 뷰 내용 삽입 · 삭제 · 갱신 연산에 제약 |
| 접근 제어 -> 자동 보안 제공 |  |

### 설계 순서
1. 대상 테이블 선정
2. 대상 컬럼 선정
3. 정의서 제시

- <키 값, 포인터> [[데이터]] 구조 -> 데이터 레코드 빠르게 접근
- 저장 물리적 구조와 관계 有
- 인덱스 X -> TABLE SCAN 발생
	- all 데이터 페이지 확인

### 종류
- 기본 인덱스 : [[기본키]] 위한 인덱스
	- 대부분 [[데이터베이스 관리 시스템|DBMS]] 에서 자동 생성
- 보조 인덱스 : 기본 인덱스가 아닌 인덱스
- 클러스터드 인덱스(Clustered Index) : 인덱스 키 순서 따라 데이터 정렬되어 저장
	- 1 [[릴레이션]] - 1 인덱스
- 넌클러스터드 인덱스(Non-Clustered Index) : 인덱스 키 정렬 O, 데이터 정렬 X
	- 1 [[릴레이션]] - 多 인덱스
- [[트리]] 기반 인덱스 : 인덱스 저장 블록 -> 트리 구조
	- B 트리 인덱스 : 일반적 사용, 브랜치 블록 / 리프 블록
	- B+ 트리 인덱스 : B 트리 변형, 인덱스 세트 / 순차 세트
- 비트맵 인덱스 : 인덱스 컬럼 데이터 -> ==0 or 1== 변환해 인덱스 키로 사용
- [[함수]] 기반 인덱스 : 컬럼 값 대신 함수 · 수식 산출 값 사용
	- B+ 트리 인덱스 or 비트맵 인덱스 생성해 사용
	- 적용 可 함수 : 산술식, 사용자 정의, [[프로그래밍 언어|PL]] / [[SQL]], Package, C Callout
- 비트맵 조인 인덱스 : 다수의 조인 된 객체 구성 인덱스
- 도메인 인덱스 : 개발자 필요 인덱스 직접 생성, 확장형 인덱스

### 설계 절차
1. 인덱스 대상 테이블 · 컬럼 선정
2. 효율성 검토 -> 인덱스 최적화 수행
3. 인덱스 정의서 작성

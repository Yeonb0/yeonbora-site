- [[데이터]] 저장 객체 - 사용 주체 사이 정보 흐름 제한

### 기능
- 비인가 사용자 접근 감시
- 접근 요구자 사용자 식별
- 접근 요구 정당성 확인 · 기록
- 보안 정책 근거 접근 승인 · 거부

### 종류
| 종류 | 내용 |
| --- | --- |
| [[Random Access\|임의 접근]] 통제(DAC, Discretionary Access Control) | 데이터 소유자 -> 접근 사용자 신원 따라 권한 부여, 객체 생성 사용자가 모든 권한 O, `GRANT` · `REVOKE` |
| 강제 접근 통제(MAC, Mandatory Access Control) | 시스템 -> 주체 / 객체 등급 비교해 권한 부여, [[데이터베이스\|DB]] 객체별 · 사용자별 부여 可 |
| 역할 기반 접근 통제(RBAC, Role Based Access Control) | 중앙 관리자 -> 사용자 역할 따라 권한 부여, 다중 프로그래밍 환경 최적화, DAC · MAC 단점 보완 |

### 정책
1. 신분 기반 정책 : 주체 · 그룹 신분 근거해 객체 접근 제한
	- IBP(Individual-Based Policy)
	- GBP(Group-Based Policy)
2. 규칙 기반 정책 : 주체 권한 근거 객체 접근 제한
	- [[다층 퍼셉트론|MLP]](Multi-Level Policy)
	- CBP(Compartment-Based Policy)
3. 역할 기반 정책 : GBP 변형, 주체 역할 근거해 접근 제한

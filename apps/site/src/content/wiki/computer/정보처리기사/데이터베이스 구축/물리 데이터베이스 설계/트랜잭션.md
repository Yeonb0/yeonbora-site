- 한 번에 수행할 연산들의 집합

### 상태
![[물리-데이터베이스-설계-01.png]]

| 상태 | 내용 |
| --- | --- |
| 활동(Active) | 트랜잭션 실행 中 |
| 실패(Failed) | 실행에 [[Error\|오류]] 발생해 중단된 상태 |
| 철회(Aborted) | 비정상적 종료 -> Rollback [[연산]] 수행 |
| 부분 완료(Partially Commited) | 모두 성공적 실행, Commit 실행 직전 |
| 완료(Commited) | Commit 실행 이후 |

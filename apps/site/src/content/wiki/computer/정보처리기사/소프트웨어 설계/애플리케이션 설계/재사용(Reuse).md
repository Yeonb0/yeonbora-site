- 이미 개발된 기능 최적화
- 사용법 공개
- [[결합도]]↓, [[응집도]]↑
- 이미 개발된 [[소프트웨어]] 전체 or 일부분 다른 소프트웨어 개발 / 유지에 사용 -> 개발 품질 · 생산성 ↑
- 기존 개발 소프트웨어 · 경험 · 지식 적용

| 종류      | 방법                   |
| ------- | -------------------- |
| [[함수]] · 객체 | [[클래스]] · [[메소드]] 코드 재사용     |
| [[컴포넌트]]    | [[인터페이스]] 통해 재사용         |
| 애플리케이션  | 공통 기능 애플리케이션 공유로 재사용 |

### 방법
- 합성 중심(Composition-Based)
	- 소프트웨어 부품으로 블록([[모듈]]) 만들어 소프트웨어 구성
	- 블록 구성 방법
- 생성 중심(Generation-Based)
	- [[추상화]] 형태 명세 구체화해 프로그램 제작
	- 패턴 구성 방법

### 장점
- 개발 시간 · 비용 ↓
- 소프트웨어 품질 · 개발 생산성 ↑
- 프로젝트 실패 위험 ↓
- 시스템 구축 방법 지식 공유
- 시스템 명세 · 설계 · 코드 문서 공유

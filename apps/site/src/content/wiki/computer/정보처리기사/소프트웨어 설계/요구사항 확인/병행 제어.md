- 여러 작업을 ==번갈아가며== 처리 -> 동시 진행 중이나 한 순간엔 하나만 실행
- Parallel ==(병렬)== 과 대비 : CPU 여러 개 사용 -> 실제 동시 실행
- [[Guarded Commands]] : non-deterministic 선택 -> [[병행 제어]] 시 사용
- [[분산 데이터베이스]] 의 병행 투명성 : 다수 [[트랜잭션]] 동시 실현 -> 결과 영향 X

### 데이터베이스 병행제어
- 다중 프로그램 이점 사용 -> 동시 다수 [[트랜잭션]] 병행 수행
- [[데이터베이스|DB]] 일관성 파괴 X 하도록 트랜잭션 상호 작용 제어

### 목적
- DB 공유 최대화
- 시스템 활용도 최대화
- DB 일관성 유지
- 사용자 응답 시간 최소화

### 기법 종류
| 기법 | 내용 |
| --- | --- |
| [[로킹]] (Locking) | 주요 [[데이터]] 상호 배타적 액세스, 액세스 전 Lock 요청 -> 허락 시 액세스 O |
| [[타임 스탬프 순서]] (Time Stamp Ordering) | 실행 시작 전 시간표 부여 -> 부여 시간 따라 작업 수행, [[교착상태]] 발생 X |
| 최적 병행 수행 | 검증 · 확인 · 낙관적 기법, 병행수행 트랜잭션이 판독 전용(Read Only) -> 충돌률 매우 ↓ -> 병행제어 기법 X 해도 일관성 유지 O |
| 다중 버전 기법 | 타임 스탬프 개념 이용, 갱신마다 버전 부여 관리 |

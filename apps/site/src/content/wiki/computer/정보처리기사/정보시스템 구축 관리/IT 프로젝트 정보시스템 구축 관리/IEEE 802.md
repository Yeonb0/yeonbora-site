- [[LAN]] 관련 표준 규격 및 그 표준안

### 주요 표준 규격
| 규격 | 내용 |
| --- | --- |
| 802.1 | 전체 구성, [[OSI 참조 모델]] 관계, 통신망 관리 |
| 802.2 | 논리 링크 제어(LLC) 계층 |
| 802.3 | [[CSMA/CD]] 방식 매체 접근 제어 계층 |
| 802.4 | 토큰 버스 방식 매체 접근 제어 계층 |
| 802.5 | 토큰 링 방식 매체 접근 제어 계층 |
| 802.6 | 도시형 통신망(MAN) |
| 802.9 | 종합 음성 / [[데이터]] [[컴퓨터 네트워크\|네트워크]] |
| 802.11 | 무선 [[LAN]] |

### 802.11 버전
| 버전 | 내용 |
| --- | --- |
| [[IEEE 802.11]] (초기 버전) | ==2.4GHz== 대역 전파 & [[CSMA/CA]] -> 최고 ==2Mbps== |
| 802.11a | ==5GHz== 대역 전파 & [[OFDM]] -> 최고 ==54Mbps== |
| 802.11b | 초기 버전 대역전파 & 기술 -> 최고 ==11Mbps== |
| 802.11e | 부가 기능 표준, 매체 접근 제어(MAC) 계층 수정 -> QoS 지원 |
| 802.11g | ==2.4GHz== 대역 전파 -> 최고 ==54Mbps== |
| 802.11i | 보안 기능 표준, 인증 방식 WPA/WPA2 |
| 802.11n | ==2.4GHz== + ==5GHz== 대역 -> 최고 ==600Mbps== |

### 매체 접근 제어
- [[CSMA/CD]] : 유선에서 데이터 프레임 [[Collision|충돌]] 검출 + 충돌 발생 시 재송신
- [[CSMA/CA]] : 무선 랜에서 매체 empty 확인 후 일정 시간 대기 -> 전송

- 기존 [[운영체제|OS]] 내재 보안 취약점 해소 위해 보안 기능 갖춘 커널 이식 -> 외부 침입으로부터 시스템 자원 보호하는 OS
- 보안 커널 : 보안 기능 갖춘 커널, TCB 기반 [[참조 모니터]] 개념 구현 & 집행

### 보호 대상
- [[메모리]], [[보조기억장치]], [[데이터]], 하드웨어 장치, [[Data Structure|자료 구조]], 명령어, 보호 메커니즘

### 보호 방법
| 방법 | 내용 |
| --- | --- |
| 암호적 분리 (Cryptographic Separation) | 내부 정보 암호화 |
| 논리적 분리 (Logical Separation) | [[프로세스]] 논리적 구역 지정 -> 구역 벗어나는 행위 제한 |
| 시간적 분리 (Temporal Separation) | 동일 시간에 1 프로세스만 수행 -> 동시 실행 보안 취약점 제거 |
| 물리적 분리 (Physical Separation) | 사용자별 특정 장비만 사용하도록 제한 |

### 보안 기능
| 기능 | 내용 |
| --- | --- |
| 식별 · 인증 | 각 접근 주체에 대한 안전 · 고유 식별 · 인증 |
| 임의적 접근통제 | 소속 그룹 or 개인 부여 권한 따라 [[접근 통제]], DAC · 신분 기반 정책 |
| 강제적 접근통제 | 보안 속성 고려 규칙 따라 강제적 통제, MAC · 규칙 기반 정책 |
| 객체 [[재사용(Reuse)\|재사용]] 보호 | 메모리에 기존 데이터 X 하도록 초기화 |
| 완전한 조정 | 우회 불가하도록 모든 접근 경로 완전 통제 |
| 신뢰 경로 | 보안 작업 위한 안전한 경로 제공 |
| 감사 · 감사기록 축소 | 모든 보안 관련 기록(Log) 후 보호 & 축소 |

- 둘 [[이상(Anomaly)|이상]] [[프로세스]] 가 자원 점유 [[state|상태]]에서 다른 프로세스 점유 자원 요구 -> 무한정 대기하는 현상
- [[상호 배제]] 에 의한 문제점

### 발생 필요 충분 조건
| 조건 | 내용 |
| --- | --- |
| [[상호 배제]] (Mutual Exclusion) | 한 번에 한 개 프로세스만 공유 자원 사용 O |
| 점유와 대기 (Hold and Wait) | 최소 1 자원 점유 + 다른 프로세스 사용 중 자원 위해 대기하는 프로세스 존재 |
| 비선점 (Non-preemption) | 다른 프로세스 할당 자원 -> 사용 끝날 때까지 강제 회수 X |
| 환형 대기 (Circular Wait) | 공유 자원 & 공유 자원 대기 프로세스가 원형 구성 |

### 해결 방법
| 방법 | 내용 |
| --- | --- |
| 예방 기법 (Prevention) | 네 조건 중 하나 제거(부정) -> 사전 시스템 제어, 자원 낭비 가장 심함 |
| 회피 기법 (Avoidance) | 발생 시 적절히 회피, [[은행원 알고리즘]] ([[Dijkstra]] 제안) |
| 발견 기법 (Detection) | 시스템 교착상태 발생 점검 -> 교착상태 프로세스 · 자원 발견, 교착상태 발견 [[알고리즘]] · 자원 할당 [[Graph\|그래프]] 사용 |
| 회복 기법 (Recovery) | 교착상태 프로세스 종료 or 할당 자원 선점 -> 회복 |

- [[트래픽 제어]] 관점 -> 교환기 [[Packet|패킷]] [[버퍼]] 포화로 인한 무한 대기

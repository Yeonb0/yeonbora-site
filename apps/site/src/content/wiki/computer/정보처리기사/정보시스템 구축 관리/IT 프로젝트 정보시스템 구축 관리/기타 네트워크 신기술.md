- [[컴퓨터 네트워크|네트워크]] 분야 기타 신기술 용어 모음

### 종류
| 기술 | 내용 |
| --- | --- |
| 징 (Zing) | ==10cm== 이내 ==3.5Gbps== 속도 [[데이터]] 전송 초고속 근접무선 통신, 휴대용 스마트 기기 · 노트북 · 키오스크 |
| NDN (Named Data Networking) | 콘텐츠 자체 정보 & [[Router\|라우터]] 기능만으로 데이터 전송 수행, = 콘텐츠 중심 네트워킹(CCN) |
| 웹 크롤링 (Web Crawling) | 웹에서 자동화 프로그램 이용한 데이터 수집 |
| 올(all)-IP | 기존 통신망 모두 [[IP]] 기반 망으로 통합한 차세대 네트워크 |
| WBAN (Wireless Body Area Network) | 웨어러블 or 몸에 심는(Implant) 형태 센서 · 기기 무선 연결 개인 영역 네트워킹 기술 |
| GIS (Geographic Information System) | 지리적 자료 수집 · 저장 · 분석 · 출력 컴퓨터 응용 시스템, 위성 이용 모든 사물 위치 정보 제공 |
| 애드 혹 네트워크 (Ad-hoc Network) | 고정 유선망 구축 불가 장소 -> 모바일 호스트만으로 네트워크 구축, 기지국 X · 호스트 이동 제약 X · 빠른 망 구성 · 저렴한 비용 |
| 네트워크 슬라이싱 (Network Slicing) | 5G 핵심 기술, 1 물리적 네트워크 -> 다수 가상 네트워크 분리 -> 고객 맞춤형 서비스 |
| WDM (Wavelength Division Multiplexing) | 광섬유 이용 통신 기술, 여러 단말기 동시 통신 회선 사용 |
| LOD (Linked Open Data) | Linked Data + Open Data, 웹상 공개 연계 데이터, 개별 URI 식별 + 링크 정보 부여 -> 상호 연결 웹 지향 |
| [[SSO]] (Single Sign On) | 로그인 1번 -> 개인 가입 모든 사이트 이용 가능 시스템 |
| 스마트 그리드 (Smart Grid) | 정보 기술을 전력에 접목한 전력 IT, 전력선 기반 통신 · 정보 애플리케이션 인프라를 1 시스템 통합 관리 |
| 메타버스 (Metaverse) | 가공(Meta) + 현실 세계(Universe), 사회 · 경제 · 문화 활동 가능한 3차원 가상 세계 |

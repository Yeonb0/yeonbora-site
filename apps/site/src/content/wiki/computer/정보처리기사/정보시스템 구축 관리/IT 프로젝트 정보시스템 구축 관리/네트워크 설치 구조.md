- 정보 전달 위해 통신 규약에 의해 연결한 통신 설비 집합
- 장치의 물리적 위치 따라 분류

### 성형
- 중앙의 중앙 컴퓨터 중심으로 단말장치 연결, = 중앙 집중형
- 포인트 투 포인트(Point-to-Point) 방식
- 단말장치 추가 · 제거 易
- 중앙 컴퓨터 고장 -> 전체 통신망 기능 정지
- 교환 [[뉴런|노드]] 수 가장 少

### 링형
- 이웃 컴퓨터 · 단말장치끼리 포인트 투 포인트 방식 연결, = 루프형
- 분산 · 집중 제어 모두 O
- 단말장치 추가 · 제거, 기밀 보호 難
- 각 단말장치 전송 [[Delay|지연]] 발생 可
- 중계기 수 多
- [[데이터]] 단방향 · 양방향 전송 O

### 버스형
- 1 통신 회선 - 다수 단말장치 연결
- 물리적 구조 간단, 단말장치 추가 · 제거 易
- 단말장치 고장에도 통신망 전체 영향 X
- 기밀 보장 X, 통신 회선 길이 제한 O

### 계층형
- 중앙 컴퓨터 · 일정 지역 단말장치 -> 1 통신 회선 연결, = 분산형
- 이웃 단말장치 -> 일정 지역 내 중간 단말장치로부터 다시 연결
- 분산 처리 시스템 구성 방식
- ![[IT-프로젝트-정보시스템-구축-관리-01.png]]

### 망형
- 모든 지점의 컴퓨터 · 단말장치 서로 연결 -> 노드 연결성 ↑
- 다수 단말장치로부터 다수 통신 필요 시 유리
- 공중 데이터 통신망에서 사용, 통신 회선 총 경로 最長
- 총 노드 $n$ -> 회선 $\frac{n(n-1)}{2}$ 개 필요, 노드당 $n-1$ 개 [[Port|포트]] 필요

- [[정보 보안]] 분야 주요 신기술 용어 모음

### 종류
| 기술 | 내용 |
| --- | --- |
| [[블록체인]] (Blockchain) | P2P [[컴퓨터 네트워크\|네트워크]] 이용, 온라인 금융 거래 정보를 참여자(Peer) 디지털 장비에 분산 저장 |
| 분산 원장 기술 (DLT) | 중앙 관리 · 중앙 [[데이터베이스\|DB]] 존재 X, P2P 망 내 참여자에게 거래 목록 분산 저장, ==ex)== [[블록체인]] |
| 양자 암호키 분배 (QKD) | 양자 통신 위해 비밀키 분배 관리, 두 시스템이 비밀키 안전 공유 위해 운용 |
| 프라이버시 강화 기술 (PET) | 개인정보 위험 관리 기술, 개인정보 보호 ~ 통제 기술 · 다양한 사용자 프라이버시 보호 기술 |
| 비트로커 (BitLocker) | Windows 전용 볼륨 암호화 기능, TPM · AES-128 [[알고리즘]] 사용 |
| 개인정보 영향평가 제도 (PIA) | 새 정보시스템 도입 · 기존 정보시스템 변경 시 사생활 영향 미리 조사 · 분석 · 평가 |
| [[소프트웨어]] 에스크로 (임치) | 소스 프로그램 & 기술 정보를 제 3의 기관 보관 -> 개발자 지식재산권 보호 + 사용자 안정적 사용 · 유지보수 |
| 서비스형 블록체인 (BaaS) | 블록체인 앱 개발 환경을 [[클라우드]] 기반 제공, [[뉴런\|노드]] 추가 · 제거 용이 + 다른 블록체인 기술 편리 사용 |
| OWASP | 웹 정보 노출 · 악성 코드 · 스크립트 · 보안 취약 부분 연구 비영리 단체, 10대 웹 애플리케이션 취약점 ==3 ~ 4년== 주기 발표 |
| [[TCP]] 래퍼 (TCP Wrapper) | 외부 컴퓨터 접속 인가 여부 점검 -> 접속 허용 · 거부 보안용 도구, 사용자 ID · 로그 조회 악용 방지 [[방화벽]] 역할 |
| 허니팟 (Honeypot) | 비정상적 접근 탐지 위해 설치한 시스템, 추적 · 공격기법 정보 수집 |
| DPI (Deep [[Packet]] Inspection) | OSI 7 Layer 전 계층 [[프로토콜]] & 패킷 내부 콘텐츠 파악, 침입 시도 · 해킹 탐지 · 트래픽 조정 패킷 분석 기술 |

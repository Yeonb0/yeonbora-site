- [[사물 인터넷]] 구현에 쓰이는 근거리 · 저전력 · 센서 통신 기술 모음

### 종류
| 기술 | 내용 |
| --- | --- |
| 올조인 (AllJoyn) | 오픈소스 기반 사물인터넷 플랫폼, 서로 다른 [[운영체제\|OS]] · 하드웨어 기기를 표준화 플랫폼으로 통신 · 제어 |
| 메시 [[컴퓨터 네트워크\|네트워크]] (Mesh [[컴퓨터 네트워크\|Network]]) | 차세대 이동통신 · 홈네트워킹 · 공공 안전 등 특수 목적용, 수십 ~ 수천 디바이스 그물망처럼 유기적 연결 -> 안정적 [[컴퓨터 네트워크\|네트워크]] |
| 와이선 (Wi-SUN) | 저전력 장거리(LPWA) 통신 기술, 낮은 [[Delay\|지연]] 속도 + 메시 네트워크 기반 확장성 + 펌웨어 업그레이드 용이 |
| UWB 초광대역 (Ultra WideBand) | 짧은 거리에서 대량 디지털 [[데이터]]를 낮은 전력으로 전송하는 무선 기술 = 무선 디지털 펄스 |
| 피코넷 (PICONET) | 여러 독립 통신장치가 블루투스 or UWB 로 통신망 형성, 수십 m 이내 좁은 공간, 정지 · 이동 장치 모두 포함 |
| USN (Ubiquitous Sensor Network) | 각종 센서로 다양한 정보 무선 수집, 모든 것에 RFID 태그 부착 -> 정보 · 데이터 관리 |
| 유비쿼터스 컴퓨팅 (Ubiquitous Computing) | 언제 어디서나 어떤 기기로도 컴퓨팅 가능한 환경, 모든 사물에 초소형 칩 내장 |
| BLE (Bluetooth Low Energy) | 블루투스와 동일 ==2.4GHz== 대역, 미연결 대기 [[state\|상태]] 절전 모드 유지 -> 극소형 사물 인터넷 적합 |
| NFC (Near Field Communication) | 고주파(HF) 이용 근거리 무선 통신, 초근거리 양방향 통신 지원 RFID 일종, ==13.56MHz== 대역 ==10cm== 내 최고 ==424Kbps== |

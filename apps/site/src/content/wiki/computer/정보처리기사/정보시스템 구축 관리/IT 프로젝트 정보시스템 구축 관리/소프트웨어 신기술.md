- [[소프트웨어]] 분야 주요 신기술 용어 모음

### 종류
| 기술 | 내용 |
| --- | --- |
| [[인공지능]] (AI) | 컴퓨터 스스로 추론 · 학습 · 판단하는 인간지능적 작업 수행 시스템, 응용 분야 -> [[신경망]] · 퍼지 · 패턴 인식 · 전문가 시스템 · 자연어 인식 · 이미지 처리 · 컴퓨터 시각 · 로봇 공학 |
| 뉴럴링크 (Neurallink) | 일론 머스크가 사람 뇌 & 컴퓨터 결합 기술 개발 위해 설립한 회사, 작은 전극 뇌 이식 -> 생각 업로드 & 다운로드 |
| [[딥 러닝]] (Deep Learning) | 인간 두뇌 모델 인공 신경망(ANN) 기반 기계 학습 기술, 스스로 [[데이터]] 수집 · 분석해 고속 처리 |
| 전문가 시스템 (Expert System) | 특정 분야 전문가 수행 고도 업무 지원 응용 프로그램, 지식 베이스 [[데이터베이스\|DB]] + 추론 기구(Inference Engine) 활용 |
| 가상현실 (VR) | 컴퓨터로 실제와 유사하나 실제 X 환경 · 상황 구현 |
| 증강현실 (AR) | 실제 촬영 화면에 가상 정보 부가 |
| 혼합현실 (MR) | 가상현실 + 현실 세계 -> 현실 물리적 객체 & 가상 객체 상호 작용 환경 |
| 그레이웨어 (Grayware) | 제공 입장 유용 ↔ 사용자 입장 유용 or 악의적, 애드웨어 · 트랙웨어 · 악성 공유웨어 |
| 매시업 (Mashup) | 웹 제공 정보 · 서비스 이용 -> 새 소프트웨어 · 서비스 · [[데이터베이스\|DB]] 생성 |
| RIA (Rich Internet Application) | 플래시 애니메이션 기술 + [[웹 서버]] 애플리케이션 기술, HTML 보다 역동적 · 인터랙티브 웹페이지 |
| 시맨틱 웹 (Sementic Web) | 컴퓨터가 사람 대신 정보 읽고 이해 · 가공 -> 새 정보 생성하는 지능형 웹, 자원 서술 · 지식 서술 · 에이전트 기술 |
| 증발품 (Vaporware) | 판매 · [[Vercel\|배포]] 계획 발표 O 실제 판매 · [[Vercel\|배포]] X 소프트웨어 |
| OGSA (Open Grid Service Architecture) | 앱 공유 위한 웹 서비스를 그리드 상에서 제공하기 위한 개방형 표준 |
| SOA (Service Oriented Architecture) | 소프트웨어 인프라 정보시스템을 서비스 · [[컴포넌트]] 중심 구축, 공유 · [[재사용(Reuse)\|재사용]] O, 계층 -> 표현 · 업무 프로세스 · 서비스 중간 · 애플리케이션 · 데이터 저장 |
| [[SaaS]] (Software as a Service) | 소프트웨어 기능 중 사용자 필요 서비스만 이용, 공급업체 1 플랫폼 -> 다수 고객 제공 |
| CEP (Complex [[Event]] Processing) | 실시간 다양 사건 중 의미 있는 것만 추출하도록 사건 발생 조건 정의, 대용량 데이터 스트림 실시간 대응 |
| 디지털 트윈 (Digital Twin) | 현실 속 사물 소프트웨어 [[서버 가상화\|가상화]] -> 모의 실험 |
| 텐서플로 (TensorFlow) | 데이터 흐름 프로그래밍 위한 오픈소스 소프트웨어 라이브러리 |
| [[Docker\|도커]] ([[도커\|Docker]]) | [[서버 컨테이너\|컨테이너]] 기술 자동화 오픈소스 프로젝트, 소프트웨어 [[서버 컨테이너\|컨테이너]] 안 응용 프로그램 [[배치 처리\|배치]] 자동화 |
| 스크래피 (Scrapy) | [[Python]] 기반 웹 크롤링 [[프레임워크]], 코드 재사용성 ↑ -> 대규모 크롤링 프로젝트 |

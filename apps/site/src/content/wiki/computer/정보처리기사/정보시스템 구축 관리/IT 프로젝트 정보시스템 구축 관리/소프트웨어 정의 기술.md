- [[컴퓨터 네트워크|네트워크]] · [[데이터 센터]] 소유 자원 [[서버 가상화|가상화]] -> 개별 사용자 제공
- 중앙 통합적 제어 O

### 종류
| 기술 | 내용 |
| --- | --- |
| SDN (Software Defined Networking) | 네트워크를 컴퓨터처럼 모델링 -> 여러 사용자가 각 [[소프트웨어]] 로 네트워킹 가상화해 제어 · 관리 |
| SDDC (Software Defined Data Center) | [[데이터 센터]] 모든 자원 가상화 -> 인력 개입 X 소프트웨어 조작만으로 관리 · 제어 |
| SDS (Software-Defined Storage) | 물리적 [[데이터]] [[스토리지]] 가상화 -> 여러 스토리지를 하나처럼, 하나를 여러 개처럼 |

### SDN 특징
- 하드웨어 의존 네트워크 체계 대비 효율적 네트워크 제어 · 관리
- 기존 네트워크 영향 X + 특정 서비스 전송 경로 수정 -> 인터넷상 발생 문제 처리

- [[클라우드]] 컴퓨팅의 연계 · 보안 · 플랫폼 관련 기술 모음

### 종류
| 기술 | 내용 |
| --- | --- |
| 인터클라우드 컴퓨팅 (Inter-Cloud Computing) | 여러 클라우드 서비스 · 자원 연결 기술, 대등 접속(Peering) -> 클라우드 서비스 제공자 간 직접 연계 |
| 클라우드 기반 HSM (Cloud-based Hardware Security [[모듈\|Module]]) | 클라우드 기반 암호화 키 생성 · 저장 · 처리 보안기기, 클라우드에 인증서 저장 -> 개별 기기 저장 X, 암호화 키 생성 in 하드웨어 -> 소프트웨어 취약점 무시 |
| 파스-타 (PaaS-TA) | [[소프트웨어]] 개발 환경 개방형 클라우드 컴퓨팅 플랫폼, 인프라 제어 · 관리 · 실행 · 개발 · 서비스 · 운영 환경 제공 |

### 서비스 유형
- [[IaaS]] : 하드웨어([[서버]] · [[스토리지]] · [[컴퓨터 네트워크|네트워크]]) 자원 [[서버 가상화|가상화]]
- [[PaaS]] : 소프트웨어(런타임 · [[미들웨어]] · [[운영체제|OS]]) 작성 플랫폼 가상화
- [[SaaS]] : 사용자 필요 소프트웨어 가상화

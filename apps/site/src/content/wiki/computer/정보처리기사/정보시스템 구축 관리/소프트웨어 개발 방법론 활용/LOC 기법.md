- [[소프트웨어]] 각 기능 원시 코드 라인 수의 비관치 · 낙관치 · 기대치 측정 -> 예측치로 비용 산정
- [[상향식 비용 산정 기법]] 의 하나

### 종류
- 비관치 : 가장 많이 측정된 코드 라인 수
%% check : 비관치는 측정된 값 중 가장 큰 코드 라인 수 %%
- 낙관치 : 가장 적게 측정된 코드 라인 수
- 기대치 : 측정된 모든 코드 라인 수의 평균

$$
예측치 = \frac {낙관치 + 기대치\times4 + 비관치}{6}
$$

### 산정 공식
- 노력(인월) = 개발 기간 × 투입 인원 = LOC / 1인당 월평균 생산 코드 라인 수
- 개발 비용 = 노력(인월) × 단위 비용(1인당 월평균 인건비)
- 개발 기간 = 노력(인월) / 투입 인원
- 생산성 = LOC / 노력(인월)

- [[소프트웨어]] 처리 개선 · 능력 평가 기준
- 정보 시스템 분야 소프트웨어 프로세스 평가 · 개선 국제 표준
- = ISO/IEC 15504

### 목적
- 프로세스 개선 위해 개발 기관 스스로 평가
- 기관 지정 요구조건 만족여부 개발 조직 스스로 평가
- 계약 체결 위해 수탁 기관 프로세스 평가

### 종류
- 프로젝트 범주 ==5== / 세부 프로세스 ==40==
	- 고객-공급자(Customer-Supplier) 프로세스
	- 공학(Engineering) 프로세스
	- 지원(Support) 프로세스
	- 관리(Management) 프로세스
	- 조직(Organization) 프로세스

### 상태
| 수준 | 내용 |
| --- | --- |
| Lv 0 - 불완전(Incomplete) | 프로세스 구현 X or 목적 달성 X |
| Lv 1 - 수행(Performed) | 프로세스 수행 & 목적 달성 |
| Lv 2 - 관리(Managed) | 정의 자원 한도 내 프로세스가 작업 산출물 인도 |
| Lv 3 - 확립(Established) | [[소프트웨어 공학]] 원칙 기반 정의 프로세스 수행 |
| Lv 4 - 예측(Predictable) | 프로세스가 목적 달성 위해 통제, 양적 측정 통해 일관되게 수행 |
| Lv 5 - 최적화(Optimizing) | 프로세스 수행 최적화 지속적 개선 통해 업무 목적 만족 |

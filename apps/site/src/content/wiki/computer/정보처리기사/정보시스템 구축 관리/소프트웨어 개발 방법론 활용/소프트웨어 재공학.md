- 새 요구 맞도록 기존 시스템 이용 -> 시스템 개선 · 새 기능 추가해 [[소프트웨어]] 성능 향상
- 유지보수 비용 문제 염두 -> 기존 소프트웨어 [[데이터]] & 기능 개조 · 개선 -> 유지보수성 · 품질 ↑
- 기존 소프트웨어 기능 개조 & 개선 -> ==예방(Preventive)== 유지보수 측면 소프트웨어 위기 해결법
- 소프트웨어 수명 · 기술 ↑, 개발 기간 ↓, [[Error|오류]] · 비용 ↓

### 주요 활동
| 활동 | 내용 |
| --- | --- |
| 분석(Analysis) | 기존 소프트웨어 명세서 확인 -> 동작 이해, 재공학 대상 선정 |
| 재구성(Restructuring) | 기존 소프트웨어 구조 향상 위해 코드 재구성. 기능 & 외적 동작 변화 X |
| [[역공학]](Reverse Engineering) | 기존 소프트웨어 구조 분석 -> 개발 과정 · 데이터 처리 과정 분석 · 설계 정보 재발견 or 재제작<br>일반적 개발 반대 방향 -> 기존 코드 복구 or 구성요소 관계 파악해 설계도 추출 |
| 이식(Migration) | 기존 소프트웨어 -> 다른 [[운영체제\|OS]] or 하드웨어 환경에서 사용하도록 변환 |

- 동일 키로 [[데이터]] 암호화 & 복호화
- = 대칭 암호 기법, 비밀키 암호화 기법
- 평문 M -> 암호화 [[알고리즘]] E(K:M) -> 암호문 C -> 복호화 알고리즘 D(K:C) -> 평문 M
- 암호화 대상 n개 사용 키 개수 $\frac{n(n-1)}{2}$

### 종류
- 블록 암호화 방식 : 1번에 한 데이터 블록 암호화
	- ==ex)== DES, SEED, AES, ARIA, IDEA
- 스트림 암호화 방식 : 평문 동일 길이 스트림 생성 -> [[비트]] / [[바이트]] / [[워드]] 단위 암호화
	- ==ex)== LFSR, RC4

### 장점
- 암호화 / 복호화 속도 ↑
- 알고리즘 단순, 파일 크기 ↓

### 단점
- 사용자 ↑ -> 관리 키 수 ↑

### 보안 약점
| 보안 약점 | 내용 |
| --- | --- |
| 적절한 인증 없이 중요기능 허용 | 보안검사 우회 -> 인증 과정 없이 주요 정보 or 기능 접근 · 변경 |
| 부적절한 인가 | 접근제어 기능 없는 실행경로 통해 정보 · 권한 탈취 |
| 중요 자원 대한 잘못된 권한 설정 | 권한 설정 잘못된 자원 접근 -> 자원 임의 사용 O |
| 취약한 [[암호 알고리즘]] 사용 | 암호화 환경설정 파일 해독 -> 비밀번호 중요정보 탈취 O |
| 중요정보 평문 저장 · 전송 | 암호화 X 평문 [[데이터]] 탈취 -> 주요 정보 획득 O |
| 하드코드 된 비밀번호 | 소스코드 유출 시 내부 하드코드 패스워드 이용 -> 관리자 권한 탈취 |

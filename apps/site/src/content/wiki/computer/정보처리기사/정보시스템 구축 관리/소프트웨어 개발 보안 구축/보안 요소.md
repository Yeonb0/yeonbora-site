### 종류
| 요소 | 내용 |
| --- | --- |
| 기밀성 | 시스템 내 정보 & 자원 -> 인가 사용자만 접근 O<br>정보 전송 중 노출 -> [[데이터]] 읽기 X |
| 무결성 | 시스템 내 정보 -> 인가 사용자만 수정 O |
| 가용성 | 인가받은 사용자 언제나 사용 O |
| 인증 | 시스템 내 정보 & 자원 사용 원하는 사용자 합법적 확인 |
| 부인 방지 | 송 · 수신 증거 제공 |

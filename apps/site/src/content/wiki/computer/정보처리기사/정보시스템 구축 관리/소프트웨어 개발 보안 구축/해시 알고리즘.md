- 임의 길이 입력 [[데이터]] or 메시지 -> 고정 길이 값 or 키 변환
- 해시 [[알고리즘]] = 해시 [[함수]] ([[Hash Function]])
- 해시값 · 해시키 : 해시 함수로 변환된 값
- 복호화 거의 불가능 일방향 함수 -> 단방향 [[암호 알고리즘]]
- 동일 원문 동일 해시값 -> 회피 수단 [[솔트]]

### 종류
| 알고리즘 | 내용 |
| --- | --- |
| SHA 시리즈 | ==1993년== 미국 국가안보국(NSA) 설계, 미국 국립표준기술연구소(NIST) 발표 |
| MD5 | ==1991년== R.Rivest 고안 암호화 해시 함수<br>블록 크기 512비트, 키 길이 128비트 |
| N-NASH | ==1989년== 일본 전신전화주식회사(NTT) 발표 암호화 해시 함수<br>블록 크기 · 키 길이 128비트 |
| SNEFRU | ==1990년== R.C.Merkle 발표 해시 함수<br>32비트 프로세스 구현 용이<br>블록 크기 512비트, 키 길이 128 / 256 |

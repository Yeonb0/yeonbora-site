- [[컴퓨터 네트워크|네트워크]] 경로 이용 정보 탈취 · 서비스 방해 공격 유형 모음

### 종류
| 용어 | 내용 |
| --- | --- |
| 스미싱(Smishing) | 문자 메시지(SMS) 이용 개인 신용 정보 탈취 / 개인 비밀번호 · 소액 결제 유도 |
| 스피어 피싱(Spear Phishing) | 특정 대상 선정 후 일반적 이메일로 위장한 메일 지속 발송 -> 개인 정보 탈취 |
| APT(Advanced Persistent Threats) | 지능형 지속 위협, 다양 IT 기술 & 방식 이용 조직적 침투 후 보안 무력화 & 정보 수집 / 공격법 : 이메일 발송 · 악성코드 USB · 악성코드 P2P 사이트 |
| 무작위 대입 공격([[Brute Force]] Attack) | 암호화 문서 암호키에 모든 값 대입 |
| 큐싱(Qshing) | QR 코드로 악성 앱 · 프로그램 설치 유도 |
| 피싱(Phishing) | 개인 정보(Private Data) + 낚시(Fishing), 이메일 · 메신저 사칭 |
| Ping Flood | 특정 사이트에 매우 많은 [[ICMP]] 메시지 전송 -> 응답으로 시스템 자원 소모 |
| Evil Twin Attack | 동일 무선 WiFi [[신호]] 송출 -> 로그온 사용자 계정 정보 · 신용 정보 탈취 |
| 스위치 재밍(Switch Jamming) | 위조 [[MAC 주소]] 네트워크 흘려보냄 -> [[MAC Address\|MAC 주소]] 테이블 기능 혼란 |

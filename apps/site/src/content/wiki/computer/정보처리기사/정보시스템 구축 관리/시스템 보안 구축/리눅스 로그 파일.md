- 리눅스가 [[로그]] 종류별로 분리 기록하는 파일 집합

### 종류
| 구분 | 데몬 | 경로 | 내용 |
| --- | --- | --- | --- |
| 커널 로그 | kernel | /dev/console | 커널 관련 내용 관리자에게 알리기 위해 파일 저장 X -> 지정 장치 표시 |
| 커널 로그 | kernel | [[var]]/log/wtmp | 성공 로그인 · 로그아웃 기록 / 시스템 시작 · 종료 기록 |
| 커널 로그 | kernel | var/run/utmp | 현재 로그인 사용자 기록 |
| 커널 로그 | kernel | var/log/btmp | 실패 로그인 기록 |
| 커널 로그 | kernel | var/log/lastlog | 마지막 성공 로그인 기록 |
| 부팅 로그 | boot | /var/log/boot | 부팅 시 나타나는 메시지 기록 |
| 크론 로그 | crond | /var/log/cron | 작업 스케줄러 crond 작업 내역 기록 |
| [[syslog\|시스템 로그]] | syslogd | /var/log/messages | 커널 실시간 전송 메시지 기록 |
| 보안 로그 | xinetd | /var/log/secure | 시스템 접속 기록 |
| FTP 로그 | ftpd | /var/log/xferlog | [[FTP]] 접속 사용자 기록 |

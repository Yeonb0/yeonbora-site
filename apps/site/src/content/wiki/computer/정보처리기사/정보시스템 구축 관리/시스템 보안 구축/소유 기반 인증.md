- 사용자 소유물 기반 [[인증]] 수행
- 소유물 도용 가능 -> [[지식 기반 인증]] · [[생체 기반 인증]] 병행

### 종류
- 신분증 : 사용자 사진 포함 주민등록증 / 운전면허증 / 여권
- [[메모리]] 카드(토큰) : 마그네틱 선에 보안 코드 저장
- 스마트 카드 : 마이크로프로세서 · 카드 [[운영체제]] · [[Memory|메모리]] 구성
- OTP(One Time Password) : 패스워드 요청마다 암호 [[알고리즘]]으로 새 패스워드 생성

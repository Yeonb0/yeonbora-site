- 악성코드 · 취약점 이용 시스템 장악 · 정보 탈취 공격 유형 모음

### 종류
| 용어 | 내용 |
| --- | --- |
| 좀비(Zombie) [[프로그램 카운터\|PC]] | 악성코드 감염 컴퓨터 -> C&C 서버 제어 받아 [[DDoS]] 공격 활용 |
| C&C 서버 | 해커가 원격지에서 좀비 PC 명령 & 악성코드 제어 위한 [[서버]] |
| 봇넷(Botnet) | 악성 프로그램 감염 컴퓨터들의 [[컴퓨터 네트워크\|네트워크]] |
| 웜(Worm) | [[컴퓨터 네트워크\|네트워크]] 통해 연속적 자신 [[레플리케이션\|복제]] -> 시스템 다운 / 형태 : [[DDoS]] 공격, [[버퍼 오버플로]] 공격, 슬래머 |
| 제로 데이 공격(Zero Day Attack) | 보안 취약점 공표 이전 공격, 공격의 신속성 |
| 키로거 공격([[키(Key)\|Key]] Logger Attack) | 컴퓨터 사용자 키보드 움직임 탐지 -> 개인 정보 탈취 |
| 랜섬웨어(Ransomware) | 컴퓨터 잠입해 내부 문서 · 파일 암호화 -> 사용자 열람 불가 |
| 백도어(Back Door) | 시스템 설계자 · 서비스 기술자가 편의 위해 보안 제거해 둔 비밀 통로 / 탐지 방법 : [[무결성]] 검사, 열린 [[Port\|포트]] 확인, [[로그]] 분석, SetUID 파일 검사 |
| 트로이 목마(Trojan Horse) | 정상 기능 위장 -> 동작 시 활성화되어 [[Side Effect\|부작용]] |
| 파밍(Pharming) | 해커가 악성코드 감염 PC 조작해 중간 도메인 탈취 -> 개인 정보 · 금융 정보 탈취 |

- 사용자 기억 정보 기반 [[인증]] 수행

### 특징
- 사용자 기억 기반 -> 관리 비용 ↓
- 사용자 기억 실패 -> 본인이라도 인증 X

### 종류
- 고정된 패스워드(Password) : 접속 시마다 알고 있는 비밀번호 반복 입력
- 패스 프레이즈(Passphrase) : 일반 패스워드보다 길이 ↑, 기억 쉬운 문장 활용 구성
- 아이핀(i-PIN) : 인터넷상 사이버 주민등록번호, 사용자 신원확인 -> 본인확인기관 온라인 발행

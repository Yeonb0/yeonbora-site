- Frequency & Time 으로 통신 channel 을 여러 개로 분할하는 [[Multiple Access]] 방식

### 종류
- [[FDMA]] : frequency 분할
- [[TDMA]] : time 분할
- [[CDMA]] : code 분할
- [[OFDMA]] : frequency + time 분할

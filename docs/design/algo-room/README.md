# 알고리즘 방 디자인

목업 캔버스 : "알고리즘 방 목업 3안" (Design 아티팩트) 의 `Garden` 대지. `garden-4-times.png` 는 로컬 시제품에서 찍은 새벽 · 낮 · 노을 · 밤 화면.

## 화면 은유
젤다 (야생의 숨결) 풍 꽃밭. 화면 전체가 앞쪽 위에서 비스듬히 내려다본 풀밭이고, Algoristro 카테고리 12개가 꽃 한 송이씩 줄기 위로 피어 있다. 꽃을 누르면 그 꽃으로 확대되며 Algoristro 목록 화면 (Notion 다크, 목업 A안) 으로 넘어간다.

## 꽃
- 꽃 종류 : 카테고리 알고리즘 수와 꽃잎 수 (피보나치로 알려진 대표 수) 가 가장 가까운 실제 꽃. L (6) 백합, F (11) 개쑥갓, B (15) · E (16) 시네라리아, C (15) · G (16) 콘마리골드, A (16) 루드베키아, J (17) 치커리, K (27) 애스터, D (43) 제충국, I (44) 해바라기, H (64) 미국쑥부쟁이. 13장 꽃이 여섯 송이라 네 종류를 번갈아 썼다.
- 색 : 그 카테고리의 티어 비율을 대략적인 파스텔 색 조합으로 (색 구분이 정확하지 않아도 됨, 2026-11-25 결정).
- 그림 : Figma AI (generate_vector_illustration) 로 그린 파스텔 · 셀 셰이딩 꽃. Figma 파일 "알고리즘 방 꽃" 에서 내보낸 PNG 의 회색 배경을 지워 `assets/flowers/<카테고리>.png` 로 저장.
- 원근 : 먼 (위쪽) 꽃일수록 작고, 채도 · 대비가 낮다. 꽃 머리 아래로 풀 뭉치 두 개가 지나가 풀 속에 있는 것처럼 보인다. 줄기 · 잎 색은 시간대 풀 색에서 뽑는다.

## 풀밭
- 풀 뭉치 (한 장에 풀잎 5 ~ 8장) 약 7,700개를 원근에 맞춰 깐다. 큰 얼룩 무늬 (값 노이즈 두 겹) 로 밝고 어두운 자리가 생기고, 멀수록 안개가 낀다. 뭉치 밑동은 투명하게 풀어 땅과 섞인다.
- 살랑임 : 일부 뭉치를 가로 띠 캔버스 5장에 한 번 그려 두고 CSS 로 띠를 기울인다 (매 프레임 다시 그리지 않아 60fps). 맨 앞 흐린 풀도 한 번만 흐리게 그린다.
- 마우스 · 손가락 : 닿은 풀만 스프링으로 꺾이고, 그 주변만 다시 그린다.
- 시간대 (접속 시각) : 새벽 5 ~ 8시 · 낮 8 ~ 17시 · 노을 17 ~ 20시 · 밤 20 ~ 5시. 밤에는 꽃이 은은하게 빛난다. 화면 아래쪽은 시간대 색의 밝은 막으로 밝힌다.

## 상호작용
- 들어올 때 : 허브 알고리즘 칸 색 (#a21caf) 이 가운데부터 걷히며 꽃밭이 드러난다.
- 꽃 호버 · 포커스 : 꽃이 조금 커지고 다른 꽃은 옅어지며, 위에 카테고리 글자 · 이름 · 알고리즘 수가 뜬다.
- 꽃 클릭 : 확대 → 목록 화면 (BOJ 티어 보드 / solved.ac class). 주소는 `#cat=<코드>` (전체는 `#cat=all`). 검색어가 아니라 해시를 쓰는 까닭은 Astro 화면 전환 라우터가 해시만 바뀐 앞 · 뒤로 가기를 페이지를 다시 불러오지 않고 처리하기 때문.
- 돌아가기 : 사이드바 맨 위 꽃 아이콘 · Esc · 뒤로가기. 꽃밭이 줄어들며 돌아온다.
- 좁은 화면 : 세로 배치 (720 x 1280 설계) 로 꽃을 다시 놓고, 목록은 사이드바가 위쪽 가로 줄, 티어 보드는 옆으로 넘긴다.

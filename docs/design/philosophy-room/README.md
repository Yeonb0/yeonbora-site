# 철학 방 디자인

설계 : `docs/superpowers/specs/2026-11-25-philosophy-room-design.md`
장면 원본 : Figma "yeonbora-site · 철학 방 장면"

`mockup.html` 은 저장소의 실제 장면 사진 (`apps/site/src/sections/philosophy/assets/`) 을 그대로 불러 쓰는 시안이다. 문 · 명판 · 액자 위치는 `scenes.ts` 와 같은 값이고, 액자 배치는 `hang.ts` 와 같은 규칙이다. 초상화는 아직 자리표시 그림이다 (Task 6 에서 퍼블릭 도메인 회화로 바꾼다).

## 목업에서 정한 것
- 서양관 명판은 문 아치 위, 폭 11% · 높이 3.8%. CONTEMPORARY 가 들어가도록 넷 다 같은 폭.
- 동양관 명판은 문틀 위, 한자 한 글자가 들어가는 작은 판 (설계의 세로형 대신). 문틀 위 공간이 낮아서.
- 액자 줄 사이 간격 5.5% : 호버하면 나타나는 이름표가 아래 줄 액자를 가리지 않게.

## 1차 피드백 반영 (2026-11-25)
- 갈림길 아치 : 호버하면 아치 안쪽 복도가 밝아지고 (backdrop-filter brightness 1.85), 아치 둘레와 바닥으로 따뜻한 빛이 번진다.
- 명판 : 서양관은 아치 쐐기돌에 붙여 달고, 동양관은 문틀 위 벽에 붙인다. 원형 벽의 곡면을 따라 문 위치에 맞춰 기울인다 (가운데에서 멀수록 최대 24도). 주변 조명 색 (따뜻한 톤) 을 입히고, 위에서 오는 조명에 맞춰 판 아래로 그림자를 떨군다. 글자는 살짝 파인 흰 글자.
- 인물 조명 : 둥근 빛 대신 천장 조명에서 액자로 내려오는 원뿔 스포트라이트. 원뿔 안의 벽이 액자 아래까지 부채꼴로 밝아지고, 공기 중에 옅은 빛줄기가 보인다. 액자 아래에서 빛이 사라진다.

## 2차 피드백 반영 (2026-11-25)
- 갈림길 아치 : 빛이 아치 아래 바닥과 둘레 벽으로 더 넓게 번진다.
- 명판을 뺐다. 문에 호버하면 문이 열린 뒤 문틈 너머 전시실 벽에 이름 (ANCIENT · 儒 …) 이 떠오른다. 모바일은 호버가 없으니 문 앞 바닥에 이름을 늘 보인다.
- 액자 이름표도 판 대신 액자 아래 벽에 쓰인 글자로 바꿨다. 스포트라이트를 받을 때만 보인다.
- 액자를 줄 맞춰 걸지 않고 살롱식으로 흩어 건다 (hang.ts : 철학자 목록으로 만든 시드의 난수, 큰 액자는 벽 가운데 눈높이 근처).
- 액자 테두리는 나무 결. 서양관은 호두나무, 동양관은 더 짙은 나무.

## 3차 피드백 반영 (2026-11-25)
- 갈림길 아치 아래쪽 빛을 줄였다.
- 문틈 이름 : 글자 간격을 없애고 문 폭에 맞춰 크기를 정한다 (CONTEMPORARY 도 문틈 안에 들어감). 문이 열리기 시작하고 0.12초 뒤에 바로 나타난다.
- 액자 배치 : 가운데로 모으지 않고 벽 전체에 고르게 흩어 건다 (best-candidate). 관리자님 참고 사진 (크기가 제각각인 액자 · 진열창이 벽 전체에 흩어진 벽) 느낌.
- 액자 이름 : 액자 바로 아래, 액자 폭 안에 맞춘 밝은 글자. 옆 액자를 침범하지 않는다.
- 스포트라이트 : 각도를 좁히고 경계를 또렷하게 (둥근 웅덩이 빼고 각진 원뿔). 빛은 중간에서 끊기지 않고 벽을 타고 바닥까지 내려가 바닥에서 서서히 옅어진다.

## 4차 피드백 반영 (2026-11-25)
- 문틈 너머 : 흐린 전시실 사진 대신 참고 사진처럼 어두운 입구 벽을 둔다. 둘레에 따뜻한 빛이 돌고, 이름은 밝은 글자로 잘 읽힌다. 문틈으로 들어갈 때는 이 어두운 벽에서 전시실이 밝아지며 나타난다.
- 스포트라이트 : 각진 원뿔을 버리고, 천장 조명에서 액자까지 내려오는 부드러운 빛기둥 (가운데가 밝고 가장자리가 흐려짐) + 액자를 감싸는 둥근 빛 웅덩이로 표현한다 (관리자님 참고 사진 : 3도 · 8도 · 15도 조명, 미술관 벽 그림 조명).

## 5차 피드백 반영 (2026-11-25)
- 문틈 둘레의 빛 테두리를 뺐다. 어두운 벽과 밝은 글자만 남긴다.
- 스포트라이트 : 빛기둥과 웅덩이를 따로 그리지 않고 한 덩어리로. 천장 조명에서 좁게 시작해 아래로 퍼지고 (액자 높이에서 액자 폭의 1.5배), 가장자리는 넓게 흐리며, 액자 아래로 길게 내려와 둥글게 사라진다.

## 뒤로가기 (2026-11-25)
- 뒤로가기 버튼을 없앤다. 화면 아래쪽 띠 (높이 16%) 에 마우스를 대면 바닥이 \\__/ 모양 (가운데는 낮게, 양옆은 높게) 으로 은은하게 밝아지고, 누르면 한 단계 뒤 장면으로 간다. Esc 도 같다.
- 갈림길에서도 같은 띠가 있고, 누르면 허브 (메인 화면) 로 나간다.
- 모바일은 아래쪽 띠가 늘 옅게 밝아 있고, 탭하면 뒤로 간다.
- 홈 버튼 (공용) 은 그대로 둔다.

# 철학 방 초상화 후보

모두 퍼블릭 도메인 회화 · 판화로 고른다. 조각을 찍은 사진은 사진가에게 저작권이 있는 경우가 많아 쓰지 않는다.
링크는 위키미디어 커먼즈 검색 결과다. 마음에 드는 그림을 골라 원본 파일을 받고, 파일 이름을 아래 `파일` 칸대로 바꿔 zip 으로 올린다.
받을 때 그 그림의 커먼즈 페이지 주소도 함께 적어 주면 `portraits/CREDITS.md` 에 출처로 남긴다.

## 서양관 고대 : 한 그림에서 잘라 화풍을 맞춘다

라파엘로 「아테네 학당」 (1509 ~ 1511, 바티칸) 에서 얼굴 부분을 잘라 쓴다. 고화질 원본 하나만 받으면 된다.

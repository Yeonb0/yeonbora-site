# 종교학 방 디자인

`mockup.html` 은 종교학 방의 목업이다 (2차). 같은 폴더의 `velvet.webp` · `velvet-tall.webp` · `badges.js` 를 불러 쓰고, three.js 0.170.0 을 jsDelivr 에서 받는다.

## 화면 은유
검은 가죽 진열 상자. 들어오면 허브 칸 색 (#9333ea) 이 걷히고, 상자가 떠오르고, 걸쇠 2개가 젖혀진 뒤 유리 뚜껑이 뒤쪽 경첩을 축으로 열린다. 안쪽에 빨간 벨벳 방석 하나가 꽉 차 있고, 방석의 오목하게 눌린 자리 8곳에 종교 상징 뱃지가 하나씩 박혀 있다.

## 재질
- 방석 : Figma AI (gpt-image-2.5-flare) 로 만든 실사 이미지 하나. 무광 벨벳, 2 x 4 로 눌린 자리 (단추 없음), 테두리 끈 · 술 없음. 원본은 Figma "yeonbora-site · 종교학 방 방석" 의 세 번째 프레임. 검은 배경을 지워 `velvet.webp` 로, 휴대폰용은 왼쪽으로 90° 세워 `velvet-tall.webp` 로 저장. 눌린 자리 좌표는 이미지에서 찾아 `mockup.html` 의 `Tufts` 에 비율로 적었다.
- 뱃지 : `badges.py` (shapely) 가 평면 도형 3층 (바탕 금속 · 에나멜 · 솟은 금속선) 을 만들어 `badges.js` 로 내보내고, three.js 가 층마다 두께를 주어 돌출한다. 금은 광낸 금 (반사색 1.0 · 0.78 · 0.36, 옅은 잔 흠집 · 얼룩) 이고 반사 환경은 HDR 스튜디오 파노라마 (소프트박스 · 세로 띠 조명 4개 · 스폿). 면은 가로로만 살짝 굽은 것처럼 법선을 줘서 (원통형, 0.28) 반사가 세로 일자 띠로 흐른다. 마우스 쪽 뱃지는 금이 훨씬 밝아지고 (envMapIntensity 0.28 + 3.4 × 가까움), 마우스 앞에 세로로 긴 가는 조명 (RectAreaLight) 을 세워 두어 금에 세로 일자 반사가 생긴다. 실제 광원이라 뱃지를 옆으로 돌리면 면 각도에 맞게 반사가 움직이거나 사라진다 (처음에는 화면에 띠를 그렸는데, 돌렸을 때 어색해서 바꿨다). 색 면은 무광 (roughness 0.92). 테두리 · 금선은 얇게 (2.2 / 약 1.4).
- 빛 : 뱃지는 기울지 않는다. 마우스 자리 위에 작은 손전등 (PointLight) 이 따라다니고, 마우스에 가까운 뱃지일수록 금이 주변 빛을 더 비춘다 (뱃지마다 재질을 따로 두고 envMapIntensity 를 거리로 조절). 그래서 마우스 쪽 뱃지만 반짝이고 나머지는 차분하다. 뚜껑이 열린 뒤에는 빛이 왼쪽에서 오른쪽으로 지나가며 뱃지를 하나씩 밝힌다. 마우스가 없는 기기는 빛이 천천히 뱃지 사이를 오가고, prefers-reduced-motion 에서는 움직이지 않는다. 들어 올린 뱃지는 마우스 쪽으로 반사 환경이 돈다.

## 상호작용
- 뱃지 호버 · 포커스 : 방석에서 살짝 들리고 그림자가 넓어진다.
- 1번 클릭 (들기) : 뱃지가 방석에서 뽑혀 화면 가운데로 크게 떠오르고, 상자는 어두운 막 뒤로 물러난다. 끌면 돌아가고 (손을 놓으면 관성으로 조금 더 돈다), 오른쪽 · Shift 끌기는 옮기기, 휠은 확대 · 축소 (0.6 ~ 3.2배). 휴대폰은 한 손가락 돌리기, 두 손가락 집기 · 옮기기. 두 번 누르면 처음 모습으로. 키보드는 화살표 돌리기, + / - 확대 · 축소, 0 처음으로.
- 2번 클릭 (들고 있는 뱃지를 끌지 않고 누르기) : 뱃지가 위로 올라가 제목 자리에 앉고, 그 종교의 문서 화면이 열린다. 글 목록은 전환이 끝난 뒤 하나씩 나타난다. 주소는 `#<종교 id>-docs`.
- 뒤로 : Esc · 뒤로가기로 문서 화면 → 들고 있는 뱃지 → 방석의 제자리 순으로 한 단계씩 돌아간다. 들고 있을 때 뱃지 밖을 누르면 바로 제자리로. 방석 위 뱃지는 내려앉는 연출이 끝난 뒤에 다시 보인다.
- 홈 버튼 : (문서 · 들기 상태를 먼저 닫고) 뚜껑이 닫히고 걸쇠가 잠긴 뒤 허브 칸 색으로 덮인다.

## 시안
- 확정 (2026-11-25) : B 시점 (거의 위에서 보기). A 는 목업 조작 버튼으로만 남긴다.
- A : 비스듬히 내려다본 시점 (32°), 뚜껑이 뒤로 젖혀져 서 있다.
- B : 거의 위에서 본 시점 (6°), 뚜껑은 화면 위쪽으로 넘어간다.
- 휴대폰 : 세로 상자, 2열.

## 주의
- 卍 은 왼쪽으로 도는 정방향 (위 팔이 왼쪽으로 꺾임) 으로만 쓴다. 기울인 卐 는 쓰지 않는다.
- 뱃지 모양 (원형이 겹치지 않게) : 유교 둥근 사각 도장 (안쪽 가는 금 테), 불교 卍 그대로, 도교 팔각 + 태극 + 복희 팔괘 8개 (위가 남쪽, 왼쪽이 동쪽), 원불교 둥근 판 + 일원상 (원 두 개가 겹친 모양), 기독교 십자, 힌두교 둥근 마름모, 이슬람 뾰족 아치 (미흐라브), 유대교 다윗의 별 모양 (가운데 흰 육각 + 파란 꼭짓점).
- 종교 배치 (2026-11-25 확정) : 위 줄 동양 종교 = 유교 · 불교 · 도교 · 원불교, 아래 줄 = 기독교 · 힌두교 · 이슬람 · 유대교. 휴대폰은 위 두 줄이 동양 종교. 불교는 卍 하나 (연꽃은 불교와 겹쳐 뺐다). 유교는 검은 바탕에 금 儒 (Noto Serif CJK Black 윤곽), 힌두교는 사프란 주황 바탕에 금 ॐ (FreeSerif Bold 윤곽). 신도는 뺐다.

## 구현 (Phase 7, 2026-11-25)
- 위치 : `apps/site/src/sections/religion/` — `Room.tsx` (골격) · `room.ts` (상자 연출 · 상태 · 기록) · `materials.ts` (금 재질 · 반사 환경 · 3D 뱃지) · `badges.ts` (`tools/badges.py` 가 만든 평면 도형) · `data.ts` (종교 목록 · 글) · `route.ts` (`?religion=<id>` = 문서 화면)
- 목업 17차 + 그림자 있는 버전 + 뚜껑 유리 없음 (검은 테두리만). 닫혀 있을 때 안쪽 어둠은 0.6 으로 옅게.
- 허브에서 들어오면 보라 칸 색이 가라앉은 뒤 상자 → 걸쇠 → 뚜껑 → 빛 순서. 글에서 돌아오거나 새로고침이면 열린 상자를 바로 보인다.
- 방을 나갈 때 (홈 등) 는 뚜껑을 닫고 걸쇠를 잠근 뒤 넘어가고, 문서 화면에서 글로 갈 때는 목록만 옅어진다.
- 글 목록은 Phase 2 전까지 `data.ts` 의 `posts` 로 채운다 (지금은 모두 비어 있어 "준비 중").

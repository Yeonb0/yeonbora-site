# 학교 방 디자인

목업 캔버스 : https://claude.ai/artifact/6CE3LcXZ7xaaUNaaxK9R52
`mockups/` 의 `.dc.html` 은 캔버스 원본이다 (Claude 디자인 캔버스에서 열린다).

## 계단 화면 (Main.dc.html, Mobile.dc.html)
- 1 ~ 5학년을 측면에서 본 막대 그래프처럼 왼쪽에서 오른쪽으로 높아지는 색 막대로 둔다.
- 막대에는 숫자 1 ~ 5만 쓴다. 설명글은 넣지 않는다.
- 배경은 단색. 장식 (별, 가로등) 은 넣지 않는다.
- 버튼은 글씨 없는 뒤로가기 아이콘 하나.
- 데스크톱은 호버, 모바일은 탭하면 그 학년 막대에서 시작해 화면 전체로 학년 색이 번진다.
- 펼친 화면에서 마우스를 위쪽 테두리로 올리면 (모바일은 맨 위 탭) 계단으로 돌아간다.

## 펼친 화면
과목을 교양 / 철학 / 종교학 / 컴퓨터공학으로 묶는다. 그 학년에 들은 과목이 없는 분류는 보이지 않는다.

후보 두 안 :
- 블록 (OpenBlocks.dc.html) : 분류마다 같은 너비 (1 : 1 : ...) 의 색 블록, 과목 이름은 흰 글씨.
- 쌓인 책 (OpenStack.dc.html) : 분류마다 책을 눕혀 쌓는다. 긴 이름이 아래, 책 길이는 이름 길이에 비례하고 최소 칸 폭의 절반. 책은 같은 더미 안에서 위아래 · 양옆으로 끌어 옮길 수 있고, 다른 책이 밀려나며 자리를 만든다.

### 분류 색
학년 색에서 분류별로 단계를 둔다. 순서는 교양 → 철학 → 종교학 → 컴퓨터공학.
- 2 · 3 · 4학년 : 흰색을 섞어 밝게 (0.12 / 0.24 / 0.36 / 0.48)
- 1 · 5학년 (밝은 노랑 · 하늘색) : 검정을 섞어 어둡게 (0.38 / 0.5 / 0.62 / 0.74)
- 예외 : 2학년은 0.28 / 0.36 / 0.42 / 0.48, 4학년 종교학은 검정 0.3, 4학년 컴퓨터공학은 흰색 0.34

## 과목 분류에서 정한 것
- 철학적인간학, 기초인공지능프로그래밍 : 교양
- 미적분학I, 선형대수학, Creative Solution : 교양
- 학년 기준 : 2022 ~ 2024년이 1 ~ 3학년, 2026년이 4학년, 2027년 (예정) 이 5학년

## 결정

- 철학 방을 실사풍 미술관으로 만든다 : 갈림길 (왼쪽 동양관 · 오른쪽 서양관) → 원형 홀의 문 4개 → 전시실 8개 (서양 : 고대 · 중세 · 근대 · 현대, 동양 : 유가 · 도가 · 불가 · 제자백가) → 초상화를 누르면 글.
- 장면은 실사풍 사진 한 장씩이고, 누른 자리로 확대되며 넘어가고 들어온 자리로 줄어들며 돌아온다.
- 구현은 페이지 하나에 React 섬 하나 (Museum.tsx) 를 두고, 장면을 주소 (?wing=&room=) 와 history 로 동기화한다.
- 배경 사진 11장은 Figma AI 로 만들었다.
- 문 열림은 닫힌 홀 사진에서 문짝을 잘라 실제로 움직인다 : 서양관은 안쪽으로 회전, 동양관은 옆으로 밀림.
- 명판은 뺐다. 문이 열리면 문틈 너머 어두운 벽에 방 이름이 떠오르고, 액자 이름은 액자 아래 벽 글자로 둔다.
- 전시실은 불이 꺼져 있고, 액자에 호버하면 천장 조명에서 내려오는 스포트라이트가 켜진다.
- 액자는 비중 (1 · 2 · 3) 에 따라 크기가 다르고, 시드 난수로 벽 전체에 흩어 건다.
- 뒤로가기 버튼 대신 화면 아래쪽에 마우스를 대면 바닥에 문 모양 빛이 깔리고, 누르면 한 단계 뒤로 간다 (갈림길에서는 허브로).
- 철학 방을 Phase 2 보다 먼저 만들고, 초상화 → 글 연결은 Phase 2 뒤에 확인한다.
- 한 철학자의 글이 여러 편이면 서재 목록 (/posts?topic=) 으로 보낸다.
- 처음 걸 철학자와 비중 : 소크라테스 · 플라톤 · 아리스토텔레스 · 공자 · 맹자 · 순자 · 노자 · 장자 · 칸트는 크게. 중세 · 현대 · 불가 · 제자백가는 비워 둔다.

## 이유 · 버린 대안

- 장면 연출 : 진짜 3D 공간 (Three.js) 과 CSS 원근 복도도 검토했다. 실사 질감을 내려면 3D 는 조명 · 재질 작업과 모바일 성능 부담이 크고, CSS 원근은 실사감이 떨어진다. 사이트의 기존 "번지며 넘어가는" 전환과 이어지는 장면 한 장씩 방식을 골랐다.
- 구조 : 장면마다 Astro 페이지 + View Transitions, 홀까지만 섬인 혼합안도 검토했다. 이 방의 핵심인 "문이 열리고 그 안으로 들어가는" 연출이 페이지 경계에서 끊겨서 섬 하나로 갔다. 주소 동기화로 공유 · 새로고침 · 뒤로가기는 살렸다.
- 이미지 도구 : 힉스필드 (구독 필요) 와 Gemini 무료를 거쳤다. Gemini 는 무료 이미지에 표시가 들어가고, 열린 문 편집이 한 문씩 빠지는 문제가 있어 Figma AI 로 다시 뽑았다.
- 문 열림 : 열린 문 사진을 따로 만들어 겹치는 방식은 문마다 편집 결과가 달라 버렸다. 닫힌 사진의 문짝을 잘라 움직이면 질감이 그대로이고 네 문이 똑같이 열린다.
- 명판 : 황동 → 은판 → 결 있는 은판 → 테두리 없는 판까지 바꿔 봤지만 사진 위에 떠 보여서 뺐다.
- 스포트라이트 : 둥근 빛 → 각진 원뿔 → 빛기둥 + 웅덩이를 거쳐, 위가 좁고 아래로 퍼지며 액자 아래에서 둥글게 사라지는 한 덩어리로 정했다.
- 액자 배치 : 줄 맞춤 배치에서 가운데로 모으는 흩어 걸기, 벽 전체에 고르게 퍼뜨리는 best-candidate 순으로 바꿨다. 참고 사진은 크기가 제각각인 진열창이 벽 전체에 흩어진 벽이었다.
- 이황 · 이이 : 남아 있는 옛 초상이 없고 지폐 초상 (표준영정) 은 저작권이 있다. 처음엔 글씨를 걸기로 했다가, 관리자님 판단으로 표준영정을 일단 건다. 저작권 표시를 자르지 않고 두며, 공개 배포 전에 사용 허락을 받거나 글씨 · 빈 액자로 바꾼다.

## 막힌 점

- 작업 환경에서 figma.com · wikimedia 다운로드가 막혔다. 사진과 초상화는 관리자님이 받아 zip 으로 올렸다.
- Gemini 무료 편집에서 동양관 맨 왼쪽 문이 끝내 열리지 않았다. 문을 잘라 움직이는 방식으로 바꿔 해결했다.
- 목업에서 액자 나무 테두리가 안 보였다. `.stage button` 초기화가 `.frame` 배경을 덮었기 때문이라, 초기화를 `:where()` 로 감쌌다.
- 방 안 뒤로가기 : ClientRouter 가 popstate 를 페이지 이동으로 처리하지 않도록, 섬이 capture 단계에서 먼저 받아 막는다. 다른 페이지로 오가는 기록은 건드리지 않는다.
- 최종 리뷰에서 지적된 문제 셋 : 전환 중 문 클릭 뒤 문이 죽는 문제, 문이 열리는 동안 뒤로가기를 하면 주소와 화면이 어긋날 수 있는 문제, 초상화 확대 중 뒤로가기를 하면 남은 링크가 다음 클릭을 글로 보내는 문제. 모두 고쳤다.

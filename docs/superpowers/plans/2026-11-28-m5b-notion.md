# M5-b Notion 이전 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** Notion 𝑨𝒓𝒄𝒉𝒊𝒗𝒆 아래 정리 글을 `posts/notion/` 으로 옮기고, 원문 대조 · 중복 정리 · 깨진 링크 0 으로 PR 하나를 낸다.

**Architecture :** 원문은 관리자가 내려받은 Notion HTML 내보내기 (그림 포함 zip) 를 `raw/notion/export/` 에, 작성일 · 주소 · 부모 같은 메타는 Notion 연결 (MCP) 로 모은 `raw/notion/meta.json` 에 둔다. `pnpm migrate:notion` 은 tistory 도구와 같은 구조 (cli · command · convert · run + pages.ts) 로 오프라인 변환한다. HTML → hast → mdast → 마크다운 경로는 tistory 와 같고, Notion 전용 블록 (토글 · 콜아웃 · 열 · 수식 · 첨부 · 페이지 링크) 만 새 처리기가 맡는다.

**Tech Stack :** TypeScript · tsx · vitest · unified (rehype-parse · rehype-remark · remark-gfm · remark-stringify) · yaml

**Spec :** `docs/superpowers/plans/2026-11-28-m5-scattered-blogs.md` 의 M5-b 행 + `docs/migration/project-instructions.md` (M5 결정) + `docs/content-rules.md`

## Review Focus
1. 토글 안에 토글 · 목록 · 코드가 겹친 블록 : 펼쳤을 때 순서 · 들여쓰기가 원문과 같아야 한다 → Task 3 테스트 `nested toggle keeps order`.
2. 열 (columns) 안의 제목 · 그림 : 열을 펼친 뒤 왼쪽 열 → 오른쪽 열 순서로 이어져야 한다 → Task 3 `columns flatten left to right`.
3. 같은 제목의 Notion 페이지 둘 (예 : 학기마다 "기말고사 공부") 또는 같은 날 같은 제목 : slug 가 겹치면 멈추고 리포트에 남겨야 한다 → Task 4 `slug clash is reported, not overwritten`.
4. 내보내기에 그림 파일이 없거나 이름이 같은 다른 그림 : 리포트의 못 찾은 그림 · 충돌로 가야 한다 → Task 4 `missing and clashing images are reported`.
5. 이미 옮긴 다른 출처와 같은 글 (Notion 원본 ↔ Jekyll · Tistory 게시본) : 둘 다 남지 않고 dupes 리포트에 짝으로 나와야 한다 → Task 5 `finds same-body pair across sources`.

블록 규칙 (테스트가 이 값을 고정한다) :

| Notion HTML | 마크다운 |
|---|---|
| `<details><summary>제목</summary>…</details>` (토글) | `> [!summary]- 제목` 접힌 콜아웃 (각 줄 `> `). 사이트 콜아웃 플러그인이 details 로 그리고, Obsidian 에서도 안쪽 마크다운이 보인다 |
| `<figure class="callout">` 아이콘 + 본문 | `> [!note] ` + 아이콘 문자 그대로 첫 줄, 본문은 `> ` |
| `<div class="column-list"><div class="column">` | 열을 왼쪽부터 차례로 펼침 (구분 줄 없음) |
| `<figure class="equation">` · `annotation[encoding="application/x-tex"]` | `$$\n<TeX>\n$$`, 줄 안 수식은 `$<TeX>$` |
| `<pre><code class="language-x">` | ` ```x ` |
| `<table>` 머리 행 있음 / 없음 | GFM 표 / 모양 속성 지운 HTML 표 |
| `<figure class="image"><img src="폴더/그림.png">` | `![](../../_assets/notion/<slug>/<그림 이름>)` |
| 첨부 (`figure` 안 파일 링크 · `<a href="…pdf">`) | 지우고 notes 에 `attachment` |
| 다른 Notion 페이지 링크 | 옮긴 글이면 `[[제목]]`, 아니면 글자만 남기고 `page-link-missing` |
| 북마크 `figure.bookmark` | `[제목](주소)` |
| 페이지 제목 `<h1 class="page-title">` · 속성 표 `table.properties` | 본문에서 빼고 frontmatter 로 |

- [ ] **Step 1 : 실패하는 테스트** (각각 입력 HTML 한 조각 → 기대 마크다운 문자열)

  - `nested toggle keeps order` : 토글 안 토글 + 목록 → 바깥 `> ` 안에 `> > [!summary]-`, 목록 순서 그대로
  - `columns flatten left to right` : 열 2개 (`<h3>A</h3>` · `<h3>B</h3>`) → `### A` 가 `### B` 보다 앞
  - `equation block and inline` : `$$\nO(n\\log n)\n$$` · `$x_i$`
  - `attachment removed and noted` : PDF 링크 블록 → 본문에 없음, notes 에 `{ kind: 'attachment' }`
  - `missing page link keeps text` : `linkTitle` 이 undefined 를 돌려주면 글자만, notes 에 `page-link-missing`
  - `frontmatter` : `source: notion` · `date: 2025-03-02` (meta.created 의 날짜) · `originalUrl: https://www.notion.so/<id>` · rule 의 topic · context · course · tags · series
  - `siteSlugOf` : `{ created: '2025-03-02T10:00:00.000Z', title: '[자구] 힙 정렬' }` → `2025-03-02-자구-힙-정렬` (tistory `siteSlugOf` 와 같은 결과인지 함께 검사)

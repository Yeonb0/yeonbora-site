# 철학 방 설계 (Phase 6)

작성 : 2026-11-25
배경 이미지 원본 : Figma 파일 "yeonbora-site · 철학 방 장면" (https://www.figma.com/design/uf28cWPqGfmSFUCxRFRyhd)

## 1. 의도

철학 방은 실사풍 미술관이다. 방에 들어서면 미술관 갈림길에 서고, 왼쪽 동양관 / 오른쪽 서양관으로 걸어 들어가 시대 · 학파별 전시실의 문을 연다. 전시실 벽에는 철학자 초상화가 그림처럼 걸려 있고, 초상화를 누르면 그 철학자를 정리한 글로 간다.

사이트의 다른 방처럼 "주제를 은유하는 다른 세계"이고, 이 방의 핵심 경험은 **문이 열리고 그 안으로 걸어 들어가는 연속된 연출**이다. 화면이 툭 바뀌는 순간이 있으면 실패다.

## 2. 목표 · 비목표 · 반목표

목표
- 갈림길 → 원형 홀 → 전시실 → 글로 이어지는 4단계 탐색
- 사진 속 문이 실제로 열리는 호버 연출 (서양관은 회전, 동양관은 옆으로 밀림)
- 전시실 벽의 초상화 수가 글 수에 따라 바뀜, 글이 없으면 빈 액자
- 데스크톱 · 모바일 모두에서 같은 흐름

비목표
- 실시간 3D 공간 (Three.js) : 장면 한 장씩 넘기는 방식으로 결정됨
- 철학자 소개 글을 방 안에 두는 것 : 글은 `/posts/<slug>` 에만 있다

반목표 (동작해도 실패로 본다)
- 장면 사이에 흰 화면 · 깜빡임 · 갑자기 나타나는 요소
- 사진 위에 떠 보이는 UI (명판 · 액자가 그림과 따로 노는 느낌)
- 요청하지 않은 설명글

## 3. 제약

- 저장소 규칙 : 방 하나 = `registry.ts` 한 줄 + `src/sections/philosophy/` (Layout.astro + tokens.css) + `src/pages/philosophy/index.astro`. 방은 콘텐츠를 직접 갖지 않는다.
- 허브 → 방 전환은 기존 ClientRouter + `transition:name="section-philosophy"` 를 그대로 쓴다.
- 모든 전환은 열 때와 닫을 때 모두 부드럽게, 새 화면 내용은 전환이 끝난 뒤에 나타난다. `prefers-reduced-motion` 이면 짧은 크로스페이드로 줄인다.
- 글꼴 : 사이트 기본은 나눔스퀘어. 명판 · 이름표에만 예외로 Cinzel (서양관 영문) 과 Noto Serif KR Bold (동양관 한자) 를 쓴다. 둘 다 정자체.
- 배경 이미지는 Figma AI 생성물 (1536 × 864). 생성 이미지에 표시 (워터마크) 를 넣는 도구는 쓰지 않는다.
- Phase 2 (content collection) 가 아직 없다. 그전까지는 학교 방의 `data.ts` 처럼 임시 데이터를 둔다.

## 4. 접근 (구현 방식)

| 안 | 내용 | 대가 |
|---|---|---|
| **A. 섬 하나 + 주소 동기화 (선택)** | `/philosophy` 에 React 섬 `Museum.tsx` 하나. 장면은 섬 안의 상태, 주소는 history.pushState 로 동기화 | 뒤로가기를 섬 안의 연출과 직접 연결해야 함. 전시실이 검색엔진에 별도 페이지로 보이지 않음 |
| B. 장면마다 Astro 페이지 + View Transitions | `/philosophy/west/ancient` 등 11개 페이지 | "문 열림 → 확대 → 다음 장면"이 페이지 경계에서 끊김. 누른 지점으로 확대를 CSS 만으로 맞춰야 함 |
| C. 홀까지 섬, 전시실은 페이지 | 섞기 | 가장 중요한 "문 → 전시실" 순간이 페이지 경계에 걸림 |

관리자님이 A 를 골랐다. 이유 : 핵심 연출을 한 화면 안에서 끊김 없이 다룰 수 있고, 학교 방 (SchoolRoom.tsx) · 컴퓨터 방 (Desktop.tsx) 과 같은 구조이며, 주소 동기화로 공유 · 새로고침 · 뒤로가기도 된다.

## 5. 정해진 것

### 5.1 장면과 흐름

```
허브 ─(ClientRouter)→ 갈림길
갈림길 ─ 왼쪽 아치 → 동양관 원형 홀 ─ 문 4개 → 전시실 4개
       └ 오른쪽 아치 → 서양관 원형 홀 ─ 문 4개 → 전시실 4개
전시실 ─ 초상화 클릭 → /posts/<slug>
```

| id | 장면 | 이미지 파일 | Figma 노드 |
|---|---|---|---|
| crossroads | 갈림길 | `01-crossroads` | 1:2 |
| west | 서양관 원형 홀 | `02-west-hall` | 3:2 |
| east | 동양관 원형 홀 | `03-east-hall` | 3:3 |
| west/ancient | 고대 | `10-west-ancient` | 3:4 |
| west/medieval | 중세 | `11-west-medieval` | 3:5 |
| west/modern | 근대 | `12-west-modern` | 3:6 |
| west/contemporary | 현대 | `13-west-contemporary` | 3:7 |
| east/confucian | 유가 | `20-east-confucian` | 3:8 |
| east/daoist | 도가 | `21-east-daoist` | 3:9 |
| east/buddhist | 불가 | `22-east-buddhist` | 3:10 |
| east/hundred | 제자백가 (묵가 · 법가 · 명가 등) | `23-east-hundred` | 3:11 |
| (재질) | 명판 금속판 | `plate-metal` | 6:2 |

- 홀의 문 순서 (왼쪽 → 오른쪽) : 서양관 고대 · 중세 · 근대 · 현대 / 동양관 유가 · 도가 · 불가 · 제자백가.
- 서양관 홀은 문을 크게 다시 뽑았다 (2026-11-25). 문이 벽 높이 대부분을 차지하는 위가 둥근 아치형 문이다.
- 처음 시안의 "복도 끝 문 4개"와 "통로 4갈래"는 버렸다. 원형 홀 가운데에서 문 4개를 정면으로 보는 한 장면이다.

### 5.2 주소

- `/philosophy` : 갈림길
- `/philosophy?wing=west` · `?wing=east` : 원형 홀
- `/philosophy?wing=west&room=ancient` : 전시실
- 주소로 바로 들어오면 그 장면을 연출 없이 바로 보여 준다. 뒤로가기는 한 단계 위 장면으로 줄어들며 돌아간다.
- 잘못된 값이면 갈림길로 바꾼다 (replaceState).

### 5.3 전환 연출

- **허브 → 갈림길** : 기존 방 전환. 허브 칸 색이 화면 전체로 커진 뒤, 그 색에서 갈림길 사진이 번져 나온다.
- **갈림길 → 홀** : 누른 아치의 중심으로 사진이 확대되며 어두워지고, 다음 홀 사진이 약간 확대된 상태에서 제자리로 내려앉으며 나타난다.
- **홀 → 전시실** : 문이 열린 상태에서 그 문틈으로 확대된다. 문틈 너머에 미리 보이던 전시실 사진이 그대로 화면 전체로 커지며 전시실이 된다 (문틈 안 이미지와 전시실 이미지가 같은 사진이라 이어진다).
- **전시실 → 글** : 누른 초상화가 화면 가운데로 커지며 어두워지고, 그 뒤 `/posts/<slug>` 로 이동한다.
- **돌아가기** : 들어온 지점으로 줄어들며 이전 장면으로 간다. 홀로 돌아오면 열려 있던 문이 닫힌다.
- 액자 · 명판 · 이름표는 장면 전환이 끝난 뒤에 나타난다.

### 5.4 문 열림

- 닫힌 홀 사진에서 문 영역을 잘라 실제로 움직인다. 열린 상태 사진은 따로 만들지 않는다.
- 서양관 : 두 문짝이 바깥쪽 경첩을 축으로 안쪽으로 회전한다 (perspective + rotateY). 문 위쪽이 둥근 아치라서 문짝과 문틈은 아치 모양으로 잘라 낸다 (clip-path).
- 동양관 : 두 창살문이 양옆 벽 속으로 미끄러져 들어간다 (translateX, 문틀 밖은 잘림).
- 문틈 너머 : 그 문이 이어지는 전시실 사진을 흐리게 깔고, 따뜻한 빛이 바닥으로 번지는 층을 얹는다.
- 호버 · 포커스하면 열리고, 벗어나면 닫힌다.

### 5.5 명판

- 문 위에 하나씩. 서양관은 가로형 영문 (ANCIENT · MEDIEVAL · MODERN · CONTEMPORARY), 동양관은 세로형 한자 (儒 · 道 · 佛 · 百).
- 판 : Figma 로 만든 밝은 은색 브러시드 금속 (`plate-metal`) 을 배경으로 쓴다. 테두리 없음. 명암은 옅게.
- 글자 : 흰색, 아래쪽 그림자로 판에서 읽히게 한다.
- 평소에는 조금 어둡게, 문에 호버하면 밝아지며 빛줄기가 한 번 지나간다.
- 서양관 명판 폭은 가장 긴 단어 (CONTEMPORARY) 에 맞춰 넷 다 같게 한다.

### 5.6 전시실

- **불이 꺼진 방** : 전시실은 평소에 불이 꺼진 것처럼 아주 어둡다. 초상화에 호버 (모바일은 탭 직전 누르는 동안) 하면 그 액자 위로 스포트라이트가 켜지듯 빛이 둥글게 퍼진다. 벗어나면 천천히 꺼진다.
  - 구현 : 같은 전시실 사진을 두 겹 쓴다. 아래는 아주 어둡게 (밝기 20 ~ 25%), 위는 원래 밝기이고 호버한 액자 위치의 둥근 마스크 (radial-gradient mask) 로만 보인다. 마스크 반지름을 0에서 키워 "켜지는" 느낌을 낸다. 전시실 사진에 이미 있는 벽의 빛 웅덩이가 그대로 스포트라이트처럼 보인다. 사진을 새로 만들 필요가 없다.
  - 액자 · 초상화 자체도 평소에는 어둡고, 빛이 닿을 때 밝아진다.
  - 전시실에 막 들어왔을 때 아무것도 안 보이면 길을 잃으므로, 액자 윤곽은 아주 희미하게 보이게 둔다.
- 벽에 초상화 액자를 건다. 초상화는 퍼블릭 도메인 고전 회화 (위키미디어 커먼즈). 액자 안에 같은 색 보정 (따뜻한 톤, 약간 낮은 채도) 과 위쪽 조명 그라데이션을 입혀 화풍 차이를 줄인다.
- 초상화가 없는 자리는 빈 액자 (액자 틀과 빈 캔버스) 로 둔다. 초상화는 있지만 글이 없는 철학자는 걸어 두되 클릭만 막는다 (§8.4).
- 이름표 : 액자 아래 같은 은색 판. 서양관은 영문 대문자 (PLATO), 동양관은 한자 (孔子). 평소에는 숨기고 초상화에 호버할 때 빛을 받아 드러난다.

### 5.7 모바일 (호버가 없는 기기)

- 장면 사진은 화면을 가득 채우고 (cover), 좌우로 끌어 둘러볼 수 있다. 처음 위치는 가운데.
- 문 · 아치 · 초상화는 한 번 탭하면 바로 들어간다 (허브와 같은 규칙). 문은 탭하는 순간 열리며 바로 확대된다.
- 명판과 이름표는 항상 보인다.

### 5.8 데이터

Phase 2 전까지 `src/sections/philosophy/data.ts` 에 임시 데이터를 둔다.

```ts
type Wing = 'west' | 'east'
type RoomId = 'ancient' | 'medieval' | 'modern' | 'contemporary' | 'confucian' | 'daoist' | 'buddhist' | 'hundred'

interface Philosopher {
  id: string
  name: string        // 한국어 이름 (alt · 접근성)
  label: string       // 이름표 : PLATO / 孔子
  wing: Wing
  room: RoomId
  weight: 1 | 2 | 3   // 액자 크기 : 비중이 클수록 크게 (§8.3)
  portrait?: string   // 없으면 빈 액자
  posts: string[]     // 0편 : 클릭 불가, 1편 : 그 글로, 여러 편 : 서재 목록으로 (§8.2)
}
```

Phase 2 이후에는 posts collection 의 `field: philosophy` + `topic` 으로 걸러 섬에 props 로 넘긴다.

## 6. 빌더에게 맡기는 것

- 장면 사진의 최적화 방식 (Astro 이미지 파이프라인으로 AVIF / WebP, 필요하면 Upscayl 로 2배 업스케일한 원본 사용)
- 아치 · 문 · 액자 걸 자리의 정확한 % 좌표 측정
- 전환 시간과 이징 세부값. 기준은 허브와 같은 `cubic-bezier(0.22, 1, 0.36, 1)`, 문 열림 0.6s 안팎, 장면 확대 0.9s 안팎
- 다음 장면 사진 미리 불러오기 시점
- 뒤로가기 버튼의 모양 (학교 방처럼 글씨 없는 아이콘 하나) 과 Esc 키 처리

## 7. 빌더 점검 뒤 정한 것 (Claude 의 판단, 관리자님 확인 필요)

- **액자 수** : 방마다 걸 철학자는 데이터의 철학자 목록으로 정한다. 글이 없는 철학자는 빈 액자. 액자는 사진 속 벽의 빛 웅덩이 자리에 한 줄로 건다 (방마다 5 ~ 6자리). 그보다 많아지면 두 줄 (살롱식) 로 촘촘하게 건다. §2 의 "글 수에 따라 바뀜"은 "철학자 목록과 글 유무에 따라 바뀜"으로 읽는다.
- **글에서 돌아올 때** : 글 페이지로 떠날 때 어느 초상화였는지 sessionStorage 에 남긴다. 그 기록이 있는 채로 전시실 주소에 돌아오면 그 초상화에서 화면이 줄어드는 역연출을 넣는다. 기록이 없으면 (공유 링크 등) 연출 없이 바로 보여 준다.
- **뒤로가기** : 섬 안의 뒤로가기 버튼 · Esc 는 항상 한 단계 위 장면으로 간다. 브라우저 뒤로가기는 히스토리를 따른다. 공유 링크로 전시실에 바로 들어왔다면 브라우저 뒤로가기는 사이트 밖으로 나가는 것이 맞다 (히스토리를 끼워 넣지 않는다).
- **목업** : 프로젝트 규칙대로 구현 계획의 첫 단계는 목업이다. 실제 장면 사진 위에 명판 · 액자 · 빈 액자 · 스포트라이트 · 뒤로가기 버튼 · 공용 홈 버튼을 올린 정적 시안을 만들어 승인받은 뒤 코드로 옮긴다.
- **이미지** : 현재 Figma 노드 (§5.1 표) 를 확정본으로 본다. 관리자님이 Figma 에서 PNG 로 내보내 `assets/` 에 넣는다. 사진이 바뀌면 그 장면의 % 좌표만 다시 잰다.

## 8. 관리자님 답 (2026-11-25)

### 8.1 Phase 2 와의 순서
철학 방을 먼저 만든다. 초상화 링크는 주소 규칙대로 걸어 두고, Phase 2 가 끝나면 실제 글로 이어진다. Phase 6 완료 기준의 "사상가 클릭 시 정리 글"은 Phase 2 이후에 확인한다.

### 8.2 한 철학자에 글이 여러 편일 때
- 글이 한 편이면 그 글 (`/posts/<slug>`) 로 바로 간다.
- 여러 편이면 그 철학자 글만 걸러 둔 서재 목록 (`/posts?topic=<철학자 id>`) 으로 간다.
- 관리자님 바람 : 서재도 실사 서재처럼 생기면 좋겠다. 서재 화면은 프로젝트 지침에서 "디자인 미정"이라 이 문서 범위 밖이다. 별도로 설계한다.
- 데이터 : `post?: string` 대신 `posts: string[]` 로 두고, 개수로 갈 곳을 정한다.

### 8.3 액자 크기 : 비중이 클수록 크게
- 철학자마다 `weight` (1 작게 · 2 보통 · 3 크게) 를 둔다. 큰 액자는 벽 가운데 눈높이에, 작은 액자는 그 둘레에 살롱식으로 모아 건다.
- 예 (관리자님) : 소크라테스 · 플라톤 · 아리스토텔레스는 크게, 나머지 소크라테스 이전 철학자들은 작게.

### 8.4 처음 걸 철학자
관리자님 : 공부한 것은 있지만 중세 · 현대 · 불가 · 제자백가는 일단 비워 두고 시작한다.

| 방 | 철학자 (weight) |
|---|---|
| 고대 | 소크라테스 (3), 플라톤 (3), 아리스토텔레스 (3), 탈레스 (1), 피타고라스 (1), 헤라클레이토스 (1), 파르메니데스 (1), 데모크리토스 (1) |
| 중세 | 비움 |
| 근대 | 칸트 (3) |
| 현대 | 비움 |
| 유가 | 공자 (3), 맹자 (2), 주희 (2), 이황 (2), 이이 (2) |
| 도가 | 노자 (3), 장자 (3), 왕필 (1) |
| 불가 | 비움 |
| 제자백가 | 비움 |

- 고대의 소크라테스 이전 다섯 명, 유가 · 도가의 weight 는 Claude 가 정했다. 관리자님이 고칠 수 있다.
- "비움" 방에는 빈 액자 세 개 (weight 2) 를 건다. Claude 의 판단.
- 지금은 글이 없으므로 모든 액자는 초상화가 걸린 채 클릭만 막아 둔다. 글이 생기면 클릭이 열린다. 초상화가 없는 철학자는 빈 액자다.
